# お知らせ一覧画面（coachアプリ）

## 概要

- アプリ: `coach`
- パス: `/notice`
- 対象ロール: コーチ
- 目的: 運営（Gabby Blueprintチーム）からのお知らせ・アップデート情報を確認する。

## この画面に来る経路

- ヘッダー右上の通知ベル（Notification Center）の「Notices」タブから「View all →」で遷移する。
- ベルのドロップダウン内で個別のお知らせをクリックした場合は、その通知をハイライト・展開した
  状態でこの画面が開く（URLの`?focus=<notice_id>`パラメータ経由）。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、件数バッジ
2. **お知らせ一覧（アコーディオン）** — カードをクリックすると内容が展開される

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 未読インジケーター（青丸） | 未読のお知らせ | カードを開くと自動的に既読になる |
| 種別バッジ | 「Notice」「Campaign」「Maintenance」「Update」のいずれか | — |
| 「Important」バッジ | 重要フラグが立っているお知らせ | — |
| 添付件数アイコン | 添付ファイルがある場合 | — |
| カードのクリック | 常時 | 本文（Markdown表示）・添付ファイル一覧を展開/折りたたみする |
| 添付ファイルの「Preview」ボタン | プレビュー可能な形式（画像・PDF等）の添付のみ表示 | 新しいタブでファイルを開く |
| 添付ファイルの「Save」ボタン | 全ての添付に表示 | ファイルをダウンロードする |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中 | スケルトン4件分 | 画面表示直後、データ取得中（この画面では常に最新データを再取得する） |
| 空 | 「No notices yet」「You'll see announcements from the team here.」 | お知らせが1件も無い場合 |
| `?focus=`指定あり | 対象のお知らせが自動的に展開され、画面中央にスクロールする | 通知ベルのドロップダウンから個別のお知らせをクリックして遷移した場合 |
