# チャット詳細画面（coachアプリ）

## 概要

- アプリ: `coach`
- パス: `/chat/[roomId]`
- 対象ロール: コーチ
- 目的: 特定のチャットルーム内でメッセージ（テキスト・添付ファイル）を送受信する。
- `md` 以上ではチャットルーム一覧（[list.md](list.md)）の右ペインに表示し、左の一覧は表示したまま。
  `md` 未満ではルームだけを表示する。

## この画面に来る経路

- チャットルーム一覧（`/chat`）の各行から開く。
- お知らせ・通知経由で該当ルームへのリンクが張られている場合はそこからも遷移し得る。

## 画面の構成

1. **ヘッダー** — 一覧へ戻る矢印（`md` 未満のみ）、相手（1対1）またはグループ名・メンバー一覧、種別ラベル
2. **タイムライン** — 送受信メッセージを時系列に表示。上にスクロールすると過去のメッセージを
   追加読み込みする
3. **メッセージ入力欄** — テキスト入力、ファイル添付、送信ボタン（自分がルームの参加者では
   ない場合はこの入力欄自体が表示されない）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| メッセージのヘッダー（送信者名・時刻） | 直前のメッセージと送信者・時間帯が連続していない場合のみ表示（連続する場合は省略され、ホバー時に時刻だけが吹き出し脇に表示される） | — |
| 自分が送ったメッセージ | 右寄せ・淡い青（ブランド色の淡色）の吹き出し | — |
| 相手が送ったメッセージ | 左寄せ・淡いグレーの吹き出し、アバター付き | — |
| 削除済みメッセージ | 「This message was deleted」（斜体） | — |
| 画像添付 | 添付ファイルが画像形式の場合 | サムネイル表示。クリックで元画像を新しいタブで開く |
| 画像以外の添付ファイル | ファイル名・サイズ付きのリンク表示 | クリックで新しいタブで開く（ダウンロード） |
| URLを含むテキスト | メッセージ本文にURLが含まれる場合 | 自動的にリンク化される |
| 「New messages」の区切り線 | ルームを開いた時点で未読メッセージがある場合、最初の未読メッセージの上に表示 | 開いた直後はこの区切り線の位置から表示する（未読が無い場合は最新メッセージの位置から表示） |
| 「Jump to latest」ボタン | 最新メッセージから離れて過去のメッセージを見ている間に表示。その間に届いた新着がある場合は「N new message(s)」と表示 | クリックすると最新メッセージまでスクロールする |
| 上端までスクロール | 過去のメッセージがまだ存在する場合 | 自動的に1ページ分（既定件数）を追加読み込みし、閲覧位置がずれないよう表示位置を保持する |
| ファイル添付ボタン（クリップアイコン） | 常時（自分が参加者の場合） | ファイル選択ダイアログを開く。複数選択可。1ファイル10MBを超えるとエラートーストが表示されそのファイルはスキップされる |
| 添付済みファイルのチップ | アップロード完了後、送信前 | 「×」ボタンで送信前に取り消せる |
| テキスト入力欄でのEnterキー | 本文入力中。改行・折り返しに合わせて入力欄の高さが伸び、10行（スマートフォンは5行）を超えると入力欄の中でスクロールする | メッセージを送信する（Shift+Enterで改行。日本語入力の変換確定のEnterでは送信しない。タッチ端末ではEnterは改行になり、送信ボタンで送信する） |
| 送信ボタン | 本文または添付ファイルのいずれかがある場合に活性化 | メッセージを送信し、末尾へ自動スクロールする |
| 下書きの保持 | 入力中の本文・送信前の添付はルームごとに保持する | 別のルームを開いてから戻っても入力内容が残る（ページの再読み込みで消える） |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 参加者ではない | 入力欄の代わりに「You are not a participant of this room, so you cannot send messages here.」 | 自分がそのルームのメンバーに含まれていない場合（閲覧のみ） |
| 読み込み中 | チャットの骨組み（ヘッダーと吹き出しの形） | ルームを開いてから表示されるまでの間 |
| 過去メッセージ読み込み中 | タイムライン上部にスピナー | 上スクロールによる追加読み込み中 |
| 新着メッセージ受信 | リアルタイムでタイムラインに追加。最新メッセージ付近を表示中なら末尾へスムーズスクロールし、過去のメッセージを見ている場合はスクロールせず「N new message(s)」ボタンを表示 | 相手または自分が別タブ等から送信した場合（Supabase Realtime経由） |
| 既読 | 表示中のルームのメッセージは既読にする。ブラウザのタブが裏にある間に届いたメッセージは、タブを表に戻した時点で既読にする | — |
| 存在しないルームID | Not Foundページ | 指定した`roomId`のルームが存在しない、または閲覧権限が無い場合 |
