# チャット詳細画面（coachアプリ）

## 概要

- アプリ: `coach`
- パス: `/chat/[roomId]`
- 対象ロール: コーチ
- 目的: 特定のチャットルーム内でメッセージ（テキスト・添付ファイル）を送受信する。

## この画面に来る経路

- チャットルーム一覧（`/chat`）の各行から遷移する。
- お知らせ・通知経由で該当ルームへのリンクが張られている場合はそこからも遷移し得る。

## 画面の構成

1. **ヘッダー** — 一覧へ戻る矢印、相手（1対1）またはグループ名・メンバー一覧、種別ラベル
2. **タイムライン** — 送受信メッセージを時系列に表示。上にスクロールすると過去のメッセージを
   追加読み込みする
3. **メッセージ入力欄** — テキスト入力、ファイル添付、送信ボタン（自分がルームの参加者では
   ない場合はこの入力欄自体が表示されない）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| メッセージのヘッダー（送信者名・時刻） | 直前のメッセージと送信者・時間帯が連続していない場合のみ表示（連続する場合は省略され、ホバー時に時刻だけが吹き出し脇に表示される） | — |
| 自分が送ったメッセージ | 右寄せ・インディゴ色の吹き出し | — |
| 相手が送ったメッセージ | 左寄せ・グレーの吹き出し、アバター付き | — |
| 削除済みメッセージ | 「This message was deleted」（斜体） | — |
| 画像添付 | 添付ファイルが画像形式の場合 | サムネイル表示。クリックで元画像を新しいタブで開く |
| 画像以外の添付ファイル | ファイル名・サイズ付きのリンク表示 | クリックで新しいタブで開く（ダウンロード） |
| URLを含むテキスト | メッセージ本文にURLが含まれる場合 | 自動的にリンク化される |
| 上端までスクロール | 過去のメッセージがまだ存在する場合 | 自動的に1ページ分（既定件数）を追加読み込みし、閲覧位置がずれないよう表示位置を保持する |
| ファイル添付ボタン（クリップアイコン） | 常時（自分が参加者の場合） | ファイル選択ダイアログを開く。複数選択可。1ファイル10MBを超えるとエラートーストが表示されそのファイルはスキップされる |
| 添付済みファイルのチップ | アップロード完了後、送信前 | 「×」ボタンで送信前に取り消せる |
| テキスト入力欄でのEnterキー | 本文入力中 | メッセージを送信する（Shift+Enterで改行） |
| 送信ボタン | 本文または添付ファイルのいずれかがある場合に活性化 | メッセージを送信し、末尾へ自動スクロールする |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 参加者ではない | 入力欄の代わりに「You are not a participant of this room, so you cannot send messages here.」 | 自分がそのルームのメンバーに含まれていない場合（閲覧のみ） |
| 過去メッセージ読み込み中 | タイムライン上部にスピナー | 上スクロールによる追加読み込み中 |
| 新着メッセージ受信 | リアルタイムでタイムラインに追加され、末尾へスムーズスクロール | 相手または自分が別タブ等から送信した場合（Supabase Realtime経由） |
| 存在しないルームID | Not Foundページ | 指定した`roomId`のルームが存在しない、または閲覧権限が無い場合 |
