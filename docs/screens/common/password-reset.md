# パスワード再設定（3アプリ共通）

## 概要

- アプリ: `admin` / `coach` / `student`（画面・処理は共通。違いは文言の言語と入力例のみ、下記「アプリごとの違い」）
- パス: `/forgot-password`（再設定メールの依頼）、`/auth/callback`（メール内リンクの受け口・画面なし）、`/update-password`（新しいパスワードの設定）
- 対象ロール: パスワードを忘れた利用者（未ログイン）
- 目的: 登録済みのメールアドレスに再設定リンクを送り、リンクから新しいパスワードを設定する。

## 流れ

1. ログイン画面の「パスワードをお忘れですか？」から `/forgot-password` を開き、メールアドレスを送信する。
2. 登録済みのアドレスであれば、再設定メールが届く（未登録でも画面上は同じ完了表示になる）。
3. メール内のリンク（`/auth/callback?token_hash=...&type=recovery`）を開くと、`/update-password` の案内が表示される。
4. 「手続きを開始する」を押すと、サーバーがリンクを確認し、新しいパスワードの入力欄が表示される。
5. 新しいパスワードを設定すると完了表示になり、約1.5秒後に**ログインしたままダッシュボード**（`/dashboard`）へ移る。
   各アプリの利用条件（student のライセンス、admin は管理者のみ等）を満たさない場合は、ダッシュボードではなくログイン画面に戻る。

- 4 でリンクを確認するまでは、トークンを消費しない（メールソフトの事前読み込みでリンクが使用済みにならないようにするため）。
- パスワードを更新すると、**この端末以外のログインはすべてログアウト**される（パスワードが漏れていた場合に他人のログインを残さないため）。
- パスワードを更新すると、ログイン失敗の回数と**アカウントロックが解除**される（再設定リンクで本人確認が済んでいるため）。
- 完了後は再設定画面を開き直してもフォームは出ない。以後のパスワード変更は、プロフィールのパスワード変更（現在のパスワードの確認あり）で行う。

## パスワード再設定メールの依頼（`/forgot-password`）

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 見出し・説明 | 常時表示 | — |
| メールアドレス | 常時表示。必須 | — |
| 「送信する」ボタン | 常時表示。送信中は「送信中...」と表示して押せなくなる | 再設定メールを依頼し、完了表示に切り替わる |
| 「ログイン画面に戻る」 | 常時表示 | `/login` へ移る |

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 完了 | 「メールを確認してください」。登録済みの場合はメールを送った旨と、届かない場合はアドレスの誤りを確認するよう案内する。「ログイン画面に戻る」ボタン | 送信した場合（**未登録のアドレス・メール送信の失敗でも同じ表示**。登録の有無を外部から判別させないため。失敗はサーバーのログにのみ残る） |
| 入力漏れ | 「メールアドレスを入力してください。」 | メールアドレスが空のまま送信された場合（通常は入力欄の必須チェックで送信前に止まる） |

## 新しいパスワードの設定（`/update-password`）

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 案内 | 「パスワードの再設定」と説明、「手続きを開始する」ボタン | 再設定メールのリンクから開いた場合 |
| 確認中 | 「確認しています...」 | 画面を開いた直後（リンクを確認済みのセッションかを判定中） |
| 入力 | 「新しいパスワードの設定」、新しいパスワード欄・確認用欄、「パスワードを更新してログイン」ボタン、「ログイン画面に戻る」 | 「手続きを開始する」でリンクを確認できた場合。確認後に再読み込みした場合も表示される（確認から30分以内） |
| 完了 | 「パスワードを更新しました」、「ホームへ」ボタン（admin・coach はダッシュボード）。約1.5秒後に自動で `/dashboard` へ移る | 更新に成功した場合 |
| リンクを確認できない | 「再設定リンクを確認できませんでした」と説明、「再設定メールを送信する」ボタン（`/forgot-password` へ） | リンクが使用済み・期限切れの場合、リンクを経由せずにこの画面を開いた場合（**ログイン中でも同じ**。プロフィールのパスワード変更の「現在のパスワード」確認を迂回させないため）、確認から30分を過ぎて送信した場合 |

入力欄の挙動（プロフィールのパスワード変更・招待と共通）:

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 新しいパスワード | 必須。欄の下に条件（8文字以上・英字と数字を両方含む）を常に案内する | 英字と数字を両方含んでいない場合、入力中に案内が警告文に切り替わる |
| 新しいパスワード（確認用） | 必須 | 入力中、一致していれば「パスワードが一致しました」（緑）、不一致なら「パスワードが一致していません」（赤） |
| 「パスワードを更新してログイン」ボタン | 送信中は「更新中...」 | 8文字未満・英数混在でない・確認用と不一致のいずれかであれば送信せず、フォーム下にエラーを表示する |

| エラー（入力画面のフォーム下に表示） | 発生条件 |
|---|---|
| 「新しいパスワードは現在と同じものは使用できません。」 | 現在と同じパスワードを指定した場合 |
| 「このパスワードは過去にデータ漏洩の被害に遭った可能性があるため使用できません。…」 | 漏洩が確認されているパスワードの場合 |
| 「このパスワードは単純すぎるか推測されやすいため使用できません。…」 | 推測されやすいパスワードの場合 |
| 「通信エラーが発生しました。時間をおいて再度お試しください。」 | 通信に失敗した場合 |

## アプリごとの違い

| 項目 | admin | coach | student |
|---|---|---|---|
| 文言 | 表示言語（日本語／英語）に従う。右上で表示言語を切り替えられる | 英語 | 日本語 |
| メールアドレスの入力例 | `admin@example.com` | `coach@example.com` | `account@example.com` |
| 説明文の対象 | 管理アカウント・管理画面 | コーチアカウント | 登録済みのアカウント |
| 再設定メールの言語 | 日本語・英語の併記 | 英語 | 日本語 |

- 上表・本文の文言は student（日本語）のもの。admin・coach の文言は「実装参照」の文言ファイルを参照。
- 再設定メールには、再設定リンク（ボタンと URL）と有効期限（「30分間」）を記載する。有効期限は Supabase の
  Auth 設定「Email OTP Expiration」に従い、メールの表記はコード上の定数 `PASSWORD_RESET_LINK_TTL_MINUTES`（30分。Supabase の設定は dev・本番とも1800秒）で出している。
  Supabase 側の設定を変えた場合は、この定数も合わせて変える。

## 実装参照（エンジニア向け）

- 画面: `packages/lib/components/auth/ForgotPasswordForm.tsx`、`UpdatePasswordFlow.tsx`、`NewPasswordFields.tsx`、`AuthLayout.tsx`
  （各アプリの `app/(public)/forgot-password/page.tsx`・`update-password/page.tsx` は文言とアクションを渡すだけ）
- 受け口: `packages/lib/auth/callback.ts`（`createAuthCallbackHandler`。各アプリの `app/(public)/auth/callback/route.ts`）
- 処理: `packages/lib/auth/portalActions.ts`（`forgotPassword` / `verifyRecovery` / `hasRecoverySession` / `resetPassword`）、
  `packages/lib/auth/core.ts`（`forgotPasswordCore` / `verifyRecoveryCore` / `resetPasswordCore`）
- リンク確認済みの判定: `packages/lib/auth/recovery.ts`（確認したセッションに紐づく署名付き Cookie `pw_recovery`、30分）
- メール: `packages/lib/mail/actions/sendPasswordReset.ts`（有効期限の定数）、`packages/lib/mail/templates/PasswordResetEmailTemplate.ts`（外枠は `packages/lib/mail/layout/`）
  （言語別の文言・件名）。アプリごとの言語は各アプリの `*AuthAction.ts` の `resetMailLanguage`
- 文言: admin `apps/admin/messages/{ja,en}.json` の `forgotPassword` / `updatePassword` / `passwordFields` / `authErrors`、
  coach `apps/coach/constants/auth.ts`、student `apps/student/constants/auth.ts`（エラーの日本語は `packages/lib/auth/errors.ts`）
