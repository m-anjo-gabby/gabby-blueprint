# 招待からの本登録（3アプリ共通）

## 概要

- アプリ: `admin` / `coach` / `student`（画面・処理は共通。違いは文言の言語・見出し・呼び方のみ、下記「アプリごとの違い」）
- パス: `/auth/invite?token=<招待トークン>`
- 対象ロール: 管理者から招待された利用者（未登録）
- 目的: 招待メールのリンクからパスワードを設定して本登録し、そのままログインする。

## この画面に来る経路

- 管理アプリのユーザー管理（[admin/users.md](../admin/users.md)）で「招待メールを送信」または「招待メールを再送する」を実行すると、
  招待された利用者の種別に応じたアプリ（管理者→admin、コーチ→coach、生徒→student）の `/auth/invite?token=...` がメールで届く。

## 画面の構成・状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 確認中 | 「招待を確認しています...」 | 画面を開いた直後（招待トークンを確認中） |
| 入力 | 見出し（例: 「アカウント初期設定」）と、氏名・メールアドレスを含む案内、新しいパスワード欄・確認用欄、送信ボタン | 招待が未使用かつ有効期限内の場合 |
| 期限切れ | 「招待リンクの期限切れ」と「招待リンクの有効期限が切れています。管理者に再送を依頼してください。」、「ログイン画面に戻る」ボタン | 招待の有効期限を過ぎている場合 |
| 確認できない | 「招待リンクを確認できませんでした」と「この招待リンクは無効か、すでに本登録が完了しています。」、「ログイン画面に戻る」ボタン | トークンが無い・誤っている・本登録が済んでいる場合 |

- 新しいパスワード欄・確認用欄の挙動と送信前のチェックは、[パスワード再設定](password-reset.md) の「入力欄の挙動」と同じ。

## 送信結果

| 結果 | 表示・挙動 | 発生条件 |
|---|---|---|
| 成功 | アカウントを作成し、招待時の内容（所属顧客・ロール・契約があればライセンス）を登録した上で、そのままログインしてダッシュボードへ移る | — |
| アカウント作成の失敗 | フォーム下に「アカウントの作成に失敗しました。(<原因>)」 | 同じメールアドレスのアカウントが既にある場合など |
| ログインの失敗 | フォーム下にログイン画面と同じエラー（例: student で「有効なライセンスが見つかりません。…」） | 本登録後の自動ログインで拒否された場合。アカウントは作成済みのため、以後はログイン画面から利用する |
| 期限切れ・確認できない | フォーム下に上表の文言 | 入力中に期限が切れた・別の画面で本登録が済んだ場合 |

## アプリごとの違い

| 項目 | admin | coach | student |
|---|---|---|---|
| 文言 | 表示言語（日本語／英語）に従う。右上で表示言語を切り替えられる | 英語 | 日本語 |
| 見出し | 管理アカウント初期設定 | Coach account setup | アカウント初期設定 |
| 氏名が無い場合の呼び方 | 管理者 | Coach | 会員 |
| 送信ボタン | アカウントを有効化する | Activate account | 本登録を完了する |

- 招待リンクの有効期限は、招待メールの送信（再送を含む）から3日間。再送すると新しいリンクが発行され、期限も送信時点から3日間に付け直される
  （以前のリンクは使えなくなる）。メール本文にも同じ日数を記載する。

## 実装参照（エンジニア向け）

- 画面: `packages/lib/components/auth/InviteSetupFlow.tsx`、`NewPasswordFields.tsx`、`AuthLayout.tsx`
  （各アプリの `app/(public)/auth/invite/page.tsx` は文言とアクションを渡すだけ）
- 処理: `packages/lib/auth/portalActions.ts`（`verifyInvitation` / `acceptInvitation`）、
  `packages/lib/auth/core.ts`（`verifyInvitationCore` / `acceptInvitationCore`。画面へは氏名・メールアドレスだけを返す）
- 招待の作成・再送: `apps/admin/actions/adminUserAction.ts`（有効期限は `INVITATION_EXPIRES_DAYS`）、テーブル `com_t_invitation`
- 文言: admin `apps/admin/messages/{ja,en}.json` の `invite` / `passwordFields` / `authErrors`、
  coach `apps/coach/constants/auth.ts`、student `apps/student/constants/auth.ts`
