# ライブセッション通話画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/live-room/[sessionId]`
- 対象ロール: 生徒
- 目的: 担当コーチとのビデオ通話（Zoom Video SDKを使用）を行う画面。カメラ・マイクの
  事前確認、通話中の映像・チャット、通話終了までを1画面で完結させる。

## この画面に来る経路

- [ライブセッション・ホーム画面](./hub.md)の今後の予定カードにある「参加する」ボタンから
  遷移する（開始予定時刻の48時間前からボタン自体は表示されるが、実際に入室できるのは
  開始予定時刻の5分前から）。

## 画面の構成

この画面は3つの段階（フェーズ）を1つの画面として順に表示する。

1. **入室不可エラー表示** — まだ入室できない等の理由でアクセスできない場合、通話画面の代わりに
   理由メッセージのみを表示する
2. **参加前プレビュー画面** — 自分のカメラ映像・マイク入力レベルを確認し、マイク・カメラ・
   背景ぼかしのON/OFFを切り替えてから参加する
3. **通話中画面** — 相手（コーチ）の映像をメインに、自分の映像を右上に小さく表示し、画面共有
   受信時はそちらをメイン表示に切り替える。下部に操作ボタン、右側（PC）または下部（モバイル）に
   チャットパネルを表示する
4. **終了後画面** — 通話終了後に短いメッセージとダッシュボードへ戻るボタンのみを表示する

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| プレビュー映像 | 参加前プレビュー画面に常時表示 | カメラOFF時は映像の代わりにアイコンを表示する |
| マイク入力レベルバー | 参加前プレビュー画面に常時表示 | マイクの音量に応じてリアルタイムに伸縮する |
| マイク／カメラ／背景ぼかしトグル（プレビュー） | 参加前プレビュー画面 | それぞれON/OFFを切り替える。背景ぼかしはカメラOFF中は操作不可 |
| 「コーチの入室を待機しています」表示 | コーチがまだこのセッションのルームに入室していない場合 | 「セッションに参加する」ボタンが非活性になる。コーチの入室を検知すると自動的に活性化する |
| 「セッションに参加する」ボタン | プレビューが利用可能、かつコーチが入室済みの場合のみ活性 | 通話中画面へ切り替わり、実際にZoom Video SDKへ接続する |
| マイク／カメラON・OFFボタン（通話中） | 通話中画面下部に常時表示 | それぞれのデバイスの有効/無効を切り替える |
| 自分の映像の表示/非表示ボタン | 通話中画面下部に常時表示 | 右上に表示している自分のワイプ映像の表示・非表示を切り替える（相手には影響しない） |
| チャットの表示/非表示ボタン | 通話中画面下部に常時表示 | チャットパネルの表示・非表示を切り替える |
| 背景ぼかしボタン（通話中） | カメラONかつ端末が対応している場合のみ活性 | 自分の映像に背景ぼかしを適用/解除する |
| 全画面表示ボタン | 通話中画面ヘッダーに常時表示 | ブラウザのネイティブ全画面表示のON/OFFを切り替える |
| 退室ボタン（受話器アイコン） | 通話中画面下部に常時表示 | 確認ダイアログ（「セッションを終了しますか？」）の上で退室し、ダッシュボードへ遷移する |
| チャット入力欄・送信ボタン | 通話中画面に常時表示 | 入力したメッセージを相手に送信し、送受信内容を画面内チャット欄に表示する（送信したメッセージのみ通話記録として保存される） |
| 「相手の入室を待機しています」表示 | 通話には参加済みだが相手（コーチ）がまだ映像で接続していない場合 | 相手の映像枠にプレースホルダーを表示する |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 入室不可 | 「まだ入室できません。開始予定時刻の5分前から入室できます。」等のメッセージ | 開始予定時刻より大幅に早い、対象外のセッション、専属コーチマッチング未完了など、サーバー側の入室条件を満たさない場合 |
| カメラ・マイクアクセス失敗 | 「カメラ・マイクへのアクセスに失敗しました。ブラウザの権限設定をご確認ください。」 | ブラウザの権限が拒否されている等でプレビューが取得できない場合 |
| 残り時間の警告表示 | 通話中画面上部に「残り5分です。セッションは開始から30分で自動的に終了します。」の帯を表示 | 生徒の入室から25分経過した時点（本番既定値。開発環境では環境変数で短縮可能） |
| 自動終了 | 通話が終了し、終了後画面に遷移する | 生徒の入室から30分経過した場合、またはコーチ側が通話を終了させた場合 |
| 通話エラー | 通話中画面上部に赤色のエラーメッセージ帯を表示 | Zoom Video SDK側でエラーが発生した場合 |

## 関連する業務フロー仕様書

この画面自体は単一画面で完結する通話操作のため、複数画面をまたぐ業務フロー仕様書は無い。
セッションの予約・キャンセルの経緯は[ライブセッション・ホーム画面](./hub.md)および
[個別予約リクエスト・振替候補フロー](../../../../testing/e2e/specs/booking/individual-booking-and-reschedule.md)を参照。

## 実装参照（エンジニア向け）

- `apps/student/app/(app)/live-room/[sessionId]/page.tsx`
- `apps/student/app/(app)/live-room/[sessionId]/_components/LiveSessionRoomView.tsx`
- `apps/student/actions/videoSessionAction.ts`（`getMyLiveSessionRoomAccess`, `recordCallJoin`,
  `recordCallLeave`, `recordChatMessage`）
- `packages/lib/zoom/hooks/useZoomVideoSession.ts`, `useZoomDevicePreview.ts`（Zoom Video SDK
  との接続・映像/音声・画面共有の制御）
- `packages/lib/liveSessionRoom/hooks/useLiveSessionPresence.ts`（Supabase Realtime Presenceに
  よるコーチ・生徒の在室状態の共有。DB永続化は行わない）
- `packages/lib/liveSessionRoom/hooks/useLiveSessionRoomOrchestration.ts`（入退室ログの記録、
  25分警告・30分自動終了タイマー、チャットの永続化を担う共通フック）
- `packages/lib/liveSessionRoom/constants.ts`（警告25分・自動終了30分・入室許可5分前の既定値。
  検証用に各アプリの`.env.local`で分単位の上書きが可能）
- `packages/lib/liveSessionRoom/actions/liveSessionRoomActions.ts`
  （`getStudentLiveSessionRoomAccessCore`, `recordSessionCallJoinCore`,
  `recordSessionCallLeaveCore`, `recordSessionChatMessageCore`）
