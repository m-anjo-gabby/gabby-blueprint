# セッション結果画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/live-room/sessions/[sessionId]/result`（シェル画面。常設ナビを表示する）
- 対象ロール: 生徒
- 目的: 実施済みの個別ライブセッションについて、日時・コーチ・入退室ログ、コーチから出された
  宿題とその進捗、セッション中に実施したLive Sprintの実績、通話中チャットの履歴を確認する。

## この画面に来る経路

- [ライブセッション・ホーム画面](./hub.md)の「実施済み」タブのセッション行から遷移する。
- 宿題・フォローアップコメント投稿時の通知から遷移する。

## 画面の構成

1. **ヘッダー** — 画面タイトル「セッション結果」、戻るボタン（直前の画面へ戻る。直接開いた場合は
   ライブセッション・ホームへ）
2. **サマリー** — セッション日時、コーチ名・アイコン、入退室ログ（折りたたみ表示）
3. **宿題** — コーチからの宿題本文・添付ファイル、フォローアップコメント
4. **トレーニング** — このセッション中に実施したLive Sprintの実績一覧
5. **チャット履歴** — 通話中にやり取りしたチャットメッセージの一覧

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 入退室ログの折りたたみ | サマリー内に常時表示（件数をラベルに表示） | タップで入退室ログの一覧（誰が・いつ入室し、いつ退室したか）を開閉する |
| 宿題本文・添付ファイル | コーチから宿題が登録されている場合 | 添付ファイルは画像ならプレビュー表示、それ以外はファイル名リンクとして新しいタブで開ける。宿題が無い場合は「まだ宿題はありません。」と表示 |
| フォローアップコメント | コーチが宿題に対してコメントを残している場合 | 日時・本文・添付ファイルを表示（生徒からの投稿・返信はできない） |
| Live Sprint実績一覧 | このセッションで実施されたLive Sprintがある場合 | 教材名・実施日時・平均スコア（5点満点）を表示。無い場合は「このセッションでは実施されませんでした。」 |
| チャット履歴 | 通話中にメッセージが送信されていた場合 | 自分の発言は右寄せ、コーチの発言は左寄せで表示。無い場合は「通話中のチャットメッセージはありません。」 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（画面遷移直後） | 見出し・区画見出し（宿題・トレーニング・チャット履歴）は本物、日時・コーチ・各区画の本文を骨組みで表示 | `live-room/loading.tsx`（ハブとパスで出し分け） |
| 存在しないセッション | 404ページ | 指定した`sessionId`のセッション結果が取得できない場合（他人のセッション、未実施のセッション等） |
| 添付ファイル読み込み中／失敗 | ローディングアイコン、または「添付ファイルの読み込みに失敗しました」 | 添付ファイルの署名付きURL取得中、または取得に失敗した場合 |

## 補足（コーチ側画面との違い）

コーチ向けの同等画面（`apps/coach`側のセッション結果画面）とは異なり、生徒側では宿題本文・
フォローアップコメントの投稿や添付ファイルのアップロードはできない（DBのRLSでもコーチのみに
書き込みが制限されている）。生徒の操作で更新されるものは無いが、宿題がある回はこの画面を開くと
「宿題を開いた日時」が記録され、コーチの画面に「見た」ことが出る（`mark_session_homework_viewed`。page.tsx でサーバー側から呼ぶ）。

## 関連する業務フロー仕様書

この画面は個別セッション実施後の閲覧専用画面であり、複数画面をまたぐ業務フローは特に無い。
セッションの実施結果ステータス（実施済み・早期終了・未参加等）が確定するまでの経緯は
[ライブセッション・ホーム画面](./hub.md)を参照。
