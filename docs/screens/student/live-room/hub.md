# ライブセッション・ホーム（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/live-room`
- 対象ロール: 生徒
- 目的: 専属コーチとの個別ライブセッションについて、今後の予定・実施済み・変更履歴の確認、
  予約リクエストの取り下げ、振替候補への応答を行う。個別セッションに関する操作の起点となる画面。

## この画面に来る経路

- 画面下部のボトムタブ（モバイル）／左サイドナビ（PC）の「ライブセッション」タブから遷移する（全生徒に表示）。
- [カレンダー](../calendar.md)・[専属コーチを探す](../coach-matching.md)の戻るボタンから戻ってくる。
- 実施済みセッションの各カードから[セッション結果画面](./session-result.md)へ、今後の予定の
  「参加する」ボタンから[通話画面](./call-room.md)へ、それぞれ遷移する。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「カレンダー」「専属コーチを探す」ボタン。契約（チケット）を複数
   保持している生徒のみ、対象契約を切り替えるセレクトボックスが表示される（現在有効な契約が
   あれば既定で選択される。無ければ最新の過去契約が選択される）
2. **振替候補バナー**（コーチから振替候補が届いている場合のみ、リスト最上部に表示）— タップで
   振替候補ダイアログを開く
3. **タブ切り替え** — 「今後の予定」「実施済み」「変更履歴」の3タブ（「今後の予定」タブは
   選択中の契約が現在有効な契約で、かつ今後の予定が1件以上ある場合のみ表示される。無い場合は
   自動的に「実施済み」タブが表示される）
4. **セッションキャンセルダイアログ**・**予約リクエストダイアログ**・**振替候補ダイアログ**
   （いずれもタブ内の操作から開く）

## ライブセッション付き契約が無い場合（紹介画面）

ライブセッション付き契約を一度も保持したことがない生徒（アプリのみ契約）には、ハブの代わりに
ライブセッション紹介画面を表示する（過去に契約があった生徒は履歴確認のためハブを表示する）。

| 要素 | 内容 | 操作した時の挙動 |
|---|---|---|
| ヒーロー | キャッチコピーとプラン概要 | — |
| 特長 | 専属コーチ・自主トレとの連携・アプリで完結、の3項目 | — |
| ご利用の流れ | 「コーチを選ぶ」「予約する」「入室する」の3ステップ | — |
| 「プラン・料金を見る」ボタン | 常時 | 公式サイトの料金ページ（`https://gabbyacademy.com/price`）を別タブで開く |

文言・導線は `apps/student/constants/liveSessionIntro.ts` で一元管理する（「担当者に相談」等の
導線追加もこのファイルで行う）。

## 表示要素・操作


| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「カレンダー」「専属コーチを探す」ボタン | 常時（ヘッダー内） | それぞれ `/calendar`・`/coach-matching` へ遷移 |
| 契約セレクトボックス | 契約（チケット）を2件以上持つ生徒のみ | 選択した契約の実施済み・変更履歴を再取得して切り替える |
| 振替候補バナー（「◯◯コーチから振替候補が届いています」） | 自分宛の未回答の振替候補提案がある場合 | タップで振替候補ダイアログを開く |
| 「未予約のセッションがあります」バナー | 選択中の契約に未消化のチケット枠がある場合、「今後の予定」タブ内に表示 | タップで予約リクエストダイアログを開く（[calendar.md](../calendar.md)の予約リクエストダイアログと同一仕様） |
| 予約リクエストの行（「コーチの承認待ち」＋希望日時＋「取り下げる」ボタン） | 自分が送信した個別予約リクエストのうち、コーチ未応答（pending）のもの | 「取り下げる」を押すとリクエストを取り下げる。取り下げ後はコーチ側も応答できなくなる |
| 今後の予定カード | 「今後の予定」タブ内、実施予定（scheduled）の個別セッション | コーチ名・開始日時を表示 |
| カード内「参加する」ボタン | 開始予定時刻の48時間前以降のセッションに表示 | [通話画面](./call-room.md)（`/live-room/[sessionId]`）へ遷移する。実際に入室できるのは開始予定時刻の5分前からで、それより早い場合は通話画面側でエラー表示になる（下記「状態」参照） |
| カード内「キャンセル」ボタン | 今後の予定カードに常時表示 | セッションキャンセルダイアログを開く（[calendar.md](../calendar.md)のセッションキャンセルダイアログと同一仕様。代替候補の提案も可能） |
| 実施済みセッションの行 | 「実施済み」タブ内、実施結果が確定したセッション | タップで[セッション結果画面](./session-result.md)（`/live-room/sessions/[sessionId]/result`）へ遷移する。右側にステータスバッジ（実施済み／早期終了／未参加 等）を表示 |
| 「さらにn件を表示」ボタン | 実施済み・変更履歴それぞれ、表示中の件数を超える履歴がある場合（初期表示は10件） | 押すたびに10件ずつ追加表示する。契約を切り替えると表示件数はリセットされる |
| 変更履歴の行 | 「変更履歴」タブ内、自分自身またはコーチ都合でキャンセルされた過去セッション | ステータスバッジとキャンセル理由（入力されていれば）を表示。タップ操作はない |

## 振替候補ダイアログ

- コーチから届いた振替候補（最大3件）を一覧表示し、候補ごとに日時と「承認」ボタンを表示する
- いずれか1件を承認すると新しいセッションが作成され、ダイアログが閉じて一覧が更新される
- 「いずれも却下する」ボタンで候補をまとめて却下できる（この場合、コーチへの通知は送られない）
- 表示されている候補が期限切れ（提案から24時間経過）だった場合、承認・却下ともにエラーになる

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 実施済み／変更履歴の読み込み中 | タブ内にスピナーを表示 | 契約を切り替えた直後、その契約の履歴データ取得中 |
| 実施済みが空 | 「実施済みのセッションはありません」 | 選択中の契約に実施済みセッションが無い場合 |
| 変更履歴が空 | 「変更履歴はありません」 | 選択中の契約に自分・コーチ都合のキャンセルが無い場合 |
| 予約リクエストの取り下げ中 | 「取り下げる」ボタンがスピナー表示になり非活性化 | 取り下げ処理の実行中 |
| 通話画面への早期アクセス | 通話画面側で「まだ入室できません。開始予定時刻の5分前から入室できます」等のメッセージ | ホーム画面の「参加する」ボタン（開始48時間前から表示）を、実際に入室可能になる5分前より早く押した場合 |
