# 専属コーチを探す（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/coach-matching`
- 対象ロール: 生徒（ライブセッション付きプランの契約者のみ利用可能）
- 目的: 週あたりのセッション枠（コマ）ごとに、担当してほしいコーチへマッチングをリクエストする。
  コーチが承認すると、契約期間分のセッションが自動で予約される。

## この画面に来る経路

- 承認待ちのコマの確認・取り下げは、[ライブセッション・ホーム](./live-room/hub.md)の「契約の状況」のコマの「確認・取り下げ」から来る（ホームの回答待ちの案内からライブセッション・ホームへ進める）。
- [ライブセッション・ホーム](./live-room/hub.md)（`/live-room`）の「専属コーチを探す」ボタンから遷移する
  （アプリシェルでは「ライブセッション」タブがアクティブになる）。

## 画面の構成

1. **ヘッダー** — 画面タイトル、ライブセッション・ホームへ戻るボタン、セッション枠数の案内文。有効な契約が2件以上なら、その下に契約の切替
2. **セッション枠の状況** — 契約上の週あたりコマ数ぶんの状況カード（マッチング済み／承認待ち／
   未マッチング）
3. **コーチを選ぶ** — 検索・絞り込みフィルター、フィルター直下の件数行（絞り込み中は「条件に合うコーチ　全N人中 M人」、
   それ以外は「リクエストできるコーチ　N人」）、コーチ一覧（カード形式。モバイルは1列、PC幅（lg以上）は2列）
4. **リクエストダイアログ**（コーチカードから開く） — 空き時間カレンダーから希望日時を選び、
   リクエストを送信する

## 対象の契約

- マッチングは契約のライセンス（チケット）単位。申請できるのは有効な契約（終了日前。開始前の次の契約を含む）。
- 有効な契約を2件以上持つ生徒（現在の契約＋継続用の次の契約）には、ヘッダーの下に契約の切替（「現在の契約：期間」「次の契約：期間」）を表示する。
  既定は現在の契約。切替はURLのクエリ（`/coach-matching?contract=<ticket_id>`）で行い、選んだ契約の枠の状況をサーバーで取り直す（切替中は内容を半透明にする）。
  切替の部品はライブセッション・ホームと共通（`components/session/LiveContractSelect.tsx`）。
- 次の契約で申請・承認されると、次の契約の期間内にその契約の回数分のセッションが予約される（現在の契約の枠・セッションは変わらない）。

## 一覧に出るコーチ

- 有効なコーチプロフィールを持つコーチが対象。
- デモユーザー（ロール `demo_user`）のコーチは、本番検証・顧客向けプレゼン用のため、通常の生徒には
  表示されず、リクエストもできない（コーチIDを直接指定した送信も「この操作を行う権限がありません。」で拒否される）。
- 生徒自身がデモユーザーの場合は、デモコーチを含む全コーチが対象になる。

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| セッション枠カード | 契約の週あたりコマ数ぶん表示。各枠の状態バッジ（「マッチング済み」緑／「承認待ち」黄／「未マッチング」グレー）、マッチング済み・承認待ちの場合は担当コーチ名・曜日・時間帯を表示 | 表示のみ（キャンセルボタンは別項参照） |
| 前回否認理由 | 未マッチング状態の枠で、直前に否認された履歴がある場合 | 「前回否認理由: 〜」を赤系の注記で表示 |
| コーチの回答期限 | 承認待ち状態の枠 | 「コーチの回答期限: <日時>（期限までに回答が無い場合、リクエストは無効になります）」を表示（申請から24時間） |
| 期限切れの注記 | 未マッチング状態の枠で、直前の申請が回答期限切れだった場合 | 「前回のリクエストは、コーチの回答期限（24時間）を過ぎたため無効になりました。別のコーチや時間帯でもリクエストできます。」を黄系の注記で表示 |
| 「リクエストを取り下げる」ボタン | 承認待ち状態の枠に表示（送信した直後から使える） | 確認ダイアログ（「リクエストを取り下げますか？」。コーチに通知される旨と、取り下げ後に別のコーチ・時間でリクエストし直せる旨）の上で取り下げ、枠は未マッチング状態に戻る。コーチにはアプリ内で通知される（メールなし）。既にコーチが対応済みの場合は「このリクエストは既にコーチが対応済みです…」 |
| コーチ名検索欄 | 常時表示（未マッチング枠が1つ以上ある場合） | 入力した文字列を含む名前のコーチのみに絞り込む |
| 曜日フィルター（複数選択可） | 同上 | 選択した曜日に対応可能時間を持つコーチのみに絞り込む |
| 時間帯フィルター（複数選択可） | 同上 | 選択した大まかな時間帯に該当する対応可能時間を持つコーチのみに絞り込む |
| 「リセット」ボタン | 何らかのフィルターが設定されている場合のみ表示 | 検索条件・曜日・時間帯の選択をすべて解除する |
| コーチカード | 未マッチングの枠が1つ以上ある場合に一覧表示。アイコン、名前、国旗・国名、指導歴、総合評価（星〔0.5刻み〕・平均点・「n件の評価」。新しく作成したコーチには初期値の評価1件〔3項目とも4〕が自動で入り、件数・平均に含める。評価が無いコーチは出さない）、自己紹介文（省略表示）、対応可能時間帯のチップ（フィルター条件に一致するものが優先的に先頭表示）。曜日・時間帯で絞り込み中は、条件に一致する枠が多いコーチほど上に並ぶ | — |
| アイコン・名前の区画（右端に「プロフィール」の目印。モバイルはアイコンのみ） | 各コーチカードの上部 | コーチの詳細プロフィール（総合評価・学歴・資格・指導歴・職務経験・自己紹介・紹介動画）をダイアログで表示 |
| 枠の状況バッジ | 自分のセッション枠でそのコーチが承認待ち・担当中の場合 | 「承認待ち（nコマ目）」黄／「担当中（nコマ目）」緑を表示（表示のみ。別の枠として同じコーチへリクエストすることは可能） |
| 「カレンダーからリクエストする」ボタン | コーチに対応可能時間が1件以上ある場合のみ活性 | リクエストダイアログを開く |
| コーチ一覧が空の場合 | リクエスト可能なコーチが1人もいない場合 | 「現在リクエスト可能なコーチがいません。」 |
| フィルター結果が0件の場合 | 検索・絞り込み条件に一致するコーチがいない場合 | 「条件に合うコーチが見つかりませんでした／条件を変更してお試しください」と「条件をリセット」ボタン（押すと検索・曜日・時間帯の選択をすべて解除） |
| 全枠マッチング完了時の表示 | 未マッチングの枠が無い場合 | 「すべての枠のマッチングが完了しています」と表示し、検索フィルター・コーチ一覧は表示されない |

## リクエストダイアログ

- 見出し（固定）・本文（スクロール）・下部（回答期限の案内と「キャンセル」「リクエストを送信」。固定）の3段。中身が増えても閉じる・送信のボタンは常に画面内に見える。
  モバイル（sm未満）は画面いっぱいに表示し、sm以上は中央に浮かせる（高さは画面の9割まで）。カレンダーは本文の中でさらにスクロールする（モバイルは画面の約4割の高さ、sm以上は360px）。

- コーチの対応可能時間（UTCで保存）を、25分セッションの開始候補として週間カレンダー形式（曜日×30分刻み）で
  表示する。時刻は生徒自身のタイムゾーンに変換して表示される。
- 申請は生徒の現地の曜日・時刻と、申請時の生徒のタイムゾーン（プロフィールの設定。サーバー側で取得）で保存する
  （`com_t_matching_request.requested_timezone`）。承認されると契約期間中の全回がこの時刻で予約され、コーチ側の
  夏時間の切り替えをまたいでも生徒側の時刻は変わらない。
- ダイアログを開いた時点（コマを切り替えた時点）で、候補ごとに契約期間内に予約できる回数をサーバーで数え、
  セルを次の3種類で表示する（取得中のセルは骨組みの色で選べない）。判定の詳細は業務フロー仕様書の「予約できる回数の判定」。
  - 〇: 契約期間内の全ての回を予約できる
  - △（黄）: 一部の回がコーチまたは自分の他の予定（予約済みのセッション・定期スケジュール・コーチの休み・他の方や自分の承認待ちの申請）と
    重なる、または契約の残り期間に入りきらないが、予約できる回数が基準の割合以上。重なる回は未予約になり、コーチと個別に日時を調整する
  - ×: 予約できる回数が基準の割合に満たない（受付終了）。他の方が同じコーチの同じ時間帯を申請中（承認待ち）の場合も、その回は予約できない回と数える
- 凡例: カレンダーの上に、セルと同じ見た目の記号を1行で並べる（「〇 全回予約可」「△ 一部は個別調整」「× 受付終了」）。
  補足（各記号の意味）は凡例の横の ⓘ（「記号の説明」）を押したときだけ吹き出しで表示する。
- セルを選択すると、「毎週◯曜日 開始時刻〜終了時刻」の確定内容と、初回のライブセッション予定日
  （現在時刻から実時間で24時間以上先、かつ選択中の契約の開始日時以降となる、選択した曜日・時刻の直近の回）が表示される。
  全ての回を予約できる枠は「このコマのN回をすべて予約します。」を表示する。
- 未予約の回が残る枠を選ぶと、黄色の注意欄に「N回のうちM回を予約します。残りK回はコーチと個別に日時を調整します。」と
  「詳しく」を表示する。「詳しく」を押すと内訳（他の予定と重なる回・契約の残り期間に入りきらない回）と、成立後にライブセッションの
  ページから未予約の回の日時をリクエストできる旨を開く。「未予約の回を個別に調整することを了承しました」に印を付けるまで送信ボタンは押せない。
- 下部の送信ボタンの上に「コーチは24時間以内に回答します（期限を過ぎるとリクエストは無効になります）。」を常に表示する。
- リクエスト対象の枠（コマ）が複数ある場合はプルダウンで選択、1つしかない場合は自動選択される。
- 送信するとサーバーで予約できる回数を数え直し（基準の割合未満なら「この時間帯は、契約期間内に予約できる回数が足りません…」）、
  当該枠は「承認待ち」状態になり、コーチの承認を待つ（即時確定ではない）。承認までにコーチの予定が埋まった場合、承認時の回数で
  成立するか、基準を下回ればコーチが否認する。成立の通知には予約できた回数と、未予約の回が残る場合の案内が入る。
