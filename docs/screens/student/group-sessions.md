# グループセッション一覧（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/group-sessions`
- 対象ロール: 生徒（全プラン。アプリのみの契約の生徒も含む）
- 目的: グループセッションをシリーズ（企画。例: 「10月の発音グループセッション」）ごとに一覧し、参加したい回を参加予定にする。
  参加登録した過去のセッションも確認できる。アプリのみの契約の生徒はカレンダーを見られないため、グループセッションを一覧できる唯一の画面。

## この画面に来る経路

- ホームのグループセッションのカードの見出しにある「一覧を見る」（[dashboard.md](./dashboard.md)）。
- イベントの詳細（ホーム・カレンダーのボトムシート）の「このシリーズの回をすべて見る」。`?series=<series_id>` 付きで開き、
  該当シリーズの位置まで移動して枠を強調する（ほかのシリーズもそのまま表示する）。
- ナビには項目を持たず、表示中はナビの「ホーム」をアクティブにする（`constants/navigation.ts` のホームの `matchPaths`）。

## 画面の構成

1. **ヘッダー** — 戻るボタン（直前の画面へ。履歴が無い場合はホームへ）、画面タイトル「グループセッション」、説明文
   （「Gabbyのプロコーチから直接学べる、ご契約中の方限定の無料セッションです。参加したい回を「参加予定」にすると、参加用のリンクが表示されます。」）
2. **タブ**（上部に固定）— 「これから」「過去のセッション」。表示中のタブは URL の `?tab=past`（「これから」はクエリなし）
3. **これから** — シリーズごとのカード（次に始まる回が早いシリーズから順）と、単発のイベントのカード
4. **過去のセッション** — 参加登録した終了済みの回の一覧
5. **イベントの詳細**（ボトムシート。回の行を押すと開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| シリーズのカード | 開催前・開催中の回（今後120日以内に始まるもの）が1つ以上あるシリーズ。シリーズ名・説明（長い場合は3行まで表示し「続きを読む」／「閉じる」で開閉）・回の一覧 | — |
| 「すべて参加予定にする（n回）」 | 参加確認ありの回が2回以上あるシリーズで、終了していない未登録の回がある場合。n はその回数 | 対象の回をまとめて参加登録し（`joinCalendarEventSeries`）、「n回を参加予定にしました」と表示する。登録済みの回はそのまま。まとめての取り消しは無い（取り消しは回ごとに詳細から） |
| 「すべての回が参加予定です」 | 上と同じ条件のシリーズで、終了していない回がすべて登録済みの場合 | — |
| 回の行 | 日時（利用者のタイムゾーン）・開催状況（「開催中」「今日・あとn時間」「明日」）・内容（タイトル）・担当コーチ（「コーチ：…」。未設定なら出さない） | 行（日時・内容）を押すとイベントの詳細を開く |
| 「参加予定にする」 | 参加確認ありで未登録の回 | 参加登録し、「参加予定」ラベルと「参加する」に切り替わる |
| 「参加予定」ラベル・「参加する」 | 参加登録済みの回。「参加する」は参加URLがある場合（参加確認なしの回は参加URLがあれば常に表示） | 「参加する」で参加URLを新しいタブで開く |
| その他のイベント | シリーズに属さない（単発の）開催前・開催中の回。シリーズが1つも無い場合は見出しを「グループセッション」にする。「すべて参加予定にする」は出さない | 回の行の操作は上と同じ |
| 過去のセッション | 直近半年（183日）に参加登録した終了済みの回（新しい順）。日時・シリーズ名・内容・担当コーチ。下に「参加予定にしていた回を表示しています（直近半年）。」（アプリは参加登録の記録だけを持ち、実際の参加の有無は分からないため） | 行を押すとイベントの詳細を開く |
| イベントの詳細 | カレンダー・ホームと同じ詳細（[calendar.md](./calendar.md)）。この画面では「このシリーズの回をすべて見る」は出さない | 参加取消・お使いのカレンダーに追加・アナウンスの確認 |

- 終了の判定は終了時刻（無い場合は開始から1時間）。表示中に終了した回はその場で「これから」から外す。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（画面遷移直後） | ヘッダー・タブは本物（タブは「これから」を選択した形）、シリーズのカード2枚分を骨組みで表示 | `group-sessions/loading.tsx`、外側の読み込み中（`ShellRouteSkeleton`） |
| 開催予定なし | 「開催予定のグループセッションはありません」「次回の開催は、決まり次第ここでお知らせします。」 | 「これから」に出す回が無い場合 |
| 過去のセッションなし | 「参加登録した過去のセッションはありません」「直近半年に参加予定にしたセッションが、ここに表示されます。」 | 「過去のセッション」に出す回が無い場合 |
