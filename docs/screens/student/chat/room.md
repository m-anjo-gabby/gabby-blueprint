# チャットルーム（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/chat/[roomId]`
- 対象ロール: 生徒
- 目的: 特定のコーチ・運営との個別チャット、またはグループチャットでメッセージ・添付ファイルの
  やり取りを行う。
- アプリシェル内の画面。PC（`lg` 以上）ではチャット一覧（[list.md](list.md)）の右ペインに表示し、
  左の一覧とサイドナビは表示したまま。`lg` 未満ではルームだけを表示する。スマートフォン（`md` 未満）では
  入力欄の縦幅を確保するため、ルームを開いている間は画面上部のヘッダーと下部のボトムタブを表示しない。

## この画面に来る経路

- チャット一覧（`/chat`）の各ルーム行から開く。
- 通知（`CHAT_NEW_MESSAGE`）の`link_path`から直接遷移してくる場合がある。

## 画面の構成

1. **ヘッダー** — チャット一覧に戻るボタン（`lg` 未満のみ）、相手（またはグループ）のアイコン・名前・種別
2. **メッセージタイムライン** — 時系列のメッセージ一覧（自分のメッセージは右寄せ・淡い青、相手の
   メッセージは左寄せ・淡いグレー。ヘッダー・タイムライン・入力欄は同じ白い背景で一体に見せる。
   ヘッダーの下の区切り線はメッセージがヘッダーの下に隠れている間だけ、入力欄の上の区切り線は過去のメッセージを
   見ている間だけ表示）
3. **メッセージ入力欄** — テキスト入力、ファイル添付、送信ボタン（参加者でない場合は非表示）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| チャット一覧に戻るボタン | `lg` 未満のみ表示 | チャット一覧（`/chat`）へ戻る |
| ヘッダーのアイコン・名前 | グループの場合はグループアイコンとルーム名、メンバー名の一覧。個別チャットの場合は相手のアイコン・名前・種別（「運営」「生徒」「コーチ」） | — |
| メッセージ本文 | テキストメッセージがある場合表示。文中のURLはリンクとして認識される | リンクをタップすると別タブで開く |
| 添付ファイル（画像） | 添付が画像形式の場合、サムネイル表示 | タップすると原寸画像を別タブで開く |
| 添付ファイル（画像以外） | ファイル名・サイズを表示 | タップすると別タブでダウンロード用URLを開く |
| 削除済みメッセージ | 「このメッセージは削除されました」と斜体表示 | 操作不可 |
| 日時ヘッダー | 直前のメッセージと送信者・時間帯が異なる場合に表示（同一送信者の連続投稿はまとめられる） | — |
| 「ここから未読」の区切り線 | ルームを開いた時点で未読メッセージがある場合、最初の未読メッセージの上に表示 | 開いた直後はこの区切り線の位置から表示する（未読が無い場合は最新メッセージの位置から表示） |
| 既読表示 | 1対1のルームのみ。自分の発言のうち、相手が既に読んだ最新の1件の下に「既読」と表示する（それより後の未読の発言には出さない）。グループでは表示しない | 相手がルームを開いて既読にすると、リアルタイムで表示位置が進む |
| 「最新のメッセージへ」ボタン | 最新メッセージから離れて過去のメッセージを見ている間、入力欄の上に表示。その間に届いた新着がある場合は「新着メッセージ N件」と表示 | タップすると最新メッセージまでスクロールする |
| メッセージ入力欄 | 参加者本人のみ表示。改行・折り返しに合わせて高さが伸び、PCは10行、スマートフォンは5行を超えると入力欄の中でスクロールする | PCはEnterキー（Shift+Enterは改行、日本語入力の変換確定のEnterでは送信しない）または送信ボタンで送信。スマートフォン等のタッチ端末ではEnterは改行になり、送信ボタンで送信する。空欄かつ添付なしの場合は送信不可 |
| 下書きの保持 | 入力中の本文・送信前の添付はルームごとに保持する | 別のルームを開いてから戻っても入力内容が残る（ページの再読み込みで消える） |
| 添付ボタン（クリップアイコン） | 常時表示（参加者のみ） | ファイル選択ダイアログを開く。複数選択可。1ファイル10MBを超える場合はエラー通知を表示してスキップ |
| 添付の取り消し（送信前） | 添付済みファイルがある場合、各ファイルに×ボタンを表示 | タップすると送信待ちリストから除去 |
| 古いメッセージの自動読み込み | メッセージ一覧の先頭までスクロールした場合 | それ以前のメッセージを追加取得し、スクロール位置を維持したまま先頭に追加表示 |
| 新着メッセージの自動反映 | 相手または自分が新しいメッセージを送信した場合（リアルタイム） | タイムラインに即座に追加する。最新メッセージ付近を表示している場合は最下部へ自動スクロールし、過去のメッセージを見ている場合はスクロールせず「新着メッセージ N件」ボタンを表示する |
| 既読 | 表示中のルームのメッセージは既読にする | ブラウザのタブが裏にある間に届いたメッセージは、タブを表に戻した時点で既読にする |
| 参加者ではない場合の表示 | ログインユーザーがこのルームのメンバーでない場合 | 入力欄の代わりに「このルームの参加者ではないため、メッセージを送信できません。」と表示（閲覧のみ） |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 存在しないルーム | 404（Not Found）ページ | 指定された`roomId`のルームが取得できない場合 |
| 読み込み中 | チャットの骨組み（ヘッダーと吹き出しの形） | ルームを開いてから表示されるまでの間 |
| 添付アップロード中 | 添付ボタンがスピナー表示になる | ファイル選択後、アップロード処理中 |
| 送信中 | 送信ボタンがスピナー表示になる | メッセージ送信処理中 |
| 添付読み込み中 | 添付エリアにスピナーを表示 | メッセージ内の添付ファイルのダウンロードURLを取得中 |
| 添付読み込み失敗 | 「添付ファイルの読み込みに失敗しました」 | ダウンロードURLの取得に失敗した場合 |
