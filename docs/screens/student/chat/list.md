# チャット一覧（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/chat`
- 対象ロール: 生徒
- 目的: 担当コーチや運営との個別チャット、グループチャットの一覧を確認し、各ルームを開く。
  担当コーチとのルームは、マッチング成立時に自動で開設され、コーチからの挨拶メッセージが届く
  （[admin/chat/list.md](../../admin/chat/list.md#マッチング成立時の自動開設)参照）。
- チャットは2ペイン表示。PC（`lg` 以上）では左にルーム一覧、右に選択中のルーム
  （[room.md](room.md)）を並べる。`lg` 未満（スマートフォン・タブレット）では一覧だけを表示し、
  ルームを選ぶとルーム画面に切り替わる。

## この画面に来る経路

- 画面下部のボトムタブ（モバイル）／左サイドナビ（PC）の「チャット」タブ（ライブセッション付き契約の有効なチケットを保持している
  場合のみ表示）から遷移する。
- チャットルーム画面（`/chat/[roomId]`）の「チャット一覧に戻る」ボタンから戻ってくる（`lg` 未満のみ）。

## 画面の構成

1. **左ペイン（ルーム一覧）**
   1. 見出し「チャット」
   2. 検索欄 — 「名前・メッセージを検索」
   3. 絞り込み — 「すべて」「未読」の切り替え
   4. ルーム一覧 — 参加しているルームを最新メッセージの新しい順にリスト表示
2. **右ペイン（PCのみ）** — ルーム未選択時は「チャットを選択してください」の案内。ルームを選ぶと
   チャットルーム（[room.md](room.md)）を表示する

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | 入力した文字を、ルーム名・参加者名・最新メッセージの本文に部分一致で絞り込む（大文字小文字を区別しない）。×ボタンで入力をクリア |
| 「すべて」「未読」 | 常時表示。「未読」には未読のあるルーム数を赤いバッジで表示 | 「未読」を選ぶと未読メッセージのあるルームだけを表示する（開いているルームは既読になっても表示し続ける） |
| ルームの行 | 参加中の各ルームにつき1行。相手の名前（グループの場合はルーム名）、アイコン、種別ラベル（「運営」「生徒」「コーチ」または「グループ」）、最新メッセージのプレビュー、最終メッセージ時刻、未読件数バッジを表示。未読のある行は名前を太字で表示。PCでは開いているルームの行を淡い青で強調する | タップすると `/chat/[roomId]` を開く（PCは右ペインに表示、`lg` 未満はルーム画面へ切り替え） |
| 最新メッセージのプレビュー | 添付画像のみの場合「📷 写真」、ファイル添付のみの場合「📎 ファイル」、削除済みメッセージの場合「このメッセージは削除されました」、メッセージが1件も無い場合「まだメッセージはありません」と表示 | — |
| 未読件数バッジ | 未読メッセージが1件以上ある場合のみ表示。99件超は「99+」と表示 | — |
| 一覧のリアルタイム更新 | この画面を開いている間、参加中のルームに新着メッセージが届いた場合 | そのルームを一覧の先頭へ移動し、プレビュー・時刻を更新する。開いていないルームは未読件数を1増やす |
| キーボード操作（PC） | 常時 | Alt + ↑／↓ で、表示中の一覧の前後のルームを開く |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| ルームが1件も無い | 「チャットルームはありません／担当コーチや運営とのチャットが開始されると、ここに表示されます。」 | 参加しているチャットルームが存在しない場合 |
| 検索・絞り込みで0件 | 「該当するチャットはありません」 | 検索語または「未読」の絞り込みに該当するルームが無い場合 |
| ルーム未選択（PCの右ペイン） | 「チャットを選択してください／左の一覧から、担当コーチや運営とのチャットを開けます。」 | PCで `/chat` を開いている場合 |
| 読み込み中 | 右ペインにチャットの骨組み（吹き出しの形）を表示 | ルームを切り替えてから表示されるまでの間 |
