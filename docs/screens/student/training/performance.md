# トレーニング記録（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/performance`
- 対象ロール: 生徒
- 目的: 単語帳ドリルとスプリントを合わせた月間のトレーニング実績（トレーニング日数・総発話回数・
  単語/フレーズ数・スプリント本数/回答数）を確認し、日別の実施内容や各履歴画面への入口とする。

## この画面に来る経路

- トレーニングタブ内の切り替え（教材｜お気に入り｜トレーニング記録）、またはダッシュボードの「今週のトレーニング」の「記録を見る」リンクから
  遷移する。単語帳履歴・スプリント履歴の各画面からも、戻るボタンで遷移してくる（履歴側で表示していた月を引き継ぐ）。
- アプリシェル内の画面で、共通ナビゲーションは「トレーニング」タブがアクティブになる。

## 画面の構成

1. **ヘッダー** — 見出し「トレーニング」とトレーニングタブ内の切り替え（画面名は選択中の切り替えタブで示し、「トレーニング記録」の見出しは読み上げ用だけで見た目には出さない）、月切替（前月・翌月・今月に戻る）。
   月切替はスクロールしても画面上部に固定表示される
2. **○月のまとめ** — 当月のトレーニング日数、発話回数（単語帳・スプリント合算）
3. **トレーニング別** — 単語帳（単語数・フレーズ数）、スプリント（実施回数・回答数）のカード。
   それぞれの履歴画面への入口を兼ねる
4. **実施カレンダー** — 曜日の列を揃えた当月のカレンダー。実施した日を塗りつぶし、
   タップするとその日の内訳をポップオーバー表示する

PC（lg以上）では 2・3 を左、4 を右に並べる。モバイルでは上から順に縦に並べる。

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 月切替の矢印（前月・翌月） | 常時表示 | 対象月を切り替えて集計を再取得する |
| 「今月に戻る」ボタン | 当月以外の月を表示している場合のみ | 当月の表示に戻す |
| トレーニング日数 | 常時表示 | 当月中、単語ドリルまたはスプリントを1回以上実施した日数を表示 |
| 発話回数 | 常時表示 | 単語ドリル・スプリントいずれかで発話評価を行った回数の合計を表示 |
| 「単語帳」カード | 常時表示 | タップで[単語帳の履歴画面](./word-history.md)（該当月指定）へ遷移する |
| 「スプリント」カード | 常時表示。「※ 回答数にドリルの回答は含みません」という注記を表示する | タップで[スプリントの履歴画面](./sprint-history.md)（該当月指定）へ遷移する |
| カレンダーの日付 | その日にトレーニング実績がある場合、ブランド色で塗りつぶして表示 | タップでポップオーバーを開き、その日の単語帳（単語数/フレーズ数）、スプリント（回数/回答数）、発話回数の内訳を表示する |

## 状態

特別なエラー状態は無い。実績が無い日・月は、カードの数値が0、カレンダーの日付がグレーで表示される。

- 画面遷移直後（`performance/loading.tsx`）: 見出し・月切替・カードの見出し・カレンダーの日付は本物で表示し、
  数値（まとめ・トレーニング別）だけを骨組みで表示する。カレンダーの実施日の色は付かない。
  表示月は `?month=` を優先し、無ければ利用者のタイムゾーンでの今月。
- 月の切り替え中: 月切替の月表示がスピナーに置き換わる（`loading.tsx` は出ない）。

## 関連する業務フロー仕様書

この画面は実績の閲覧・各履歴画面への導線であり、複数画面をまたぐ業務フローは特に無い。
実績の数え方（実施日数・発話回数・日付の境界・タイムゾーン）は[トレーニング実績の集計](../../../../testing/e2e/specs/training/training-stats.md)を参照。
