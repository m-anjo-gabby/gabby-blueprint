# トレーニング成果ダッシュボード（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/performance`
- 対象ロール: 生徒
- 目的: 単語帳ドリルとスプリントを合わせた月間のトレーニング実績（トレーニング日数・総発話回数・
  単語/フレーズ数・スプリント本数/回答数）を確認し、日別の実施内容や各履歴画面への入口とする。

## この画面に来る経路

- ダッシュボードから遷移する。単語帳履歴・スプリント履歴の各画面からも、パフォーマンス画面へ
  戻るボタンで遷移してくる。

## 画面の構成

1. **ヘッダー** — ダッシュボードへ戻るボタン、月送り（前月・次月）、当月以外を見ている場合の
   「今月」ボタン
2. **コアKPIカード** — 当月のトレーニング日数、総発話回数（単語ドリル・スプリント合算）
3. **トレーニング詳細カード** — 単語帳ドリル（単語数・フレーズ数）、スプリント（本数・回答数）
   のサマリーカード。それぞれの履歴画面への入口を兼ねる
4. **トレーニング・トラッカー（カレンダー）** — 当月のカレンダーで、実施した日をマークし、
   タップするとその日の内訳をポップオーバー表示する
5. **フッター** — 教材一覧（`/library`）への導線

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 月送り矢印（前月・次月） | 常時表示 | 対象月を切り替えて集計を再取得する |
| 「今月」ボタン | 当月以外の月を表示している場合のみ | 当月の表示に戻す |
| トレーニング日数カード | 常時表示 | 当月中、単語ドリルまたはスプリントを1回以上実施した日数を表示 |
| 総発話回数カード | 常時表示 | 単語ドリル・スプリントいずれかで発話評価を行った回数の合計を表示 |
| 「単語帳ドリル」カード | 常時表示 | タップで[単語ドリル学習履歴画面](./word-history.md)（該当月指定）へ遷移する |
| 「スプリント」カード | 常時表示 | タップで[スプリント学習履歴画面](./sprint-history.md)（該当月指定）へ遷移する。ヘルプアイコンから「ドリルモードの回答数は含まれていません」という注記を表示できる |
| カレンダーの日付マーク | その日にトレーニング実績がある場合、インジゴ色の丸で強調表示 | タップでポップオーバーを開き、その日の単語数/フレーズ数、スプリント本数/回答数、総発話回数の内訳を表示する |
| 「教材を選択する」ボタン | フッターに常時表示 | 教材一覧画面（`/library`）へ遷移する |

## 状態

特別なローディング・エラー状態は無く、月の切り替え中はカレンダー部分の月表示がスピナーに
置き換わる程度で、それ以外は常に確定したデータを表示する（実績が無い日・月はカードの数値が
0またはグレー表示になる）。

## 関連する業務フロー仕様書

この画面は実績の閲覧・各履歴画面への導線であり、複数画面をまたぐ業務フローは特に無い。
