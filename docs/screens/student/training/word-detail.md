# 単語帳トレーニング画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/word/[id]`
- 対象ロール: 生徒
- 目的: 教材（セクション）に含まれる単語とフレーズを、カード形式でめくりながら発音を聞き、
  発話練習（音声認識による評価）を行う。学習の途中離脱・再開（ブックマーク）にも対応する。

## この画面に来る経路

- 教材一覧（`/library`）から対象教材（`id`）を指定して遷移する。
- ダッシュボードの「続きから再開」導線から、直前に保存した学習位置を復元する形（`resume=true`）
  で遷移してくる場合がある。

## 画面の構成

1. **ヘッダー** — 戻るボタン、教材名・CEFRレベルバッジ、現在の単語（タップで単語インデックスを
   開く）、進捗バー（Word n/合計）
2. **学習カード** — 現在のフレーズの英文（表面）・日本語訳（裏面、タップでフリップ）、
   お気に入りボタン、フレーズ種別・ステップ進捗の表示
3. **操作パネル** — ブックマーク保存、前へ/次へ、自動再生切り替え、再生速度変更、音声再生、
   発話練習（音声認識）
4. **単語インデックス（ドロワー）** — 教材内の全単語一覧。出題順／アルファベット順で切り替え、
   タップで任意の単語へジャンプできる
5. **発話フィードバックモーダル** — 発話練習後の評価結果を表示する

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 学習カード（英文/日本語） | 常時表示 | タップでカードをフリップし、英文⇔日本語訳を切り替える |
| お気に入りボタン | カード右上に常時表示 | フレーズのお気に入り登録/解除を切り替える（即座にサーバーへ反映、失敗時は表示を元に戻す） |
| 単語名（ヘッダー中央） | 常時表示 | タップで単語インデックス（ドロワー）を開く |
| 進捗バー | ヘッダーに常時表示 | 現在の単語番号/全体数、達成率(%)を表示する |
| ブックマーク（保存）ボタン | 操作パネルに常時表示 | 確認ダイアログの上、現在の学習位置を保存してダッシュボードへ戻る |
| 前へ/次へボタン | 操作パネルに常時表示 | フレーズを1つ前/次に移動する。最後のフレーズでは「次へ」が「Finish」表示になる |
| 自動再生トグル | 操作パネルに常時表示 | ONの場合、確認ダイアログの上で自動再生を開始し、音声再生→一定時間待機→次のフレーズへ、を自動で繰り返す |
| 再生速度変更 | 操作パネルに常時表示 | ポップオーバーから再生速度を選択する |
| 「Listen」ボタン | 操作パネルに常時表示 | 現在のフレーズの音声を再生する |
| 「Practice」ボタン（マイク） | 操作パネルに常時表示 | タップで発話認識・評価を開始し、もう一度タップ（Stop）で終了する。評価結果は発話フィードバックモーダルで表示される |
| 単語インデックスの並び替えタブ（By Rank / A-Z） | ドロワー内に常時表示 | 単語の表示順を出題順・アルファベット順で切り替える |
| 単語インデックスの項目タップ | ドロワー内、各単語 | その単語の先頭フレーズへジャンプし、ドロワーを閉じる |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中 | 「教材データを読み込んでいます...」のローディング画面 | 教材データ取得中（レジューム時は保存位置の解決も含む） |
| 利用不可 | 「Unavailable」、この教材は利用できないかアクセス権限が無い旨のメッセージ | 教材データが0件、またはアクセス権限が無い場合。ダッシュボードへ戻る/前の画面に戻るボタンを表示 |
| レジューム完了 | 「続きから再開しました」のトースト | `resume=true`で遷移し、保存済みの学習位置が見つかった場合 |
| 音声再生失敗 | 「音声を再生できません」のエラートースト | フレーズ音声の再生に失敗した場合（代替の読み上げは行わない） |
| ブックマーク保存完了 | 「ブックマークしました」のトースト後、ダッシュボードへ遷移 | 保存確認ダイアログで「はい」を選んだ場合 |

## 補足

- 学習の進捗（学習した単語数・フレーズ数・発話評価回数）は5分ごとに自動でサーバーへ同期される
  ほか、画面を離れる際・ブックマーク保存時にも即座に同期される。
- 単語ごとに複数のフレーズ（ステップ）があり、フレーズ単位で1件としてカードが進む。

## 関連する業務フロー仕様書

この画面は単一教材内で完結する学習画面であり、複数画面をまたぐ業務フローは特に無い。
月次の学習実績集計は[単語ドリル学習履歴画面](./word-history.md)・
[学習記録](./performance.md)を参照。
