# スプリント実施画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/sprint/play`
- 対象ロール: 生徒
- 目的: スプリント教材の「タイムアタック」（制限時間内に一問一答でテンポよく回答する瞬発力トレーニング）、
  および「ドリル」（時間無制限で、自分のペースで聞いて発話を繰り返す練習）を実施する画面。問題種別・難易度・
  制限時間・発話評価の有無を選び、実施後は結果が保存されて[スプリント結果画面](./sprint-result.md)
  へ遷移する。

## この画面に来る経路

- 教材一覧（`/library`）の各教材から、対象教材（`content_id`）を指定して遷移する。
- ダッシュボードの「続きから」カードから、直前の実施設定を復元した状態（`resume=true`）で
  遷移してくる場合がある。
- [スプリント結果画面](./sprint-result.md)の「スプリントをリトライ」ボタンから、同じ教材・
  種別で再度この画面に遷移する。

## 画面の構成

1. **教材未割当てエラー画面** — 対象教材が取得できない場合に表示する専用画面
2. **開始準備画面（ジェスチャー待ち）** — レジューム時など、ブラウザの自動再生制限を解除する
   ために一度タップが必要な場合にのみ挟まる確認画面
3. **トレーニング設定選択画面** — モード（タイムアタック/ドリル）、発話評価ON/OFF、問題種別・
   難易度・制限時間を選び、開始する画面
4. **ドリルプレイヤー画面** — 自分のペースで進めるカード形式の学習画面
5. **タイムアタックプレイヤー画面** — 制限時間内に次々と回答していくタイマー付きの画面
6. **完了オーバーレイ** — タイムアタック終了時（タイムアップ、または全問回答完了時）に成果を
   先出し表示し、結果画面へ誘導する

## トレーニング設定選択画面

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 戻るボタン | 常時表示 | 入口の画面（教材一覧・ホーム等）へ戻る。選択→実施→結果→リトライの間は履歴を置き換えて移動するため、結果画面から来た場合も結果画面には戻らない。戻る先の履歴が無い場合（URLを直接開いた等）は教材一覧（`/library`）へ遷移する |
| ホームボタン | 常時表示 | ホーム（`/dashboard`）へ戻る |
| トレーニングモード切り替え（タイムアタック/ドリル） | 常時表示 | 「タイムアタック」は制限時間内に一問一答、「ドリル」は時間無制限で自分のペースで進める練習に切り替える。教材種別の「スプリント」と区別するため、時間制限のあるモードは「タイムアタック」と表示する（内部の識別子は `sprint` のまま）。？ボタンでモードの説明を表示する |
| 発話評価ON/OFF切り替え | 常時表示 | ONの場合、回答時にマイクで発話を録音し評価する。マイク権限が拒否されている場合はOFF固定になる |
| マイク許可ボタン | 発話評価ON、かつマイク権限が未確認（プロンプト）の場合 | タップでブラウザのマイク許可を要求する。拒否された場合は発話評価OFFへの切り替えを提案する確認ダイアログが出る |
| 「種別・レベル・時間を変更」ボタン | 常時表示 | 詳細設定ドロワーを開く（下記） |
| 出題テーマとTips | 常時表示 | 出題テーマの説明と、種別に応じたヒントを表示するダイアログを開く |
| ヘルプ（音声が聞こえない場合／マイクがブロックされている場合） | 常時表示（アコーディオン） | それぞれのトラブルシューティングダイアログを開く |
| 開始ボタン | 常時表示 | 選択中の設定でセッションを開始する。問題種別がUG Speedかつタイムアタックの場合は「YESで回答開始」「NOで回答開始」の2ボタンになる。それ以外は「タイムアタックを開始」／「ドリルを開始」 |

### 詳細設定ドロワー

- **問題種別**: UG Speed／UG Builders／UG Structure／UG Masteryの4種別。教材（コーパス型）の対応設定に
  無い種別と、問題が1件も無い種別は「提供されていません」として選択不可になる
- **レベル**: 種別ごとにBasic〜上限レベルのうち、**問題が存在するレベルだけ**を表示する（コーパス教材は
  特定のレベルにしか問題が無いことがある。種別によりレベル設定自体が無い教材もある）。問題が存在する
  種別×レベルは、教材情報の取得時に同じ往復で取得する（RPC `get_sprint_available_levels`）。
  到達レベル（`student_m_sprint_progress`。全教材で共通）の次のレベルまで選択でき、それより先はロックされる。
  レベル管理がオフの生徒（アプリのみ契約は初期値でオフ。アドミンのユーザー管理で切り替えられる）は、ロックされず全レベルを選択できる。
  同じ判定（`isSprintLevelSelectable`）を問題の取得時にサーバーでも行う
- **選択の補正**: 前回の設定・URLの `level` 指定・種別の切り替えで、問題の無いレベルやロック中のレベルが
  選ばれた場合は、「問題あり かつ 選択可」の最も低いレベルに自動で切り替える（`pickSprintLevel`）
- **制限時間**（タイムアタックのみ）: 60秒／90秒／120秒／150秒から選択

## ドリルプレイヤー画面

- カードに問題文（基本文・質問文/指示文）が表示され、音声が自動再生される。カードをタップすると
  解答が表示される（Reveal）
- 発話評価ONの場合、マイクボタンで発話を録音・評価できる（チャイムが鳴り終わってから認識を開始する）。
  停止ボタンでその時点の評価で確定し、評価後は解答音声が再生される。発話中にカードを切り替えた場合は、
  評価を出さずに中断する
- 自動再生モードをONにすると、音声再生→思考時間→解答表示→次のカードへ、を自動で繰り返す
  （手動操作は自動再生停止まで一部制限される）
- 再生速度（0.75倍〜等）をポップオーバーから変更できる
- 「戻る」ボタンで確認ダイアログの上、前の画面に戻る（進捗は自動保存される）

## スプリントプレイヤー画面

- 上部に制限時間の残りを示すプログレスバーとカウントダウン（秒）を表示する。時間経過に応じて
  バーの色が青→黄→赤へ変化する
- 問題文（基本文/質問文/指示文）が自動再生され、続けて発話評価ON時はチャイム後に自動で録音を
  開始する。発話評価OFF、またはマイク拒否時は「脳内で回答しましょう」の表示になり、手動で
  「次の問題へ」を押して進める
- 「発話を完了」ボタンで録音を終了し、評価結果（Excellent/Great/Good/Fair/Poor）を一瞬表示して
  次の問題へ自動的に進む
- 「スキップする」ボタンでその場で次の問題へ進める（スキップした問題は正誤判定なしで履歴に残る）
- 制限時間が0になると、その時点までの内容で自動的に結果を保存し、完了オーバーレイを表示する
- 音声の再生に失敗した問題は、通知の上でスキップされ、回答履歴からも除外される

## 完了オーバーレイ・結果への遷移

- タイムアタック完了時（タイムアップ、または全問終了時）に、回答数・発話数・平均スコアの
  先出しプレビューを表示する
- タイムアップの場合は3.5秒後に自動で[スプリント結果画面](./sprint-result.md)へ遷移する
  （「結果を確認する」ボタンで即座に遷移することも可能）
- 全問終了（タイムアップ以外）の場合は保存完了後、自動的に結果画面へ遷移する

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 教材未割当て | 「教材が選択されていません」、教材データを取得できない旨のメッセージと「教材一覧へ」ボタン | 対象教材IDが無い、または取得に失敗した場合 |
| 開始準備画面 | 「トレーニングを再開します」、タップで音声を有効化して再開する「トレーニングを開始」ボタン | レジューム（`resume=true`）または直接レベル指定でのアクセス時、ブラウザの自動再生ロックを解除するために表示 |
| 選択できないレベル | 選択画面に戻り、エラートースト「このレベルには問題がありません。別のレベルを選択してください。」／「このレベルはまだ選択できません。別のレベルを選択してください。」 | 開始時に問題が0件だった（画面を開いた後に問題が移動・削除された等。そのレベルは選択肢から外す）／ロック中のレベルが指定された（URLの `level` 指定・レジューム等） |
| 問題データ取得エラー | 「教材データを取得できません」、「ホームに戻る」ボタン | 問題データの取得処理そのものに失敗した場合 |
| マイクブロック | 「マイクがブロックされています。ブラウザ設定を確認してください。」 | ブラウザのマイク権限が拒否されている場合。発話評価は強制的にOFFになる |
| 音声再生失敗（個別） | エラートースト「音声を再生できません」（ドリル）／「この問題は音声を再生できないため、スキップしました。」（タイムアタック） | 問題文・解答音声の再生に失敗した場合 |
| 音声の中断 | 再生・発話を止め、復旧したら中断した問題を頭からやり直す（次の問題へは進めない）。画面に戻ったときに自動で再開できればそのまま続ける。できなければ「音声が停止しました。タップして再開」 | 画面が隠れた（バックグラウンド・画面ロック・タブ切替）、通話等で音声が止められた、再生が終わらない（iOS で音が出ないまま止まった）場合 |
| 音声の復旧失敗 | 「セッションが切断されました」と「再読み込み」ボタン。再読み込みした同じ画面でまた失敗した場合は「音声を復旧できませんでした」とタブを閉じて開き直す手順 | 「タップして再開」でも音声が戻らなかった場合（再読み込みでは直らない状態は、タブを閉じて開き直すよう案内する） |
| 終了確認 | 確認ダイアログ（自動再生中の終了、進行中のタイムアタックの中断など） | 「戻る」操作時、進行中の内容によって確認文言が変わる（タイムアタックは「タイムアタックを終了しますか？」の確認で「スコアは記録されません」と明示） |

## 関連する業務フロー仕様書

この画面は単一教材内で完結するトレーニング実施画面であり、複数画面をまたぐ業務フローは
特に無い。実施結果の確認は[スプリント結果画面](./sprint-result.md)、月次の実績集計は
[スプリントの履歴](./sprint-history.md)・[トレーニング記録](./performance.md)
を参照。

- [発話の流れ](../../../../testing/e2e/specs/training/speaking-flow.md) — 問題種別ごとの再生順（Speed: 質問文 / Builders・Structure: 基本文 → 指示文 / Mastery: 基本文 → 質問文）→ チャイム → 発話評価、発話評価OFF、ドリルの発話ボタン
