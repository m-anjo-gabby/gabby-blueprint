# スプリント結果画面（studentアプリ）

## 概要

- アプリ: `student`
- パス:
  - `/training/sprint/result/[id]` — 実施直後に開く**没入画面**（常設ナビなし）
  - `/training/sprint/history/[id]` — スプリントの履歴から開く**シェル画面**（常設ナビあり）
- 対象ロール: 生徒
- 目的: 実施したスプリント（またはドリル）1回分の内容を、問題ごとの基本文・質問文・解答文と
  発話評価スコアつきで振り返り、まとめて再生したりリトライしたりする。

## この画面に来る経路

- [スプリント実施画面](./sprint-play.md)でスプリントを完了・タイムアップした際、完了オーバーレイ
  から自動的に没入画面（`/training/sprint/result/[id]`）へ遷移する。実施画面は履歴に残さない
  （ブラウザの戻るで実施途中の画面に戻らない）。
- 選択→実施→結果→（戻る・リトライで）選択の間は常に履歴を置き換えて移動し、履歴には入口の画面
  （教材一覧・ホーム等）だけを残す。選択画面の「戻る」やブラウザの戻るで結果画面に戻ってループせず、
  入口へ抜けられる。前回の結果は[スプリントの履歴](./sprint-history.md)から確認する。
- [スプリントの履歴](./sprint-history.md)の各スプリント項目から、シェル画面
  （`/training/sprint/history/[id]`）へ遷移する。

実施直後は続けてリトライする流れのため没入画面、履歴からは振り返りのためシェル画面で表示する
（コーチアプリの Live Sprint 結果と同じ考え方）。どちらも表示内容（サマリー・出題リスト）と
ヘッダーの並び（戻る・見出し・実施日）は同じで、操作ボタンの配置だけが異なる。

## 画面の構成

### 没入画面（実施直後）

1. **ヘッダー** — スプリント選択画面（同じ教材・種別）へ戻るボタン、画面タイトル「スプリント結果」、
   ホームへ戻るボタン（右端）、実施日
2. **サマリー** — シェル画面と同じカード。出題リストと一緒にスクロールする
3. **出題リスト** — 実施した問題を出題順に並べたカード一覧。各カードに基本文/質問文/指示文/
   解答文とその音声、発話評価スコア（記録がある場合）、お気に入り（☆）ボタンを表示する
4. **フッター** — 初めは「全て再生」、再生完了・停止後は「スプリントをリトライ」のボタンに
   切り替わる単一のアクションエリア

### シェル画面（履歴から）

1. **ヘッダー** — 画面タイトル「スプリント結果」、実施日、履歴画面（該当セッションをハイライトした
   状態）へ戻るボタン。その下に「全て再生」「リトライ」ボタンを並べ（モバイル幅に収めるため短い表記）、スクロールしても
   上部に固定表示する
2. **サマリー** — コース名・種別バッジ・制限時間、回答数/発話数/平均スコア
3. **出題リスト** — 没入画面と同じ

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 各カードの「再生」バッジ | 全カードに常時表示 | そのカードの基本文→質問文/指示文→解答文を順番に自動再生する（「全て再生」中は操作不可） |
| 各文の個別再生ボタン | 基本文・質問文・解答文それぞれ | その文だけを単独で再生する |
| 日本語表示切り替え | 各文の見出し部分 | タップで英文⇔日本語訳の表示を切り替える |
| スコアバッジ | 発話評価を行った問題（スキップ・未評価を除く） | 詳細な評価データ（フィードバック）が保存されている場合、タップで発話フィードバックのモーダルを開く。古いデータで詳細が無い場合はタップ不可 |
| スキップバッジ | その場でスキップした問題 | 表示のみ（操作不可） |
| お気に入り（☆）ボタン | 全カードの右上。登録済みの問題は塗りつぶしの☆ | タップでお気に入りの登録／解除を即座に切り替える（トースト通知あり、失敗時は元の状態に戻す）（[お気に入り](../favorites.md)の登録上限（種別ごと1,000件）に達している場合は登録せず、上限と削除を促すトーストを表示）。登録した問題は[お気に入り](../favorites.md)の「スプリント問題」に表示される |
| 「全て再生」ボタン | 没入画面ではフッターの初期状態、シェル画面では上部に常時表示 | 全問題を順番に自動再生する（再生中の問題カードまで自動スクロール）。再生中は「停止」ボタンに変わる。没入画面では再生完了または停止後に「スプリントをリトライ」ボタンに切り替わる |
| 「再生せずにすぐリトライする」リンク | 「全て再生」表示中に併記 | 再生せず、直接リトライ（同じ教材・種別で[スプリント実施画面](./sprint-play.md)を開く）する |
| 「スプリントをリトライ」ボタン（シェル画面では「リトライ」） | 没入画面では全て再生の完了/停止後、シェル画面では常時表示 | 同じ教材・スプリント種別で[スプリント実施画面](./sprint-play.md)のスプリント選択を開く。結果画面は履歴から置き換えるため、選択画面の「戻る」では入口（没入画面では教材一覧・ホーム等、シェル画面ではスプリントの履歴）へ戻る |
| 戻るボタン | 常時表示 | 没入画面：同じ教材・スプリント種別のスプリント選択画面へ戻る（前回の設定が選択された状態。結果画面は履歴から置き換える）。シェル画面：スプリントの履歴（該当月・該当セッションをハイライト）へ戻る |
| ホームボタン | 没入画面のみ | ホーム（`/dashboard`）へ戻る |
| 英文中の各単語 | 英文（基本文・質問文/指示文・解答文）表示中の全単語。日本語訳表示中は対象外 | タップするとその単語がハイライトされ、単語の上（上に余白が無い場合は下）に「Color Vowelを検索」ボタンが出る。詳細は「Color Vowel辞書」節を参照 |

## Color Vowel辞書

英文中の単語をタップして、その単語の発音（アクセントのある母音の Color Vowel）を調べる機能。

### 検索までの操作

1. 英文中の単語をタップすると、「Color Vowelを検索」ボタンが表示される。
   - 単語は英数字・アポストロフィ・ハイフンのつながりで区切られる（`didn't`、`high-quality` は1語）。
     前後の記号（`.` `,` `?` `"` など）は取り除いて検索する。
   - 1文字の単語（`a`、`I`）も対象。英字を含まない語（数字のみ等）はボタンが表示されない。
   - ボタン以外の場所をタップするか画面をスクロールすると、ボタンは閉じる。
2. 「Color Vowelを検索」をタップすると、右下に「Searching Color Vowel...」が表示され、
   検索が終わると「Color Vowel Dictionary」ダイアログが開く。

検索は、タップした単語の出現形（`launched`、`offers` など）そのままで行い、大文字小文字は区別しない。
公開中のエントリだけが対象。

### 辞書ダイアログの表示

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 品詞タブ | 同じ単語に複数の品詞が登録されている場合のみ（例: `offer` の動詞・名詞）。文中での品詞に関係なく、登録されている全品詞を表示する | タップした品詞のエントリに切り替わる（初期表示は品詞の表示順で先頭のもの） |
| 見出し語 | 常時表示。辞書に登録された表記のまま表示する（`CEO`、`Friday` 等は大文字を含む）。第一アクセントのある母音の綴りに下線を引き、その下に Color Vowel のアイコンを表示する | — |
| 「単語を再生」ボタン | 常時表示。単語の音声が未生成の場合は操作不可 | 単語の音声を再生する |
| 「母音を再生」ボタン | 常時表示。Color Vowel の音声が無い場合は操作不可 | Color Vowel（例: Olive Sock）の音声を再生する |
| 品詞ラベル・発音記号 | 品詞は常時表示。発音記号は登録されている場合のみ | — |
| 日本語訳 | 登録されている場合のみ | — |
| 原形 | 語形変化した語で原形が登録されている場合のみ「原形: launch」の形で表示 | — |
| Color Vowel の説明 | 常時表示。Color Vowel 名（その色の文字色）と説明文 | — |

### 辞書ダイアログの状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 未登録 | 「Not in dictionary」と「"<単語>" はColor Vowel辞書に登録されていません。」 | タップした単語が辞書に登録されていない場合（検索エラー時も同じ表示） |

辞書の登録内容は admin の [CV Dictionary](../../admin/tools/cv-dictionary.md) で管理する。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（履歴から開いた時の画面遷移直後） | 見出しは本物、実施日時・操作ボタン・結果のまとめ・問題カードを骨組みで表示 | `sprint/history/loading.tsx`（履歴一覧とパスで出し分け）。没入画面の結果表示は対象外 |
| 存在しない結果 | 404ページ | 指定した`id`のスプリント結果が取得できない場合（他人の結果、削除済み教材の結果等） |
| 発話評価なし | スコアバッジを表示せず（スキップでもない場合は何も表示しない） | 発話評価OFFで実施した問題、またはまだ評価が完了していない問題 |
