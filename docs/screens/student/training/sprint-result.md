# スプリント結果画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/sprint/result/[id]`
- 対象ロール: 生徒
- 目的: 実施したスプリント（またはドリル）1回分の内容を、問題ごとの基本文・質問文・解答文と
  発話評価スコアつきで振り返り、まとめて再生したりリトライしたりする。

## この画面に来る経路

- [スプリント実施画面](./sprint-play.md)でスプリントを完了・タイムアップした際、完了オーバーレイ
  から自動的に遷移する。
- [スプリント学習履歴画面](./sprint-history.md)の各スプリント項目から遷移する。

## 画面の構成

1. **ヘッダー** — 履歴画面（該当セッションをハイライトした状態）・ダッシュボードへ戻るボタン、
   コース名・種別バッジ・制限時間、回答数/発話数/平均スコアのサマリー
2. **出題リスト** — 実施した問題を出題順に並べたカード一覧。各カードに基本文/質問文/指示文/
   解答文とその音声、発話評価スコア（記録がある場合）を表示する
3. **フッター** — 実施直後は「全て再生」、それ以外（履歴からの遷移、再生完了後）は
   「スプリントをリトライ」のボタンに切り替わる単一のアクションエリア

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 各カードの「再生」バッジ | 全カードに常時表示 | そのカードの基本文→質問文/指示文→解答文を順番に自動再生する（「全て再生」中は操作不可） |
| 各文の個別再生ボタン | 基本文・質問文・解答文それぞれ | その文だけを単独で再生する |
| 日本語表示切り替え | 各文の見出し部分 | タップで英文⇔日本語訳の表示を切り替える |
| スコアバッジ | 発話評価を行った問題（スキップ・未評価を除く） | 詳細な評価データ（フィードバック）が保存されている場合、タップで発話フィードバックのモーダルを開く。古いデータで詳細が無い場合はタップ不可 |
| スキップバッジ | その場でスキップした問題 | 表示のみ（操作不可） |
| 「全て再生」ボタン（実施直後のみ） | スプリント実施直後に遷移してきた場合の初期状態 | 全問題を順番に自動再生する。再生中は「停止」ボタンに変わり、再生完了または停止後は「スプリントをリトライ」ボタンに切り替わる |
| 「再生せずにすぐリトライする」リンク | 「全て再生」表示中に併記 | 再生せず、直接リトライ（同じ教材・種別で[スプリント実施画面](./sprint-play.md)を開く）する |
| 「スプリントをリトライ」ボタン | 履歴一覧からの遷移時、または全て再生の完了/停止後 | 同じ教材・スプリント種別で[スプリント実施画面](./sprint-play.md)を開く |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 存在しない結果 | 404ページ | 指定した`id`のスプリント結果が取得できない場合（他人の結果、削除済み教材の結果等） |
| 発話評価なし | スコアバッジを表示せず（スキップでもない場合は何も表示しない） | 発話評価OFFで実施した問題、またはまだ評価が完了していない問題 |

## 関連する業務フロー仕様書

この画面は実施結果の閲覧・リトライ導線であり、複数画面をまたぐ業務フローは特に無い。
