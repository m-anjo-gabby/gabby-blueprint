# ビデオ教材の画面（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/training/video/[id]`（`id` は教材ID。見ているビデオは `?v=<ビデオID>`）
- 対象ロール: 生徒（公開中で、公開範囲に入っているビデオ教材だけを閲覧できる）
- 目的: ビデオ教材（1シリーズ = 1教材。発音トレーニング・オンデマンド・ColorVowel）のビデオを、セクション（見出し）ごとの
  一覧から選んで見る。どこまで見たかはビデオごとに自動で残り、次に開いた時はその位置から再生する。

## この画面に来る経路

- 教材一覧（`/library`。「お気に入り」で絞り込んだ場合を含む）のビデオ教材のカードの「トレーニングを始める」ボタンから遷移する。
- ホームの「続きから」カード（「ブックマークして終了」をした教材）、または今日のトレーニングメニューのビデオのやること（`?v=` でそのビデオ）から遷移する。

## 画面の構成

1. **ヘッダー** — 戻るボタン、画面タイトル「ビデオ」
2. **再生画面** — 見ているビデオの動画（再生・一時停止・シーク・全画面は動画の標準の操作）
3. **ビデオの情報** — 教材名、ビデオのタイトル、再生時間と「n / m 本目」、説明（登録時のみ）、「次のビデオへ」「ブックマークして終了」
4. **ビデオの一覧** — 教材名と「n / m 本 視聴済み」、セクションの見出しごとのビデオ

PC は再生画面の右にビデオの一覧を並べ、スマホは再生画面の下に一覧を出す。アプリシェル内の画面で、共通ナビゲーションは
「トレーニング」タブがアクティブになる。

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 戻るボタン | 常時 | 直前の画面（教材一覧・ホーム）へ戻る。履歴が無い場合は教材一覧（`/library`）へ遷移 |
| 画面タイトル「ビデオ」 | 常時 | 操作なし |
| 再生画面 | 見ているビデオがある時。サムネイルがあれば再生前に表示する | 再生すると、見ている位置を自動で保存する（下記「視聴の記録」）。ダウンロードのメニューは出さない |
| 教材名・タイトル | 常時 | 操作なし |
| 再生時間・「n / m 本目」 | 常時（再生時間が分からないビデオは「-」） | 操作なし |
| 説明 | ビデオに説明が登録されている時（改行はそのまま表示） | 操作なし |
| 「次のビデオへ」ボタン | 一覧で次のビデオがある時（セクションをまたいで次へ進む） | 次のビデオに切り替える（自動では再生しない） |
| 「ブックマークして終了」ボタン | 常時 | 確認ダイアログ（「ブックマークして終了しますか？」）の上で再生を止め、今の位置をブックマークしてホームへ戻る（「ブックマークしました」のトースト）。ホームの「続きから」から、このビデオの今の位置で再開できる |
| 「n / m 本 視聴済み」 | 常時（一覧の上） | 操作なし |
| セクションの見出し | 見出しのあるセクションだけ表示（見出しの無いセクションはビデオだけを並べる） | 操作なし |
| ビデオの行 | 公開中のビデオごと。サムネイル（無ければ空の枠）・タイトル・再生時間。見ているビデオは色付きで再生のマークを重ねる。最後まで見たビデオは「視聴済み」、途中まで見たビデオはサムネイルの下端に進み具合のバー | 押すとそのビデオに切り替える（自動では再生せず、サムネイル・タイトル・説明を見てから再生ボタンで再生する）。URL の `v` だけを置き換え、履歴は積まない（戻るボタン・ブラウザの戻るで、教材を開く前の画面へ戻る） |

### 視聴の記録

- 再生中は15秒ごと、一時停止した時、画面を離れる・タブを隠した時、別のビデオに切り替えた時に、見ている位置を保存する。
- 終わりの3秒前（短いビデオは長さの5%）まで見ると「視聴済み」になる。一度見終えたビデオは、見直しても「視聴済み」のまま。
- 途中まで見たビデオを開くと、保存した位置から再生する。最初の5秒より前・終わり間際・視聴済みのビデオは最初から再生する。
- 最初に開くビデオは、URL で指定したビデオ（「続きから」はブックマークしたビデオ）、無ければ最後まで見ていない最初のビデオ、
  全て見終えていれば先頭のビデオ。
- 視聴の記録は、トレーニングの実施日数・トレーニング記録の集計には数えない。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（画面遷移直後） | 見出しは本物、再生画面・タイトルとビデオの一覧（5行）を骨組みで表示 | `training/video/loading.tsx` |
| 教材が見つからない | 404ページ | 非公開・公開範囲の外・ビデオ以外の教材・誤った ID を開いた場合 |
| 読み込みの失敗 | 見出しの下に「データを読み込めませんでした。時間を置いてから、もう一度お試しください」と「再読み込み」 | 教材・ビデオの取得に失敗した場合 |
| 動画を読み込めない | 再生画面の位置に「動画を読み込めませんでした。画面を再読み込みしてください」と「再読み込み」ボタン（押すと画面を取り直し、動画の URL を作り直す） | 動画の URL の期限（4時間）が切れた・通信が切れた等で、動画の読み込みに失敗した場合 |
| ビデオが無い | 再生画面の位置に「ビデオがありません」 | 公開中のビデオが1本も無い教材を開いた場合 |
| ブックマークの失敗 | 「ブックマークできませんでした」のトースト（画面に留まる） | ブックマークの保存に失敗した場合 |

## 補足（設計上の注意点）

- 一覧には公開中のビデオだけを出し、公開中のビデオが無いセクションは出さない（admin で非公開にしたビデオは、URL で指定しても開けない）。
- 動画・サムネイルは非公開の保存先に置き、画面を開くたびにサーバーで期限付きの URL（4時間）を作る。本人に見えるビデオの行の
  ファイルにだけ URL を作る。
- 視聴の記録の定期的な保存に失敗しても、再生は止めない（次の保存で取り戻す）。
- 「続きから」はホームに1件だけ残る仕組み（単語帳と共通）のため、ビデオを見ただけでは載せず、「ブックマークして終了」をした時だけ載せる。
  「続きから」で開いた時点でブックマークは消える（再生位置はビデオごとの視聴の記録に残る）。
- iPhone では動画を画面内で再生する（全画面にはしない。全画面は動画の標準の操作で切り替える）。
