# パスワード変更（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/profile/password`
- 対象ロール: 生徒
- 目的: ログイン中のアカウントのパスワードを変更する。

## この画面に来る経路

- 画面右上のヘッダーのユーザーメニューから「パスワード変更」を選んで遷移する。

## 画面の構成

1. **パスワード変更フォーム** — 現在のパスワード、新しいパスワード、新しいパスワード（確認用）
   の3項目と送信ボタン

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 現在のパスワード入力欄 | 常時表示（必須） | 入力（マスク表示） |
| 新しいパスワード入力欄 | 常時表示（必須、8文字以上） | 入力するとリアルタイムで「英字と数字を両方含めてください」の警告が出る（英数混在でない場合） |
| 新しいパスワード（確認用）入力欄 | 常時表示（必須、8文字以上） | 入力するとリアルタイムで新しいパスワードと一致しているかを表示する（「パスワードが一致しました」／「パスワードが一致していません」） |
| 「パスワードを更新」ボタン | 常時表示 | 送信時、8文字未満・英数混在でない・一致しないのいずれかであればサーバーに送らずエラーメッセージを表示。条件を満たせばサーバーへ送信し、成功時はトースト通知の上で`/dashboard`へ遷移する |
| 「ダッシュボードに戻る」リンク | 常時表示 | `/dashboard`へ遷移 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 現在のパスワード誤り | 現在のパスワード欄の直下にエラーメッセージを表示し、当該欄のみ入力をクリアする | サーバー側で現在のパスワードが正しくないと判定された場合 |
| その他のサーバーエラー | 新しいパスワード欄の下に一般エラーメッセージを表示（例: 漏洩パスワード警告、過去と同じパスワードのエラー等） | 上記以外のサーバーエラーが返った場合 |
| 更新中 | 送信ボタンがローディング表示になる | フォーム送信処理中 |
