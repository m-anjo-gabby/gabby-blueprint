# モニタリングダッシュボード（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/monitor`
- 対象ロール: 生徒（同じ契約先（クライアント）に所属する他の受講生のトレーニング状況を横断的に閲覧できる
  権限を持つユーザー。法人契約等で、代表者・管理者的な立場のユーザーに限られる）
- 目的: 同じ契約先に所属する受講生全員のトレーニング状況（トレーニング日数・単語ドリル・スプリント実績）
  を月単位で集計・一覧し、CSVとして出力する。
- 期間とタイムゾーン: 対象年月・対象期間・ライセンス期間は**日本時間**の日付で区切る（集計期間のタイムゾーン。
  `packages/lib/date/reporting.ts` の `REPORTING_TIMEZONE`、DB側は `public.reporting_timezone()`）。期間の指定が無いときは日本時間の今月。
  各実績の日付は、閲覧する担当者ではなく**実施した受講生のタイムゾーンでの実施日**（スプリントのセッションもRPCで受講生の実施日にして返す）。
- 対象生徒の決定方法: 内部共通ヘルパー`private.get_monitor_target_users`（`_client_id`,
  `_start_date`, `_end_date`, `_include_monitor`）に判定ロジックを一本化しており、受講生
  一覧・単語ドリル履歴・スプリント履歴・スプリントドリル履歴の4RPCすべてがこれを利用する。
  「今この瞬間に契約が有効か（NOW基準）」ではなく、**表示中の対象年月とライセンス期間が
  重なっているか（status=1の有効なライセンスに限る）**で対象生徒を判定する。これにより、
  前期のみ契約し後期は契約していない（更新しなかった）生徒でも、前期の年月を表示している
  間、または在籍期間の一部が含まれる月（例: 月の途中で契約が切れた月）を表示している間は、
  一覧・絞り込み・実績（単語ドリル/スプリント）すべてに表示される。ライセンス状態バッジは
  「現時点（NOW）」での状態を示すため、既に契約が終了した生徒は「期限切れ」バッジのまま
  一覧に表示される。停止（status=0）・満了（status=9）のライセンスは、日付が対象期間と
  重なっていても対象外。
  - 招待中・承認待ちユーザー（`com_t_invitation`、本登録未完了＝ライセンス未発行）は、
    「対象期間に有効な生徒」の定義に該当しないため一覧に一切表示されない（2026-09-22
    以降。それ以前は対象期間を無視して常に表示されており、招待リンクが失効済みの招待までも
    どの対象期間でも表示され続けるバグがあった）。招待管理はこの画面の対象外。

## この画面に来る経路

- 画面下部のボトムタブ（モバイル）／左サイドナビ（PC）の「モニター」タブから遷移する。閲覧権限は
  `com_t_user_role`の`role_id='monitor'`ロールで制御されており、これを持たない受講生にはタブ自体が
  表示されない（`apps/student/app/(app)/(shell)/layout.tsx`でロールを判定し、
  `apps/student/constants/navigation.ts`の表示条件で出し分ける）。仮にURLを直接
  入力してアクセスしようとしても、`apps/student/proxy.ts`のミドルウェアが`role_id='monitor'`
  を持たないユーザーを`/dashboard`へリダイレクトするため画面自体を開けない。`get_monitor_user_list`
  等のRPCによるクライアント単位の絞り込みは、この画面に入れた後の「表示対象データ」の絞り込み
  であり、画面へのアクセス可否そのものは制御していない。
  詳細は[E2E仕様書](../../../testing/e2e/specs/monitoring/student-monitor-dashboard.md)を参照。

## 画面の構成

1. **ヘッダー** — 画面タイトル「モニタリングダッシュボード」と説明文（`ShellPageHeader`）
2. **タブナビゲーション** — 「受講生サマリー」「単語ドリル履歴」「スプリント履歴」の3ビューを
   URLクエリ（`view`）で切り替える（`PillTabs`。見出しの下に固定表示）
3. **モニター表示スイッチ** — モニター用アカウントを一覧・集計に含めるかどうかを
   切り替えるスイッチ（タブの右側。URLクエリ `includeMonitor`）
4. **受講生サマリービュー** — 受講生ごとのライセンス状態・期間・月間実績を一覧表示
5. **単語ドリル履歴ビュー**／**スプリント履歴ビュー** — 期間・受講生で絞り込んだ詳細ログを
   日付ごとにグループ化して一覧表示

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「モニターを含める」スイッチ | タブの右側に常時表示 | オンにすると、モニターロール（`role_id='monitor'`）を持つアカウントも一覧・集計・CSVに含める（デモユーザーは常に含めない）。一覧・履歴ではモニター用アカウントに「モニター」ラベルを付ける |
| 対象年月の前月/翌月ボタン（受講生サマリー） | 常時表示（トレーニング記録画面と同じ月切替。当月以外では「今月に戻る」も表示）。対象生徒が0人の月に進んでも消えない（後述） | 表示対象月を切り替え、その月の集計を再計算する。対象生徒もその月に有効なライセンス期間が重なる生徒に切り替わる（過去に在籍していたが現在は契約していない生徒も、その在籍期間の一部が含まれる月を表示している間は現れる） |
| 年月選択ボタン（受講生サマリー） | 月切替の右のカレンダーアイコン（常時表示） | 年月ピッカーのポップオーバーを開く。年送り＋月グリッドから直接ジャンプできる（前月/翌月ボタンでの連続クリックが不要になる） |
| CSVエクスポートボタン | 各ビューに常時表示（対象データが0件の場合は非活性） | 現在の絞り込み条件に基づく一覧をCSVファイルとしてダウンロードする |
| 受講生の行（サマリービュー） | 契約先に所属する受講生ごとに1行 | 氏名・メール・ライセンス状態バッジ・ライセンス期間・トレーニング日数・フレーズ数・スプリント本数・回答数・発話数・最終実施日を表示する（PC幅は表形式、狭い画面は項目名付きのカード形式） |
| ライセンス状態バッジ | 各受講生の行 | 「利用中」「期限切れ」「開始前」のいずれかを色分け表示（招待中・承認待ちユーザーは一覧に表示されないため、「招待中」「期限切れ(招待)」「送信失敗」の状態は実質的に発生しない） |
| 対象期間（開始日・終了日） | 単語ドリル履歴・スプリント履歴ビュー | 日付を指定して「表示」ボタンを押すと、その期間（最大半年）の履歴を再取得する。開始日が終了日より後、または半年を超える範囲を指定するとエラーメッセージが表示され検索できない |
| 受講生の絞り込み | 単語ドリル履歴・スプリント履歴ビュー | 「受講生」ボタンで候補を開き、名前・メールで検索して複数選択できる。選択中の受講生は条件欄の下にバッジ表示され、個別・一括で解除できる |
| 日付ごとの履歴カード | 単語ドリル履歴・スプリント履歴ビュー、対象期間内に実績がある日ごと | 見出しにその日の合計、中に受講生別・教材別の内訳（単語数/フレーズ数/発話数、またはスプリント本数/回答数/発話数）を表示する（開閉なし。スクロールは画面全体で行う） |
| ページ送り | 一覧が7日分を超える場合（一覧の上、日数の右） | 日付単位で7日ごとにページを切り替える |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（画面遷移直後） | 見出し・タブ・モニター切替（表示中の条件は URL から）は本物、表示中のタブの条件欄と一覧を骨組みで表示 | `monitor/loading.tsx` |
| 再取得中（月・期間・絞り込み・モニター切替） | 条件欄はそのまま、一覧を薄く表示（月切替は月の表示部分、期間は「表示」ボタンが処理中表示） | URLのクエリだけが変わる遷移（`loading.tsx` は出ない） |
| 対象年月に受講生が0人（受講生サマリー） | 月切替・年月選択・CSVボタンは常に表示されたまま、その下に「この年月に該当する受講生が見つかりません」＋モニター未含の場合は「モニター用アカウントのみの場合は『モニターを含める』をオンにしてください」を併記 | 表示中の対象年月に、有効なライセンス期間が重なる受講生が1人もいない場合（2026-09-22以降。それ以前はコントロールバーごと消え、月を戻れなくなるバグがあった） |
| 履歴なし | 「該当する履歴はありません」 | 指定した期間・絞り込み条件に一致する履歴が無い場合 |
| 期間指定エラー | 入力欄が赤枠になり、条件欄の下にエラー文言を表示。「表示」ボタンも非活性 | 開始日が終了日より後、または期間が半年を超える場合 |
