# お気に入り（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/favorites`
- 対象ロール: 生徒
- 目的: お気に入り登録した教材、およびお気に入り登録した単語帳フレーズを、タブで切り替えて
  確認・解除する。

## この画面に来る経路

- ダッシュボードの「Favorites」ショートカットから遷移する（アプリシェルでは「学習」タブがアクティブになる）。
- ライブラリ画面の教材カードでお気に入り登録した教材も、ここに反映される。

## 画面の構成

1. **ヘッダー** — 戻るボタン、画面タイトル「Favorites」、「教材」／「フレーズ」タブ
2. **教材タブ** — お気に入り登録した教材の一覧（検索・種別絞り込み付き）
3. **フレーズタブ** — お気に入り登録した単語帳フレーズの一覧（検索・教材絞り込み付き）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「教材」／「フレーズ」タブ | 常時表示 | タップで表示内容を切り替える（初期表示は「教材」） |
| 教材検索欄 | 教材タブ表示中 | 入力文字列を教材名に含む教材のみに絞り込む |
| 教材種別セレクト | 同上 | 選択した種別（単語帳／ビデオ／スプリント等、お気に入り登録がある種別のみ選択肢に出る）で絞り込む |
| 教材カード | お気に入り登録した教材ごとに表示。種別・CEFRバッジ・教材名・説明文（省略時は「Read more」で展開可）・タグを表示 | カード内の「Start Training」で当該教材の学習画面へ遷移。星（お気に入り）アイコンをタップすると確認ダイアログの上でお気に入りから削除される |
| 教材が0件の場合 | 検索結果が無い場合／お気に入り教材が1件も無い場合 | 「該当する教材が見つかりません」または「お気に入り教材はありません」 |
| フレーズ検索欄 | フレーズタブ表示中 | 英語・日本語どちらの文字列でも部分一致検索できる |
| 教材セレクト（フレーズ用） | 同上 | 選択した教材に紐づくフレーズのみに絞り込む |
| フレーズカード | お気に入り登録したフレーズごとに表示。紐づく教材名、英語フレーズ、日本語訳を表示 | 「Listen Now」ボタンで音声再生（音声ファイルがあればそれを、無ければブラウザの音声合成を使用）。ゴミ箱アイコンで確認ダイアログの上でお気に入りから削除される |
| フレーズが0件の場合 | 検索結果が無い場合／お気に入りフレーズが1件も無い場合 | 「該当するフレーズが見つかりません」または「お気に入りフレーズはありません」 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中（教材タブ） | 「Loading Favorites...」とスピナー | 教材データの初回取得中 |
| 読み込み中（フレーズタブ） | 「Loading Phrases...」とスピナー | フレーズデータの初回取得中 |
| 削除失敗時のロールバック | 一覧を再取得して元の状態に戻す | お気に入り解除のサーバー処理が失敗した場合 |
