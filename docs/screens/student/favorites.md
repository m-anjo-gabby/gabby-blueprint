# お気に入り（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/favorites`（表示する種別は `?kind=contents` / `?kind=phrases` で指定できる）
- 対象ロール: 生徒
- 目的: お気に入り登録した教材・単語帳フレーズを、種別ごとに確認・検索し、トレーニングの開始や
  音声での復習、お気に入りの解除を行う。

## この画面に来る経路

- ホームの「お気に入りを復習」から遷移する（アプリシェルでは「トレーニング」タブがアクティブになる）。
- 教材一覧の教材カードの☆、単語帳トレーニングのカードの☆で登録したものが、ここに表示される。

## 画面の構成

1. **ヘッダー** — 戻るボタン（直前の画面へ戻る。履歴が無い場合はホームへ）、画面タイトル「お気に入り」
2. **固定ツールバー**（スクロールしても上部に固定）— 種別のピル（「教材」「フレーズ」、それぞれ件数付き）、
   検索欄、絞り込みセレクト
3. **一覧** — 選択中の種別のお気に入り（教材はPCで2列、フレーズは1列）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 種別のピル | 常時表示。種別名・アイコン・登録件数。種別が増えた場合は横スクロール | タップで種別を切り替える。URLの `kind` も書き換わる（履歴は積まない）。切り替えると検索・絞り込みは初期状態に戻る |
| 初期表示の種別 | `kind` の指定がある場合はその種別。無い場合は、登録がある最初の種別（教材→フレーズの順）。どちらも0件なら「教材」 | — |
| 検索欄 | 選択中の種別に1件以上登録がある場合。教材は「教材名で検索」、フレーズは「英語・日本語で検索」 | 教材は教材名、フレーズは英文・日本語訳・単語の部分一致（大文字小文字を区別しない）で絞り込む |
| 絞り込みセレクト | 登録済みの項目に分類が2つ以上ある場合のみ。教材は種別（単語帳／スプリント等）、フレーズは出典の教材 | 選択した分類で絞り込む。選択中の分類の項目を全て削除した場合は「すべて」に戻る |
| 教材カード | 教材一覧と同じカード。星の代わりに削除（ゴミ箱）ボタン | 「トレーニングを始める」で当該教材のトレーニング画面へ遷移。ゴミ箱で確認ダイアログの上でお気に入りから削除 |
| フレーズカード | 出典（教材名・単語）、英文、日本語訳、「音声を聞く」ボタン、削除（ゴミ箱）ボタン | 「音声を聞く」で音声再生（生成済みの音声ファイルがあればそれを、無ければブラウザの音声合成を使用）。ゴミ箱で確認ダイアログの上でお気に入りから削除 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中 | シェル共通の骨組み（スケルトン） | 画面遷移直後、サーバーでお気に入りを取得している間（`(shell)/loading.tsx`） |
| 0件 | 「お気に入りの教材（フレーズ）はまだありません」、登録方法の案内、「教材一覧を見る」ボタン | 選択中の種別に登録が1件も無い場合 |
| 該当なし | 「条件に合う教材（フレーズ）が見つかりません」、「条件をクリア」ボタン | 検索・絞り込みの結果が0件の場合 |
| 削除 | 一覧から即座に外し、「お気に入りから削除しました」を表示。ピルの件数も減る | 確認ダイアログで削除を選んだ場合 |
| 削除失敗 | 項目を元の位置に戻し、「削除できませんでした。通信環境を確認してください」を表示 | お気に入り解除のサーバー処理が失敗した場合 |

## 業務ルール

- 教材は教材一覧と同じ取得処理（`getAllContent`、ダイアログは割当済みのみ）からお気に入りだけを
  抽出するため、割当の外れたダイアログ・非公開になった教材は表示されない。
- お気に入りフレーズ（`com_t_favorite_phrase`）・お気に入り教材（`com_t_favorite_contents`）は、RLSにより
  本人だけが参照・登録・解除できる（同じ顧客の他ユーザーからは参照できない）。
- 教材のお気に入りを解除すると、教材一覧の☆の表示にも反映される。

  （表示名・検索対象・絞り込みの分類・解除処理・カード）。種別を追加する場合はここと `page.tsx` に足す
- `apps/student/app/(app)/(shell)/favorites/_components/FavoritesView.tsx` — 種別の切り替え（URL）・解除
- `apps/student/app/(app)/(shell)/favorites/_components/FavoriteKindSection.tsx` — 検索・絞り込み・一覧・0件表示
- カード: `ContentFavoriteCard.tsx`（共通の `components/common/ContentCard.tsx` を使用）、`PhraseFavoriteCard.tsx`
- 種別のピル: `apps/student/components/shell/PillTabs.tsx`（教材一覧と共通）
- 関連アクション: `getFavoriteContents`, `toggleContentFavorite`（`apps/student/actions/contentAction.ts`）、
  `getFavoritePhrases`, `toggleFavorite`（`apps/student/actions/wordAction.ts`）
- DDL: `supabase/DDL/table/com_t_favorite_contents.sql`, `supabase/DDL/table/com_t_favorite_phrase.sql`
