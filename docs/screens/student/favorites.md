# お気に入り（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/favorites`（表示する種別は `?kind=contents` / `?kind=phrases` / `?kind=sprintQuestions`、絞り込みは
  `content`（教材）・`type`（種別／問題種別）・`level`（レベル）のクエリで指定できる。例: `?kind=sprintQuestions&type=0&level=2`）
- 対象ロール: 生徒
- 目的: お気に入り登録した教材・単語帳フレーズ・スプリント問題を、種別ごとに確認・検索し、
  トレーニングの開始や音声での復習、お気に入りの解除を行う。

## この画面に来る経路

- トレーニングタブ内の切り替え（教材｜お気に入り｜トレーニング記録）、またはホームの「今日やること」の「お気に入りを復習」から遷移する（アプリシェルでは「トレーニング」タブがアクティブになる）。
- 教材一覧の教材カードの☆、単語帳トレーニングのカードの☆、[スプリント結果](training/sprint-result.md)
  （実施直後・履歴から）の各問題の☆で登録したものが、ここに表示される。

## 画面の構成

1. **ヘッダー** — 見出し「トレーニング」とトレーニングタブ内の切り替え（教材｜お気に入り｜トレーニング記録）。画面名は選択中の切り替えタブで示し、「お気に入り」の見出しは読み上げ用だけで見た目には出さない（戻るボタンは無い）
2. **固定ツールバー**（スクロールしても上部に固定）— 種別のピル（「教材」「フレーズ」「スプリント問題」、
   それぞれ件数付き）、検索欄、絞り込み（PC=md以上は検索欄の横にセレクトを並べる。モバイルは「絞り込み」ボタンと
   指定中の条件のチップ）
3. **一覧** — 選択中の種別のお気に入り（教材はPCで2列、フレーズ・スプリント問題は1列）。50件ずつ表示する

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 種別のピル | 常時表示。種別名・アイコン・登録件数。画面幅に収まらない場合は横スクロール（選択中のピルを中央に寄せ、続きがある側の端をフェード表示） | タップで種別を切り替える。URLの `kind` も書き換わる（履歴は積まない）。切り替えると検索・絞り込みは初期状態に戻る |
| 初期表示の種別 | `kind` の指定がある場合はその種別。無い場合は常に「教材」（登録のある種別へ自動では切り替えない。読み込み中の骨組みから選択が移ってちらつくため） | — |
| 他の種別への案内 | 選択中の種別が0件で、他の種別に登録がある場合、空の表示の下に「フレーズを見る（n件）」等のボタンを登録のある種別ごとに表示 | タップでその種別に切り替える（種別のピルと同じ） |
| 検索欄 | 選択中の種別に1件以上登録がある場合。教材は「教材名で検索」、フレーズ・スプリント問題は「英語・日本語で検索」 | 教材は教材名、フレーズは英文・日本語訳・単語、スプリント問題は基本文・質問文・解答文の英語と日本語訳の部分一致（大文字小文字を区別しない）で絞り込む |
| 絞り込み | 種別ごとに次の項目。**選択肢が2つ以上ある項目だけ**を出し、選択肢は登録済みの項目から件数付きで作る。<br>・教材: 種別（単語帳／スプリント等）<br>・フレーズ: 教材<br>・スプリント問題: 教材 → 問題種別（UG Speed／Builders／Structure／Mastery の順）→ レベル（Basic・Lv.1〜の順）。レベルは問題種別を選んだ後にだけ出し、レベル分けの無い教材（コーパススプリント。教材設定の `has_level=false`）の問題は対象外 | 絞り込みは連動する（前の項目で絞った結果から次の選択肢を作り、前の項目を変えると後ろの項目は「すべて」に戻る）。条件はURLに保持し、再読み込み・トレーニングから戻った時も残る。選択中の値が無くなった場合（削除・URLの手入力）は「すべて」として扱う |
| 「絞り込み」ボタン（モバイル） | 絞り込み項目がある場合。指定中の条件の数をバッジで表示 | 下から開くシートで、項目ごとの選択肢（「すべて」＋件数付きの選択肢）をタップで選ぶ。「条件をクリア」で全項目を解除、「◯件を表示」でシートを閉じる |
| 条件のチップ（モバイル） | 条件を指定中の場合、検索欄の下に「問題種別: UG Speed ×」の形で表示 | タップでその条件（と連動する後ろの条件）を外す |
| 「さらに表示（残り◯件）」 | 絞り込み・検索後の件数が50件を超える場合、一覧の末尾 | 次の50件を表示する。条件を変えると最初の50件に戻る |
| 教材カード | 教材一覧と同じカード。星の代わりに削除（ゴミ箱）ボタン | 「トレーニングを始める」で当該教材のトレーニング画面へ遷移。ゴミ箱で確認ダイアログの上でお気に入りから削除 |
| フレーズカード | 出典（教材名・単語）、英文、日本語訳、「音声を聞く」ボタン、削除（ゴミ箱）ボタン | 「音声を聞く」で音声再生（生成済みの音声ファイルがあればそれを、無ければブラウザの音声合成を使用）。ゴミ箱で確認ダイアログの上でお気に入りから削除 |
| スプリント問題カード | 出典（教材名・コース名 例: UG Speed Lv.1）、基本文（ある場合）・質問文／指示文・解答文（YES/NOの2通りがある問題は「解答文（Yes）」「解答文（No）」の両方）、削除（ゴミ箱）ボタン。各文の見た目は結果画面と同じ | 各文の再生ボタンでその文を再生（音声ファイルが無い場合はブラウザの音声合成）。見出しのボタンで英文⇔日本語訳を切り替える（日本語から英語を思い出す復習に使える）。ゴミ箱で確認ダイアログの上でお気に入りから削除 |
| 音声再生（共通） | フレーズ・スプリント問題カード | 一覧で1つのプレイヤーを共有し、別の音声を再生すると再生中の音声は止まる（同時に鳴らない）。画面を離れると停止する |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中 | 画面専用の骨組み。見出し・種別ピルは本物（件数なし）、検索欄と種別ごとのカードを骨組みで表示（列数は本番と同じ）。種別は `?kind=` があればその種別、無ければ本番の既定と同じ「教材」の形で描く | 画面遷移直後、サーバーでお気に入りを取得している間（`favorites/loading.tsx`） |
| 0件 | 「お気に入りの教材（フレーズ／問題）はまだありません」、登録方法の案内、「教材一覧を見る」（スプリント問題は「スプリントの履歴を見る」）ボタン | 選択中の種別に登録が1件も無い場合 |
| 該当なし | 「条件に合う教材（フレーズ／問題）が見つかりません」、「条件をクリア」ボタン | 検索・絞り込みの結果が0件の場合 |
| 削除 | 一覧から即座に外し、「お気に入りから削除しました」を表示。ピルの件数も減る | 確認ダイアログで削除を選んだ場合 |
| 登録上限 | 「お気に入りの教材（フレーズ／問題）が上限（1,000件）に達しています。新しく登録するには、不要なものを削除してください。」の案内 | 選択中の種別の登録件数が1,000件の場合 |
| 削除失敗 | 項目を元の位置に戻し、「削除できませんでした。通信環境を確認してください」を表示 | お気に入り解除のサーバー処理が失敗した場合 |

## 業務ルール

- 教材は教材一覧と同じ取得処理（`getAllContent`、ダイアログは割当済みのみ）からお気に入りだけを
  抽出するため、割当の外れたダイアログ・非公開になった教材は表示されない。
- スプリント問題は、出典の教材が非公開・削除済み・アクセス権なしになった場合は表示されない
  （問題マスタ `com_m_sprint_questions` は教材への外部キーを持たないため、取得後に教材の可視性で絞り込む）。
- お気に入りテーブル（`com_t_favorite_contents` / `com_t_favorite_phrase` / `com_t_favorite_sprint_question`）は、
  RLSにより本人だけが参照・登録・解除できる（同じ顧客の他ユーザーからは参照できない）。種別ごとに別テーブルとし、
  元の教材・フレーズ・問題が削除されるとお気に入りも削除される（`ON DELETE CASCADE`）。
- 教材一覧・ホームと同じく、画面を開くたびにサーバーで取得し、画面をまたぐクライアントキャッシュは持たない
  （他画面での登録・解除は次に開いた時に反映される。教材一覧の☆への反映処理も持たない）。ブラウザの「戻る・進む」で
  キャッシュ済みの画面が再利用された場合は、表示後に裏で取り直して最新に差し替える（`useRefreshOnRestoredRender`）。
- **登録上限は1人・種別ごとに1,000件**（Supabase API の1回の取得上限 `max_rows=1000` と揃え、一覧の取りこぼしを防ぐ）。
  DBのトリガー（`fn_check_favorite_limit`）で判定するため、教材一覧・単語帳トレーニング・スプリント結果のどこから
  登録しても同じく拒否され、各画面は「お気に入りは1,000件まで登録できます。不要なものを削除してから登録してください」を
  トーストで表示する。登録済みの項目を登録し直す（upsert）場合は件数が増えないため拒否しない。
