# ライブラリ（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/library`（`?favorite=1` でお気に入りの教材だけに絞り込んだ状態で開く）
- 対象ロール: 生徒
- 目的: 利用可能な教材（単語帳・ビデオ・スプリント・ダイアログ）を検索・種別タブで絞り込みながら
  一覧し、トレーニングを開始する。お気に入り登録もここから行い、**お気に入りの教材は本画面の「お気に入り」の絞り込みで表示する**
  （[お気に入り](favorites.md)画面はフレーズ・スプリント問題だけを扱う）。**ダイアログのみ、コーチに割り当てられた
  セットだけが一覧に表示される**（他種別はテナント等に基づくRLSの可視範囲がそのまま一覧に出る）。

## この画面に来る経路

- 画面下部のボトムタブ（モバイル）／左サイドナビ（PC）の「トレーニング」タブ、トレーニングタブ内の切り替え（教材｜お気に入り｜トレーニング記録）、またはホームの「今日やること」の「教材を選ぶ」から遷移する。以前のお気に入りの教材のリンク（`/favorites?kind=contents`）は、`?favorite=1` 付きで本画面へ転送される。

## 画面の構成

1. **ヘッダー** — 見出し「トレーニング」とトレーニングタブ内の切り替え（教材｜お気に入り｜トレーニング記録）。画面名は選択中の切り替えタブで示し、「教材」の見出しは読み上げ用だけで見た目には出さない
2. **固定ツールバー**（スクロールしても上部に固定）— 検索バー・「☆ お気に入り」の切り替え、種別タブ（横スクロール。選択中は濃いインディゴ）と件数（「n件」、種別タブの右端）
3. **教材一覧** — 検索・タブ条件に一致する教材のカード一覧

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 件数バッジ | 常時表示（種別タブの右端） | 現在の絞り込み条件に一致する教材数を表示 |
| 検索欄 | 常時表示 | 入力文字列を教材名に含む教材のみに絞り込む |
| 「☆ お気に入り」の切り替え | 常時表示（検索欄の右隣）。オンの間は背景を淡い青、☆を塗りつぶしで表示 | オン・オフで、お気に入りの教材だけに絞り込む／解除する。検索・種別タブと組み合わせられ、オンの間は種別タブの件数もお気に入りの中での件数になる。状態はURL（`?favorite=1`、履歴は積まない）に持ち、再読み込み・トレーニングから戻った時も残る。オンの間に教材カードの☆を外すと、その教材はその場で一覧から消える |
| クリア（×）ボタン | 検索文字列・タブ・タグ・お気に入りの絞り込みのいずれかが設定されている場合のみ表示 | 検索文字列・種別タブ・タグ・お気に入りの絞り込みをすべてリセットする |
| 種別タブ（すべて／単語帳／スプリント／ダイアログ／ビデオ。並びは `LIBRALY_TABS`） | 常時表示。種別アイコン（未選択時は種別の分類色）・ラベル・該当件数を表示する横スクロールpill形式（種別が増えても折り返さず1行のまま増やせる）。スクロール可能な場合のみ端にフェード表示、選択中タブは自動的に中央付近へスクロールする | タップで該当種別の教材のみに絞り込む |
| 教材カード | 絞り込み条件に一致する教材ごとに表示（PCは2列で、同じ行のカードは高さを揃え「トレーニングを始める」ボタンを下端に揃える。教材名は2行で省略）。種別アイコン（種別の分類色のマス）・CEFRバッジ・教材名・説明文（長い場合は「続きを読む」で展開、「閉じる」で折りたたみ）・タグ・お気に入り（星）ボタンを表示 | 星アイコンで即座にお気に入りの追加／解除を切り替える（トースト通知あり、失敗時は元の状態に戻す）（[お気に入り](favorites.md)の登録上限（種別ごと1,000件）に達している場合は登録せず、上限と削除を促すトーストを表示）。「トレーニングを始める」ボタンでトレーニング画面へ遷移（ダイアログのみ、[ダイアログ専用画面](training/dialogue-practice.md)へ遷移し、他種別は各トレーニング画面へ遷移する） |
| お気に入りの教材が無い場合 | 「お気に入り」がオンで、お気に入りの教材が1件も無い場合 | 「お気に入りの教材はまだありません」「教材カードの☆から登録できます」と「すべての教材を見る」ボタン（押すと「お気に入り」をオフにする） |
| 該当教材が0件の場合 | 上記以外で、検索・絞り込み条件に一致する教材が無い場合 | 「条件に合う教材が見つかりません」 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 読み込み中 | 画面専用の骨組み。見出し「トレーニング」・切り替えタブ・種別タブ・「お気に入り」の切り替え（URLの状態どおり）は本物、件数・検索欄・教材カード4枚を骨組みで表示（2列は本番と同じ） | 画面遷移直後、サーバーで教材を取得している間（`library/loading.tsx`） |

## 補足（設計上の注意点）

- **データの鮮度**: 画面を開くたびにサーバーで取得し、画面をまたぐクライアントキャッシュは持たない。そのため管理側の更新
  （教材の追加・非公開・利用権・ダイアログの割当）や他画面でのお気に入り変更は、次に開いた時に反映される。ブラウザの
  「戻る・進む」でキャッシュ済みの画面が再利用された場合も、表示後に裏で取り直して最新に差し替える
  （`packages/lib/hooks/useRefreshOnRestoredRender.ts`。サーバー描画ごとの `renderId` で再利用を判定）。
- ダイアログ（`content_type=3`）は、他種別のようなcom_m_contents単体のRLS可視範囲ではなく、
  自身への割当（`com_t_dialogue_assignment`）を起点に取得している。コーチが割り当てていない
  ダイアログ教材は、たとえRLS上アクセス可能でもこの一覧には出ない
  （[コーチ側のDialogue Practice管理画面](../coach/students/dialogue-practice.md)を参照）。
- お気に入りの教材は専用の取得を持たず、本画面の一覧（`getAllContent`）の `is_favorite` で絞り込む。そのため、割当の外れた
  ダイアログ・非公開になった教材は、お気に入りに登録済みでも表示されない。
