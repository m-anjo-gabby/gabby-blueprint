# ログイン（studentアプリ）

## 概要

- アプリ: `student`
- パス: `/login`
- 対象ロール: 生徒（未ログインの利用者）
- 目的: メールアドレスとパスワードでログインする。ログイン後はホーム（`/dashboard`）、または
  ログイン前に開こうとしていた画面へ移る。

## この画面に来る経路

- アプリのトップ（`/`）を未ログインで開いた場合。
- 未ログインでログインが必要な画面を開いた場合（通知・メール内のリンク等）。この場合、開こうとしていた
  画面が URL の `?next=` に付く（例: `/login?next=/chat/<ルームID>`）。
- ログアウトした場合、ログインの状態が切れた場合。
- 次の場合は、ログイン状態が破棄されてこの画面に戻される（画面上にメッセージは出ない）。
  - 管理者アカウントのまま生徒アプリを開いた場合
  - ログイン中に有効なライセンスが無くなった場合
  - 管理者による代理ログインの有効時間が過ぎた場合

## 画面の構成

1. **ロゴと案内文** — 「登録済みアカウントでログインしてください」
2. **入力欄** — メールアドレス、パスワード
3. **「パスワードをお忘れですか？」リンク**
4. **エラー表示欄** — ログインに失敗した場合のみ
5. **「ログイン」ボタン**

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| メールアドレス | 常時表示。必須 | — |
| パスワード | 常時表示。必須。右端に表示切り替え（目のアイコン） | アイコンを押すと、入力した文字の表示・非表示を切り替える |
| 「パスワードをお忘れですか？」 | 常時表示 | パスワード再設定の画面（`/forgot-password`）へ移る |
| 「ログイン」ボタン | 常時表示。処理中は「認証中...」と表示して押せなくなる | ログインする。パスワード欄で Enter キーを押しても同じ |
| ログイン後の移動先 | ログインに成功した場合 | URL に `?next=` があればその画面へ、無ければホーム（`/dashboard`）へ移る。`?next=` はアプリ内の画面のみ有効で、外部サイト（`//example.com` 等）やログイン画面自身が指定されている場合は無視してホームへ移る |
| ログイン済みで開いた場合 | 既にログインしている場合 | 画面を表示せず、`?next=` があればその画面へ、無ければホームへ移る |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 入力漏れ | 「メールアドレスとパスワードを入力してください。」 | どちらかが空のまま送信した場合（通常は入力欄の必須チェックで送信前に止まる） |
| 認証失敗 | 「認証情報が正しくありません。」。パスワード欄は空になる | メールアドレスまたはパスワードが誤っている場合 |
| アカウントロック（発生時） | 「パスワードを連続して間違えたため、アカウントが30分間ロックされました。」 | パスワードを連続10回間違えた場合 |
| アカウントロック中 | 「アカウントが一時的にロックされています。しばらく時間をおいてお試しください。」 | ロック中（30分間）にログインしようとした場合。正しいパスワードでもログインできない |
| ライセンス無し | 「有効なライセンスが見つかりません。管理者にお問い合わせください。」 | 有効期間内のライセンスが無い場合（ログインは取り消される）。コーチのアカウントはライセンスを持たないため、この表示になる |
| 管理者アカウント | 「管理者アカウントです。管理画面からログインしてください。」 | 管理者のアカウントでログインしようとした場合（ログインは取り消される） |
| 予期しないエラー | 「予期せぬエラーが発生しました」 | サーバー側で想定外のエラーが起きた場合 |
| 無効な再設定リンク | 「リンクが無効です／このリセットリンクは既に使用済みか、有効期限が切れています。再度リセットメールを送信しますか？」の確認ダイアログ | 使用済み・期限切れのパスワード再設定リンクからこの画面に戻ってきた場合。確定するとパスワード再設定の画面へ移る |

- ログインに成功すると、それまでのパスワードの失敗回数とロックは解除される。

  `packages/lib/auth/returnTo.ts`（`?next=` の検証）、`packages/lib/proxy-base.ts`（`redirectToLogin` / `redirectAfterLogin`）
- 関連RPC: `get_user_lock_status_by_email`, `increment_login_failed_count`
