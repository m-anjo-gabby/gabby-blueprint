# タイムゾーン管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/timezones`
- 対象ロール: 管理者
- 目的: 生徒・コーチ・管理者のプロフィールで選択可能なタイムゾーン（IANA準拠）のマスタを
  登録・編集・削除する。

## この画面に来る経路

- サイドバーの「タイムゾーン管理」から遷移する。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「新規登録」ボタン
2. **タイムゾーン一覧テーブル** — 検索欄（クライアント側フィルタ）、ページネーション、一覧表

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | タイムゾーン名・表示名称でその場で絞り込む |
| 「新規登録」ボタン | 常時表示 | 登録ダイアログを開く |
| 一覧の各列 | 表示順（SEQ）、表示名称（日本語）、表示名称（英語）、IANAタイムゾーン名 | 表示のみ |
| 一覧の「編集」ボタン | 各行に表示 | 編集ダイアログを既存値付きで開く（IANAタイムゾーン名は編集不可） |
| 一覧の削除ボタン（ゴミ箱アイコン） | 各行に表示 | 確認ダイアログの上で削除する |

## 登録・編集ダイアログ

- 入力項目: IANAタイムゾーン名（新規登録時のみ入力可。登録後は変更不可）、表示名称（日本語・英語）、
  表示順
- 「登録内容を確認する」で確認画面に切り替わり、「はい、確定します」で送信する
- IANA形式としての妥当性はサーバー（DBトリガー）側で最終検証される

## 削除

- 確認ダイアログで「削除する」を押すと削除する
- 既にそのタイムゾーンを設定しているユーザーには影響しないが、以後は選択肢に表示されなくなる

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 一覧が空 | 「タイムゾーンデータが見つかりませんでした。」 | 検索条件に一致するタイムゾーンが0件の場合 |
