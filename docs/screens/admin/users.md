# ユーザー管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/users`
- 対象ロール: 管理者
- 目的: 各テナント（顧客）に所属する生徒・コーチ・管理者アカウント（`com_m_user`）の作成・編集、
  権限（ロール）設定、ライセンス割当、生徒のトレーニング進捗（ステージ・レベル）の補正、
  および障害対応用の代理ログインを行う。

## この画面に来る経路

- サイドバーの「ユーザー管理」から遷移する。ダッシュボードの「ユーザー管理」カードからも遷移できる。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「一括登録」ボタン、「新規登録」ボタン
2. **ユーザー一覧テーブル** — 検索欄、区分フィルタ（管理者・生徒・コーチ）、顧客フィルタ、
   ページネーション、一覧表（1ページ10件）
3. **ユーザー登録・編集ダイアログ**
4. **ライセンス管理ダイアログ**（生徒のみ、一覧の「ライセンス」欄から開く）
5. **ステージ・レベル管理ダイアログ**（生徒のみ、一覧の「ステージ」ボタンから開く）
6. **代理ログインダイアログ**（本登録済みの生徒・コーチのみ、一覧の「代理ログイン」ボタンから開く）
7. **コーチの評価画面**（コーチのみ、一覧の「評価」ボタンから `/users/[id]/ratings` へ遷移）
8. **CSV一括登録ダイアログ**（生徒のみ対象）

## ユーザー登録・編集ダイアログ

- 新規登録時は作成方法を選択できる: 「招待メールを送信」（本登録リンクをメール送付、相手が
  パスワード設定するまで招待中の状態）または「即時作成」（確認メール無しでその場で有効化。
  管理者がその場でパスワードを設定する）
- 入力項目: メールアドレス、氏名、所属顧客（検索式）、ユーザー種別（生徒／管理者／コーチ）、
  ロール（ユーザー種別に応じて選べるロールが変わる。共通ロールは種別を問わず選択可）、
  新規登録・生徒の場合は初期ライセンス（有効な契約から選択。生徒には必須）、即時作成の場合は
  パスワード・パスワード確認
- 初期ライセンスは契約期間いっぱいで発行する。招待の場合は生徒が本登録した時点、即時作成の場合はその場で発行する（CSV一括登録も同じ）。
  ライブセッション付き契約ならチケットも発行し、割当履歴・ダイアログプラクティス提供有無の扱いもライセンス管理ダイアログ・契約管理からの割当と同じ
- ユーザー種別を変更すると、その種別で選択不可になったロールは自動的に選択解除される
- 招待中（未登録）のユーザーを編集する場合、氏名・メールアドレス・所属顧客・種別・ロールは変更
  できず、代わりに「招待メールを再送する」ボタンのみ表示される
- 編集モードではメールアドレス・初期ライセンス欄は表示・変更されない（メールアドレスは編集不可、
  ライセンスは別画面のライセンス管理ダイアログで扱う）
- 「確認画面へ進む」でバリデーション後に確認表示へ切り替わり、「確定して保存」（新規・即時作成時は
  「アカウントを作成する」）で送信する

## ライセンス管理ダイアログ（生徒のみ）

- 「一覧・履歴」タブ: その生徒に紐づく全ライセンスの履歴を表示（無効化済み・解除済み・期間終了は
  グレー表示）。有効なライセンスには編集ボタンと無効化ボタンがある
- 「新規割当」／「編集」タブ: 契約（新規時は残枠のある有効契約から「契約名（プラン名）」で選択、
  編集時は変更不可のため現在の契約名を表示のみ）、ライセンス開始日・終了日、備考（変更理由等）
  - 新規割当時: 契約期間の範囲内であることをサーバー側で常に検証する
  - 編集時: 契約期間内チェックは行わない（個別の生徒対応として、契約の終了日を超える延長を
    含め期限を自由に変更できる仕様。画面上にもその旨の案内文を表示する）
  - 新規・編集とも、同じ生徒の他のライセンスと期間が重複する場合は割当・変更できない
    （契約更新に伴う次タームライセンスの前倒し登録など、期間が重ならない複数ライセンスの
    保有は許容される。DB側にも排他制約があり、同時操作による重複登録は最終的に防止される）
- 無効化すると即座にシステム利用が不可になり、未実施の今後のセッションもキャンセルされるが、
  実施済みのセッション履歴・チャット・宿題は削除されずチケット消化数も戻らない

## ステージ・レベル管理ダイアログ（生徒のみ）

- 上部の「レベル管理する」スイッチ（`student_m_sprint_progress.level_managed`。初期値は生徒の作成・本登録時の初期ライセンスの契約で決まり、ライブセッション付き契約はオン、アプリのみ契約はオフ。契約の種類が後から変わった場合はここで切り替える）: オンの生徒は
  自主トレのスプリントで到達レベルの次のレベルまで選択でき、オフの生徒は全レベルを選択できる
  （コーチが付かない契約向け）。切り替えても到達レベル・ステージは変わらず、履歴にも記録されない
- 「問題種別ごと」タブ: トレーニングの問題種別（複数）ごとに現在のレベルを表示し、選択式で
  個別に変更・保存できる（コーチの誤操作補正等を想定）
- 「ステージ」タブ: 現在のステージを表示し、目標ステージを選択する
  - 現在より上のステージへ引き上げる場合、到達条件を満たしていない問題種別があれば警告を表示し、
    実行すると該当レベルが必要最小値まで強制的に引き上げられる（条件を満たす種別は変更されない）
  - 現在より下のステージへ引き下げる場合、対象ステージちょうどの基準値まで該当レベルがリセット
    される旨の警告を表示する
- レベルの変更はすべて履歴（`student_t_sprint_level_history`）に自動で記録され、トレーニングレポートの
  「開始時・終了時のレベル」に使われる。管理者による**引き下げは「誤った引き上げの修正」**として扱い、
  修正後より高い直近の記録を取り消して、その記録の日時に遡って修正後の値にする（修正前に期間が
  終わった生徒のレポートにも、誤ったレベルは出ない）

## 代理ログインダイアログ

- 実行理由（チケット番号・問合せ内容等）の入力が必須
- 実行すると対象ユーザーとして生徒ポータルまたはコーチポータルへの代理ログイン用タブが新規に開く。
  画面上の操作は全て本人の操作として実際に反映され、実行内容は監査ログに記録される旨の注記あり

## CSV一括登録ダイアログ（生徒のみ対象）

- 手順: 1. 所属顧客を選択 → 2. 初期ライセンス（有効な契約）を選択 → 3. CSVファイルをドラッグ&ドロップ
  またはクリックして選択（1回最大30件、サンプルCSVのダウンンロードリンクあり）
- CSVは「メールアドレス」「名前」列（英語ヘッダーの`email`/`user_name`も可）を読み取り、
  メール形式・名前未入力をその場でチェックし、内容確認テーブルに一覧表示する
- 顧客に有効な契約が無い場合、ライセンス選択欄に警告が表示され、生徒を含む一括登録はライセンス
  割当が必須のため進められない
- 「一括登録を開始」を押すとユーザー作成とライセンス割当を行い、各行ごとに「データ作成済/作成失敗」
  「メール送信済/メール送信失敗」の結果がレポート表示される
- 作成されるユーザーは常に生徒種別(user_type=1)固定であり、コーチ・管理者の一括登録はできない

## コーチの評価画面（`/users/[id]/ratings`）

生徒からのコーチ評価（契約×コーチにつき1回。星1〜5の3項目）と運営へのコメントを確認する画面。コメントはコーチには公開されない。

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「ユーザー管理へ戻る」 | 常時 | `/users` へ戻る |
| 集計カード（総合評価・コーチング・親近感・おすすめ度） | 平均点と星（0.5刻み）。総合評価は3項目の平均で、件数と「3項目の平均（コーチ・生徒に表示）」を添える。おすすめ度は「単独では表示しない」（コーチ・生徒の画面には出さない値）。評価0件は「-」と「評価はまだありません。」。値は `com_t_coach_stats`（コーチ・生徒の画面と同じ値） | — |
| 絞り込み「すべて（n）／コメントあり（n）」 | 常時 | URL の `?feedback=1` で運営へのコメントがある評価だけに絞る |
| 評価の一覧 | 新しい順。評価日時（日本時間）・生徒（氏名・メール）・契約（プラン名・期間）・3項目の点数・平均・運営へのコメント（全文）。移行データ・初期値（新人コーチに自動で入る 4/4/4）は生徒・契約が空で、登録元のバッジ（「移行データ」「初期値」）を出す | 表示のみ（評価の変更・削除はできない） |
| コーチが見つからない | 指定IDがコーチでない・存在しない | 「コーチが見つかりませんでした。」と戻るリンク |

取得は `admin_get_coach_ratings`（アドミン以外は DB 側で拒否。運営へのコメントを含むため、ログイン中のアドミンの JWT で呼ぶ）。
読み込み中は戻るリンク・説明文・表の見出しを本物、コーチ名・集計の数値・行を骨組みで表示する（`users/[id]/ratings/loading.tsx`）。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| データ読み込み中 | スピナー付きプレースホルダー | ユーザー一覧取得中（Suspense） |
| 検索結果が空 | 「データが見つかりませんでした。」 | 検索・フィルタ条件に一致するユーザーが0件の場合 |
| 割当可能なライセンスなし | 選択欄に「割当可能な契約プランがありません」、登録・保存ボタンが非活性 | 対象顧客に有効な契約が無い場合 |
