# タグ管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/contents/tags`
- 対象ロール: システム管理者
- 目的: 教材に設定するタグ（マスタデータ）の登録・編集・削除を行う。教材への割当自体は
  教材管理一覧（`/contents`）のタグ割当ダイアログから行う。

## この画面に来る経路

- 教材管理一覧（`/contents`）ヘッダーの「タグ管理」ボタンから遷移する。

## 画面の構成

1. **ヘッダー** — 「教材管理に戻る」リンク、画面タイトル、説明文、「新規登録」ボタン
2. **一覧テーブル** — 登録済みタグの一覧（検索・種別の絞り込み・ページング付き）
3. **新規登録／編集ダイアログ**（一覧から開く）
4. **削除確認ダイアログ**（一覧から開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索ボックス | 常時表示 | タグ名・タグIDの部分一致で絞り込む（全件を取得済みのため、ブラウザ側で絞る。Enterまたは「検索」ボタンで確定し、URLの`q`に反映する（1ページ目に戻る。サーバーへの再取得はしない）） |
| 種別フィルター | 「すべての種別」＋タグ種別 | 選択した種別で絞り込む（URLの`type`。1ページ目に戻る） |
| 「条件をクリア」ボタン | 常時表示（検索語・絞り込みが無いときは押せない） | 検索語・絞り込み・ページをすべて外し、初期状態の一覧に戻す |
| 件数・ページ送り（前へ・次へ） | 常時表示（「全 n 件」、1ページ10件。先頭・末尾では該当ボタンが無効） | 前後のページへ移る（URLの`page`） |
| SEQ列 | 表示順の数値 | 表示のみ |
| タイプバッジ | 「業界」「シチュエーション」「スキル」「レベル」「その他」のいずれか | 表示のみ |
| タグID列 | タグのUUID | 表示のみ |
| 「編集」ボタン | 各行に表示 | 新規登録と同じダイアログが編集モードで開く |
| 削除ボタン（ゴミ箱アイコン） | 各行に表示 | 確認ダイアログを経て削除する（取り消し不可の操作として案内される） |
| 「新規登録」ボタン | 常時表示 | 新規登録ダイアログを開く |

## 新規登録／編集ダイアログ

- 「登録内容を確認する」ボタンでいったん確認画面に切り替わり、「はい、確定します」で確定する
  2段階の登録フローになっている。
- 入力項目: タグ名称（必須）、タイプ（業界/シチュエーション/スキル/レベル/その他から選択）、
  表示順（数値）。編集モードではタグIDが参考情報として表示される。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 一覧が空 | 「タグデータが見つかりませんでした。」 | 登録されたタグが0件、または検索条件に一致する行がない場合 |
| 登録・更新エラー | 確認画面内にエラーメッセージを表示 | サーバー側で保存に失敗した場合（ダイアログは閉じない） |
