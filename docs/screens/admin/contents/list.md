# 教材管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/contents`
- 対象ロール: システム管理者
- 目的: 学習教材（単語帳・ビデオ・スプリント・ダイアログ）の基本情報・公開範囲・タグ・表示順を管理する。
  教材の中身（単語・フレーズ・問題・セッション等）の編集は教材詳細画面（`/contents/[id]`）で行う。

## この画面に来る経路

- 管理画面のナビゲーションから直接遷移する（詳細な導線は本ドキュメントの対象外）。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「タグ管理」への導線ボタン、「新規登録」ボタン
2. **一覧テーブル** — 教材の一覧（検索・種別フィルター・ページング付き。URLのクエリパラメータ
   `q`/`type`/`page`で状態を保持する。最後の条件はブラウザのタブ単位で記憶され、
   教材詳細画面の「戻る」ボタンで一覧に戻った際に復元される）
   並び順は 種別 → セット分類（ダイアログのみ。Beginner/Intermediate/Advanced/Corpus順）→ 表示順。
3. **新規登録／編集ダイアログ**（一覧から開く。教材の基本情報のみを扱う）
4. **タグ割当ダイアログ**（一覧の各行から開く）
5. **公開先（顧客）割当ダイアログ**（公開範囲が「限定」の行からのみ開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索ボックス | 常時表示 | 教材名・管理ラベルで検索し、Enterまたは「検索」ボタンで一覧を絞り込む（1ページ目に戻る） |
| 種別フィルターセレクト | 常時表示（「すべての種別」がデフォルト） | 選択した種別で一覧をサーバーサイド絞り込みする（1ページ目に戻る） |
| 教材名列 | 教材名称（日本語）、教材名称（英語、任意）、管理ラベルを併記 | エディタがある種別（単語帳/スプリント/ダイアログ）は教材名称がリンクになり、エディタボタンと同じく教材詳細画面へ遷移する（ビデオは表示のみ） |
| 種別バッジ | 「単語帳」「ビデオ」「スプリント」「ダイアログ」のいずれか | 表示のみ |
| 公開範囲表示（共通・非公開） | 公開範囲が「共通」または「非公開」の場合 | クリック不可の表示のみ |
| 公開範囲表示（限定） | 公開範囲が「限定」の場合。割当先が0件だと赤色の警告表示（「公開先を設定してください」） | クリックすると公開先（顧客）割当ダイアログを開く |
| タグ表示 | 割当済みタグをバッジで列挙。未設定時は「未設定」の点線ボタン | クリックするとタグ割当ダイアログを開く |
| 基本情報の編集ボタン（鉛筆アイコン） | 各行に表示（ホバーで「基本情報を編集」） | 新規登録と同じダイアログが編集モードで開く（種別は編集不可） |
| エディタボタン（「単語を編集」/「問題を編集」/「セッションを編集」） | 単語帳・スプリント・ダイアログの行のみ（ビデオはエディタ未実装のため非表示）。色・アイコンは種別バッジと対応（生徒アプリと共通の `getContentTypeConfig` で定義） | 教材詳細画面（`/contents/[id]`）へ遷移する。種別が「スプリント」の場合はメタデータの`question_type`をクエリパラメータに付与して遷移する |
| 「タグ管理」ボタン | 常時表示 | タグ管理画面（`/contents/tags`）へ遷移する |
| 「新規登録」ボタン | 常時表示 | 新規登録ダイアログを開く |

## 新規登録／編集ダイアログ

- 「内容を確認する」ボタンでいったん確認画面（入力値の読み取り専用表示）に切り替わり、
  「はい、確定します」で確定する2段階の登録フローになっている。
- 入力項目: 教材名称（必須）、教材名称（英語・任意。コーチ向け画面で使用し、未入力時は日本語名称が
  表示される）、種別（単語帳/ビデオ/スプリント/ダイアログ。新規時のみ選択可、編集時は変更不可）、公開範囲
  （共通/限定/非公開）、管理ラベル（必須）、CEFRレベル（任意）、表示順（数値）、説明・解析根拠（任意）。
- 種別が「スプリント」の場合、追加で以下の項目が表示される:
  - **スプリント種別**（必須。汎用スプリント／コーパススプリント）
  - コーパススプリントを選んだ場合はさらに、教材テーマ（必須）、
    「問題種別ごとのレベル管理」の有効/無効、対応する問題種別（UG Speed / UG Builders /
    UG Structure / UG Mastery。1つ以上の選択が必須）を設定する
- 種別が「ダイアログ」の場合、追加で**セット分類**（必須。Beginner/Intermediate/Advanced/Corpus）
  の選択が表示される。セット分類はコーチ向け教材選択画面での分類（タブ）に使われ、
  公開範囲とは独立して任意の組み合わせで設定できる。
- 新規登録が成功すると、そのまま教材詳細画面（`/contents/[id]`）へ遷移する。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 一覧が空 | 「教材データが見つかりませんでした。」 | 登録された教材が0件、または検索条件に一致する行がない場合 |
| 登録・更新エラー | 確認画面内にエラーメッセージを表示 | サーバー側で保存に失敗した場合（ダイアログは閉じない） |
