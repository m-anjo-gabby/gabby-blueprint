# 顧客管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/clients`
- 対象ロール: 管理者
- 目的: システムを利用するテナント（法人・個人）の基本情報（`com_m_client`）を一覧・検索し、
  新規登録・編集を行う。

## この画面に来る経路

- サイドバーの「顧客管理」から遷移する。ダッシュボードの「顧客管理」カードからも遷移できる。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「新規登録」ボタン
2. **顧客一覧テーブル** — 検索欄、ページネーション、顧客の一覧表（1ページ10件）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | 顧客名称の部分一致で検索。Enterまたは「検索」ボタンで確定し、URLの`q`に反映する（1ページ目に戻る）。入力した文字はそのまま文字として検索する（`%`・`,`等も特別な意味を持たない） |
| 「条件をクリア」ボタン | 常時表示（検索語・絞り込みが無いときは押せない） | 検索語・絞り込み・ページをすべて外し、初期状態の一覧に戻す |
| 件数・ページ送り（前へ・次へ） | 常時表示（「全 n 件」、1ページ10件。先頭・末尾では該当ボタンが無効） | 前後のページへ移る（URLの`page`） |
| 「新規登録」ボタン | 常時表示 | 新規登録ダイアログを開く |
| 一覧テーブルの「編集」ボタン | 各行に表示 | その顧客の編集ダイアログを、既存値が入力された状態で開く |
| 一覧の各列 | 顧客名称（取引終了の顧客は「取引終了」の目印）、種別（法人／個人）、業界（製薬／半導体／その他／未設定）、登録日。取引中の顧客を先に並べる | 表示のみ |

## 新規登録・編集ダイアログ

- 入力項目: 顧客名称（必須）、顧客種別（法人／個人。選択式）、業界区分（製薬／半導体／その他。
  選択式）、取引状態（編集時のみ。取引中／取引終了。取引を終えた顧客は削除せずに取引終了にする）
- 「登録内容を確認する」（編集時は「編集内容を確認する」）ボタンを押すと、入力値のバリデーションを
  行った上で確認画面に切り替わる（一度画面遷移せず、同じダイアログ内で確認表示に変わる）
- 確認画面では入力内容が読み取り専用で表示され、「いいえ」で入力に戻る、「はい、確定します」で
  送信する
- 送信が成功すると「顧客を登録しました」／「顧客を更新しました」というトースト通知が表示され、
  ダイアログが閉じて一覧が更新される
- 送信が失敗した場合は確認画面内にエラーメッセージが表示される

## 顧客の削除（編集ダイアログの最下部の DangerZone）

- テスト・営業用デモ・誤って作った顧客を、所属するユーザー・契約・ライセンス・セッション・学習の記録・招待・お知らせ・イベントごと
  削除する（取り消せない。システム管理者のみ）
- 「顧客を削除する」で確認ダイアログを開くと、消える件数（生徒・コーチ・招待中・契約・ライセンス・セッション・学習の記録・
  チャットのメッセージ・お知らせ・イベント）を表示する。顧客名を入力すると実行できる
- 削除できない顧客は理由を表示して実行できない: 初期テナント・Webトライアルの顧客／管理者が所属している／
  他の顧客のユーザーとのセッション・担当関係等がある

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 検索結果が空 | 「顧客データが見つかりませんでした。」 | 検索条件に一致する顧客が0件の場合 |
| 送信中 | ボタンが「処理中...」表示になり非活性化 | 登録・更新の確定処理中 |

- `apps/admin/components/list/`（一覧の共通部品: `useListQuery`・`ListToolbar`・`DataTable`・`ListSelectFilter`・`ClientFilter`）, `apps/admin/lib/list.ts`（URLの条件の読み取り・ページ範囲）

- `apps/admin/app/(app)/clients/_components/columns.tsx`
- `apps/admin/actions/adminClientAction.ts`（`getClients`, `createClient`, `updateClient`）
- 対象テーブル: `com_m_client`。編集ダイアログで取引状態（`status`: 取引中 / 取引終了）を変える。取引終了の顧客は一覧に「取引終了」と出る
- 顧客の削除は、編集ダイアログの最下部の DangerZone（`PurgeClientSection.tsx`、`adminDataDeletionAction.ts` の `previewPurgeClient` / `purgeClient`）。
  開いた時に消える件数を表示し、顧客名の入力で確認してから、所属するユーザー・契約・記録ごと削除する（システム管理者のみ。規約は `docs/DATA-DELETION.md` §5）。
  `deleteClient`（契約・ユーザーの無い顧客の物理削除）はこの画面のUIからは呼び出していない
