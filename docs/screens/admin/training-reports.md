# トレーニングレポート（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/training-reports`
- 対象ロール: 管理者
- 目的: 生徒の契約期間（ライセンス）ごとに、トレーニングレポート（PDF）を作成する。満了月を選ぶと、その月に期間が終わる
  ライセンスを契約ごとに一覧し、生徒ごとのPDF、または契約の全員分をまとめたZIPを作る。作ったPDFは、アドミンが受講生本人
  または企業の担当者へ**システム外で**送付する（システム内での配布・通知は無い）。
- 現在はドラフト版（運営確認用）。作成の記録（発行履歴）は残さず、作成のたびに最新のデータからPDFを作る。

## この画面に来る経路

- サイドバーメニューの「サポート」グループ内「トレーニングレポート」から遷移する。

## 画面の構成

1. **見出し** — 画面名、説明、ドラフト版である旨の注記
2. **満了月の切り替え** — 前月・翌月・今月に戻る（URLの `month` に反映）
3. **契約ごとの一覧** — 契約名・顧客・プラン・その月に満了する人数、契約の全員分のZIP作成ボタン、生徒ごとの行

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 満了月の切り替え | 常時表示。既定は**日本時間の今月**（集計期間のタイムゾーン。契約期間は日本時間の日付で作っているため） | 表示する満了月を切り替える。一覧は月ごとに読み込み中の骨組みを出してから表示する |
| 契約の見出し | 満了日がその月（日本時間）にあるライセンスを持つ契約ごと | 契約名と「{顧客} ・ {プラン} ・ この月に満了 n名」を表示 |
| 「契約の全員分をZIPで作成」ボタン | 契約ごと | 満了月を問わず、その契約の**ライセンス保持者全員分**のPDFを1人1ファイルでZIPにまとめてダウンロードする（上限100件）。ファイル名は `Gabbyトレーニングレポート_{契約名}_{作成日}.zip`、同姓同名は連番を付ける |
| 生徒の行 | その月に満了するライセンスごと | 生徒名、期間（日本時間の日付）、状態（有効／停止／満了。有効のまま終了日を過ぎたものも満了）、コーチのコメントの記入状況（ライブ付き契約のみ。未記入／下書き n件／確定 n件。アプリのみの契約は「対象外」） |
| 「PDF」ボタン | 生徒の行ごと | その生徒のレポートをPDFでダウンロードする。ファイル名は `{氏名}様_Gabbyトレーニングレポート_{終了年月}.pdf` |

## PDFの掲載内容

| 区画 | 内容 |
|---|---|
| 基本情報 | 氏名・プラン（生徒に見せるプラン名。管理用の契約名は載せない）・期間 |
| スプリントの到達レベル | 期間の開始時と終了時（終了前に作った場合は作成時点）の問題種別ごとのレベルとステージ。レベルの記録を始める前の時点は「—」 |
| 学習の記録 | 期間合計の学習日数・単語・フレーズ・スプリント（問）・発話評価と、月別の学習日数・単語とフレーズ・スプリント |
| ライブセッション | ライブ付き契約のみ。受講回数（実施／契約回数）・欠席・直前のキャンセル |
| 評価結果 | 準備中（スピーキングテスト・評価AIの作り直し中のため） |
| コーチからのコメント | ライブ付き契約のみ。下書きも「下書き」と表示して載せる |

発行元は日本法人の会社情報（システム設定 > 会社情報）。学習の記録の数え方は
[トレーニング実績の集計](../../../testing/e2e/specs/training/training-stats.md)を参照（期間は日本時間で区切り、各実績は生徒の
タイムゾーンでの実施日で数える。スプリントはドリルの問題数と制限時間ありの回答数の合計）。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 該当なし | 「この月に満了するライセンスはありません。」 | 選んだ月に満了日があるライセンスが無い |
| 取得失敗 | 「一覧の取得に失敗しました。DDL/DMLが反映されているかご確認ください。」 | 一覧のRPCが失敗した |
| 作成失敗 | トースト「レポートの作成に失敗しました。時間をおいて再度お試しください。」 | PDF・ZIPの作成が失敗した |
