# Webトライアル申込（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/trial-applications`
- 対象ロール: 管理者（`admin` ロール）
- 目的: Webトライアルの申込（[student の申込画面](../student/trial.md)）を一覧し、申込者が本登録（パスワード設定）まで進んだかを確かめる。閲覧のみ。

## この画面に来る経路

- サイドバーの「Webトライアル申込」から遷移する。
- 申込のたびに届くアプリ内の通知「Webトライアルの申込」（[notification.md](notification.md)）を押すと、この画面に移る。
- サポート窓口へのメール（申込の内容）の「申込一覧を開く」ボタンからも開ける。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文
2. **申込の一覧テーブル** — 検索欄、状態・業種の絞り込み、条件をクリア、件数・ページ送り、申込の一覧表（1ページ10件、最後に申し込んだ日時の新しい順）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | 氏名（姓 名）・ローマ字の氏名（名 姓）・メールアドレスの部分一致で検索（URLの`q`。1ページ目に戻る） |
| 状態の絞り込み | 常時表示（すべて / 招待中 / 登録済み / 期限切れ） | URLの`status`に反映し、1ページ目に戻る |
| 業種の絞り込み | 常時表示（すべて / 申込フォームの業種・職業の選択肢） | URLの`occupation`（業種のコード）に反映し、1ページ目に戻る |
| 「条件をクリア」・件数・ページ送り | 管理画面の一覧の共通の挙動（[testing/e2e/specs/admin/list-filters.md](../../../testing/e2e/specs/admin/list-filters.md)） | — |
| 申込日時 | 最後に申し込んだ日時（日本時間）。2回目以降は「n回目の申込」を併記 | 表示のみ |
| 氏名 | 氏名（姓 名）・ローマ字の氏名（名 姓。本登録後の画面の名前と同じ）・メールアドレス。ユーザーがいる（本登録済み・登録済みのアドレス）場合、氏名はユーザー詳細へのリンク | 氏名のリンクでユーザー詳細（[users.md](users.md)）へ |
| 業種・職業 | 選択肢の名前（「その他」は記入内容を括弧で併記）。表示言語に合わせる | 表示のみ |
| 国・都市 / タイムゾーン | 入力された国・都市（無ければ「—」）と、選んだタイムゾーン | 表示のみ |
| ご要望・ご質問 | 3行まで表示（全文はマウスを重ねると出る）。無ければ「—」 | 表示のみ |
| 状態 | 下表のバッジ。登録済みは本登録の日時、招待中は招待の有効期限を併記 | 表示のみ |

### 状態

| 状態 | 条件 |
|---|---|
| 登録済み | 本登録（パスワード設定）が済んだ、または登録済みのアドレスからの申込（アカウントがある） |
| 招待中 | 招待が本登録前で、有効期限（送信から3日）内 |
| 期限切れ | それ以外（招待の期限切れ、トライアル以外の招待中のアドレスからの申込等） |

- 期限切れの申込者が再度申し込むと、招待を出し直して「招待中」に戻る。

## 文言
