# プランマスタ管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/contracts/plans`
- 対象ロール: 管理者
- 目的: 契約作成時に選択できる契約プランのマスタデータを管理する。プランを1つ選ぶだけで
  「コーチ有無・週回数・チケット数・ダイアログプラクティス提供有無」が一意に決まるようにするための
  マスタ登録画面。

## この画面に来る経路

- [契約管理画面](list.md)の「プランマスタ管理」リンクから遷移する。独立したサイドバー項目としては
  存在しない。

## 画面の構成

1. **ヘッダー** — 「契約管理に戻る」リンク、画面タイトル、説明文、「新規登録」ボタン
2. **プラン一覧テーブル** — 検索欄（クライアント側フィルタ）、ページネーション、プラン一覧表

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「契約管理に戻る」リンク | 常時表示 | `/contracts` へ遷移 |
| 検索欄 | 常時表示 | プラン名・コードで一覧をその場で絞り込む（サーバー再取得なし） |
| 「新規登録」ボタン | 常時表示 | プラン登録ダイアログを開く |
| 一覧の「SEQ」列 | 表示順（`sort_no`） | 表示のみ |
| 一覧の「プラン名」列 | 日本語名・英語名 | 表示のみ |
| 一覧の「構成」列 | コーチ無しの場合は「コーチ無し」バッジ。コーチ有りの場合は「週n回・全n回」バッジと、ダイアログプラクティス提供ありなら追加バッジ | 表示のみ |
| 一覧の「標準期間」列 | 標準契約期間（月数） | 表示のみ |
| 一覧の「プランコード」列 | システム内部識別用コード | 表示のみ |
| 一覧の「編集」ボタン | 各行に表示 | プラン編集ダイアログを既存値付きで開く |
| 一覧の削除ボタン（ゴミ箱アイコン） | 各行に表示 | 確認ダイアログの上でプランを削除する |

## プラン登録・編集ダイアログ

- 入力項目: プラン名（日本語・英語）、プランコード、コーチとのライブセッション有無（選択式）、
  標準契約期間（月数）、表示順
- 「コーチとのライブセッション」を「有り」にした場合のみ、週回数・チケット数・ダイアログ
  プラクティス提供有無の入力欄が表示され、両方とも1以上の数値が必須になる
- 「登録内容を確認する」で確認画面に切り替わり、「はい、確定します」で送信する

## プラン削除

- 確認ダイアログで「削除する」を押すとプランを削除する
- 既にそのプランを選んで作成済みの契約には影響しない（契約側にはプラン名等の値がコピー済みのため）。
  削除すると今後の契約作成時の選択肢から消えるのみ

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 一覧が空 | 「プランデータが見つかりませんでした。」 | 検索条件に一致するプランが0件の場合 |
