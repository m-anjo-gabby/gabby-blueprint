# 契約管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/contracts`
- 対象ロール: 管理者
- 目的: 顧客ごとの契約（プラン・契約期間・上限ライセンス数）を一覧・検索し、契約の登録・編集・
  削除、およびライセンス（ユーザーへの利用枠）の割当・無効化を行う。

## この画面に来る経路

- サイドバーの「契約管理」から遷移する。ダッシュボードの「契約管理」カードからも遷移できる。
- 「プランマスタ管理」リンクから `/contracts/plans`（[別紙](plans.md)）へ遷移できる。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「プランマスタ管理」リンク、「新規登録」ボタン
2. **契約一覧テーブル** — 検索欄、顧客フィルタ、ページネーション、契約の一覧表（1ページ10件）
3. **ライセンス割当ダイアログ**（一覧の「ライセンス利用状況」欄から開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | 顧客名の部分一致で検索。Enterまたは「検索」ボタンで実行し、1ページ目に戻る |
| 顧客フィルタ | 常時表示 | 検索式セレクトで顧客を選択して絞り込む（未選択時は「すべての顧客」で全件対象）。選択すると1ページ目に戻る |
| 「プランマスタ管理」リンク | 常時表示 | `/contracts/plans` へ遷移 |
| 「新規登録」ボタン | 常時表示 | 契約登録ダイアログを開く |
| 一覧の「顧客名」列 | 契約に紐づく顧客名。紐付けが取れない場合は「未紐付け」 | 表示のみ |
| 一覧の「プラン」列 | プラン名。ライブセッション付きプランの場合は「ライブ週n回・全n回」バッジ、ダイアログプラクティス提供ありの場合は追加バッジを表示 | 表示のみ |
| 一覧の「ライセンス利用状況」列 | 割当実績数／上限ライセンス数と進捗バー。割当数が上限を超えている場合は警告色＋「※超過」表示 | クリックでライセンス割当ダイアログを開く |
| 一覧の「契約期間」列 | 開始日・終了日 | 表示のみ |
| 一覧の「ステータス」列 | 「停止中」「解約済」「期間終了」「開始待ち」「稼働中」のいずれかを契約ステータスと期間から算出して表示 | 表示のみ |
| 一覧の「編集」ボタン | 各行に表示 | 契約編集ダイアログを既存値付きで開く |
| 一覧の削除ボタン（ゴミ箱アイコン） | ライセンス割当実績（`current_assigned_count`）が0件の契約のみ活性。実績がある契約は非活性でツールチップ「ライセンスが割り当てられているため削除できません」 | クリックで削除確認ダイアログを開く |

## 契約ステータスの表示ロジック

- DBのステータスが「無効」または「解約」の場合はそれをそのまま優先表示する
- 「有効」ステータスでも、契約終了日が過去なら「期間終了」、契約開始日が未来なら「開始待ち」、
  それ以外は「稼働中」と表示する（DBのステータス値と画面表示が一致しない場合がある点に注意）

## 契約登録・編集ダイアログ

- 入力項目: 対象顧客（検索式セレクト。編集時は変更不可）、プラン（選択式。選ぶとプラン名・週回数・
  チケット数・ダイアログプラクティス提供有無が初期値としてセットされ、開始日=本日・終了日=本日
  からプランの標準契約期間分先が提案される。いずれも個別に上書き可能）、プラン名（日本語・英語）、
  上限ライセンス数、契約開始日・終了日、ステータス（編集時のみ変更可。有効／無効／解約）、備考
- ライブセッション付きプランを選んだ場合のみ、週回数・チケット数・ダイアログプラクティス提供有無の
  入力欄が追加表示される
- 終了日は開始日以降でなければならない（不正な場合は画面上でエラー表示）
- 「登録内容を確認する」で確認画面に切り替わり、「はい、確定します」で送信する
- 新規登録時は必ずステータス「有効」で作成される

## ライセンス割当ダイアログ

- ヘッダーに「割当数 / 上限数」を表示
- 一覧モード: 割当済みユーザーの一覧（氏名・メールアドレス、無効化済みは「無効化済み」バッジと
  グレー表示。ライブセッション付き契約の場合はチケット消化数も表示）
- 「ユーザーを追加」ボタン（契約期間終了後は非表示）→ 追加モードに切り替わり、同じ顧客に属する
  未割当ユーザーの一覧から選んで追加する。上限に達している場合は追加不可
- 各ユーザーの無効化ボタン（契約期間終了後、または既に無効化済みの場合は非表示）→ 確認ダイアログの
  上でライセンスを無効化する。無効化すると即座にシステムアクセス不可・未実施の今後のセッションは
  キャンセルされるが、実施済みのセッション履歴・チャット・宿題は削除されず、チケット消化数も戻らない
- 無効化されたライセンスも「消化済み」として扱われ、枠（上限ライセンス数の消費）は戻らない

## 契約削除ダイアログ

- 通常の削除: 確認ダイアログで「削除する」を押すと契約を削除する。取り消し不可
- ライセンス割当実績がある契約は、削除ボタン自体が非活性になっており、通常削除は行えない
  （誤操作防止のための設計であり、そもそもダイアログを開けない）
- サーバー側が「履歴あり」で削除を拒否した場合（想定外のケース）は、「履歴ごと完全に削除する」
  エスカレーション画面が表示される。これは契約本体・割当済みライセンス・割当解除履歴・ライブ
  セッションチケットの発行消化履歴を全て復元不能に削除するもので、実運用契約には使用してはならない
  操作。実行にはプラン名の入力による確認が必要

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 検索結果が空 | 「一致する契約情報が見つかりませんでした。」 | 検索条件に一致する契約が0件の場合 |
| ライセンス一覧が空 | 「現在、割当はありません」 | 割当済みユーザーが0人の場合 |
| 追加対象ユーザーなし | 「追加可能なユーザーがいません」 | その顧客の全ユーザーが割当済み、またはユーザー未登録の場合 |
