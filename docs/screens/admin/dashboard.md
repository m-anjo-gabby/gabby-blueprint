# ダッシュボード（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/dashboard`
- 対象ロール: 管理者（サイドバーで各モジュールへのアクセス権を持つロール）
- 目的: 顧客・契約・ユーザー・教材・お知らせという主要5モジュールについて、登録件数と
  「対応が必要な件数」を一覧表示し、対応が必要な画面へすぐ遷移できるようにする。

## この画面に来る経路

- ログイン後の初期画面。サイドバーの「ダッシュボード」からも遷移できる。

## 画面の構成

1. **ヘッダー** — 画面タイトルと説明文のみ（操作要素なし）
2. **モジュールカードのグリッド** — ログインユーザーが閲覧権限を持つモジュールのみ、カードとして
   表示される（権限がないモジュールのカードはそもそも表示されず、件数の取得も行われない）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 顧客管理カード | `/clients`への閲覧権限がある場合 | クリックで`/clients`へ遷移。件数は削除されていない顧客の総数、要対応件数は「有効な契約（ステータスが有効かつ契約終了日が未来）を1件も持たない顧客数」 |
| 契約管理カード | `/contracts`への閲覧権限がある場合 | クリックで`/contracts`へ遷移。件数はステータスが有効な契約の総数、要対応件数は「30日以内に契約終了日を迎える契約」または「割当済みライセンス数が上限を超過している契約」の件数 |
| ユーザー管理カード | `/users`への閲覧権限がある場合 | クリックで`/users`へ遷移。件数は総ユーザー数、要対応件数は招待状態が「招待中」「招待期限切れ」「招待メール送信失敗」のいずれかのユーザー数 |
| 教材管理カード | `/contents`への閲覧権限がある場合 | クリックで`/contents`へ遷移。件数は削除されていない教材の総数、要対応件数は非公開（`content_scope`が限定公開）の教材数 |
| お知らせ管理カード | `/notice`への閲覧権限がある場合 | クリックで`/notice`へ遷移。件数は公開中のお知らせ数、要対応件数は「下書き」または「公開中だが掲載期限切れ」のお知らせ数の合計 |
| カード内の「問題なし」バッジ | 要対応件数が0件のカード | 緑色のチェックマーク付きバッジを表示 |
| カード内の要対応バッジ | 要対応件数が1件以上のカード | 「〇〇 n件」という黄色バッジを表示 |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| カードなし | 「表示できる管理項目がありません」 | ログインユーザーがいずれのモジュールにも閲覧権限を持たない場合 |
| 個別モジュールの取得失敗 | 該当カードの件数・要対応件数が0として表示される（画面全体はエラーにならない） | 該当モジュールの集計クエリが失敗した場合。他モジュールの表示には影響しない |
