# 音声機能検証ページ（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/speachPoc`（実装ディレクトリ名がこの綴りになっている。"speech PoC"の誤記と
  思われるが、実際のルートがこの綴りなのでURLもこのまま）
- 対象ロール: ログイン済みの管理者であれば誰でも到達可能（サイドバーメニューには存在せず、
  URLを直接開いた場合のみ表示される検証用ページ）
- 目的: Azure Speech SDKとブラウザ標準のWeb Speech APIについて、読み上げ（TTS）と発音評価
  （STT／Pronunciation Assessment）の挙動・精度を比較検証するための内部PoCツール。

## この画面に来る経路

- サイドバーメニューからは到達できない。URLを直接開く必要がある。

## 画面の構成

1. **タブ切り替え** — 「読み上げテスト (TTS)」／「発音評価テスト (STT)」
2. **読み上げテスト (TTS)タブ** — サンプル文選択・自由入力欄、Azure TTS（音声・スタイル選択＋
   再生ボタン）とWeb Speech（再生ボタンのみ）の左右比較
3. **発音評価テスト (STT)タブ** — サンプル文選択・自由入力欄、Azure Assessment
   （録音開始→自動評価）とWeb Speech（自作評価ロジック）の左右比較

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| サンプル文プルダウン | 両タブに表示 | 選択するとテキストエリアの内容が置き換わる（その後自由に編集可能） |
| Voice／Styleプルダウン | TTSタブのAzure側のみ | 再生時に反映される |
| 「Azureで再生」ボタン | TTSタブ | Azure Speech SDKで指定テキストを読み上げる。再生中はボタンが無効化される |
| 「ブラウザで再生」ボタン | TTSタブ | ブラウザ標準のWeb Speech APIで読み上げる |
| 「Azure評価を開始」ボタン | STTタブ | マイクの使用許可を求めた上で7秒間録音し、Azureの発音評価（総合スコア）を実行する。録音中はボタンが「録音中... (n秒)」の残り秒数表示に変わる |
| 「自作評価を開始」ボタン | STTタブ | ブラウザのWeb Speech APIを使った自作の評価ロジックでスコアと講評を表示する |
| 「結果をクリア」リンク | STTタブ | Azure側・自作側の両方の評価結果を消去する |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| Azure評価結果あり | 「総合スコア: {点数}」のみ表示 | Azureの発音評価が完了した場合。単語単位の詳細（強勢・音素スコア等）は取得はしているが画面には表示されていない |
| 自作評価結果あり | スコア（0〜100に換算した数値）と講評テキスト | Web Speechベースの自作評価が完了した場合 |
| 録音タイムアウト | 自動的に録音を終了する | 開始から7秒経過した場合（Azure・自作どちらも共通の設計） |

## 実装参照（エンジニア向け）

- `apps/admin/app/(app)/speachPoc/page.tsx`（`_components/`ディレクトリは存在せず、単一ファイル
  構成）
- `apps/admin/hooks/useAzureSpeechTest.ts`（Azure Speech SDKによるTTS・発音評価のロジック）
- `packages/lib/hooks/useWebSpeech`（ブラウザ標準Web Speech APIによるTTS・自作評価ロジック）

## 気づいた点（実装の粗さ）

- `useAzureSpeechTest`はブラウザ側（クライアントコンポーネント）で
  `process.env.AZURE_SPEECH_SERVICE_KEY`を直接参照しているが、`apps/admin/next.config.ts`には
  このキーをクライアントに公開する設定（`NEXT_PUBLIC_`接頭辞や`env`設定）が見当たらない。
  実際にAzureボタンが動作しているか（＝この画面がまだ機能しているか）は要確認。
- Azure発音評価は単語単位の結果（`assessmentData`、`AssessmentWord[]`）を`useMemo`で算出して
  いるが、画面上には表示されていない（総合スコアのみ表示）。録音した音声のURL
  （`recordedAudioUrl`）も取得しているが再生UIは無い。実装途中、または他画面向けの検証用
  ロジックを転用した名残と思われる。
