# チャットルーム（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/chat/[roomId]`
- 対象ロール: システム管理者
- 目的: 個別のチャットルーム（1対1／グループ）のメッセージ履歴を表示し、自分が参加している
  ルームであればメッセージ送信を行う。参加していないルームも「査閲モード」として内容を閲覧できる。
- `md` 以上ではチャット一覧（[list.md](list.md)）の右ペインに表示し、左の一覧は表示したまま。
  画面幅が `2xl` 以上の場合は、さらに右側にルーム情報パネル（3ペイン目）を常に表示する。

## この画面に来る経路

- チャット一覧（`/chat`）のルーム行をクリックして遷移する。
- 新規チャット作成ダイアログでルームを作成すると、自動的にこの画面へ遷移する。

## 画面の構成

1. **ヘッダー** — 一覧へ戻るボタン（`md` 未満のみ）、相手（または相手一覧・ルーム名）の表示、
   査閲モードの場合はその旨のバッジ、「ルーム情報」ボタン（`2xl` 未満のみ）
2. **タイムライン** — メッセージを時系列（古い→新しい）で表示。上端まで到達すると過去メッセージを
   自動で追加読み込みする
3. **メッセージ入力欄** — 自分が参加しているルームでのみ表示される。参加していない場合は
   「閲覧のみ可能」の案内文に置き換わる
4. **ルーム情報パネル** — `2xl` 以上はタイムラインの右に常設、`2xl` 未満は「ルーム情報」ボタンで
   右からシートとして開く。種別・作成日・参加者一覧、グループの場合は参加者の追加・削除（Adminのみ）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 一覧へ戻るボタン | `md` 未満のみ表示 | チャット一覧（`/chat`）へ遷移する |
| 査閲モードバッジ | ログイン中の管理者がそのルームの参加者ではない場合 | 表示のみ。参加者全員の氏名・種別が併記される |
| 「ルーム情報」ボタン（iアイコン） | `2xl` 未満のみ表示 | ルーム情報パネルを右からシートで開く |
| 「ここから未読」の区切り線 | ルームを開いた時点で未読メッセージがある場合、最初の未読メッセージの上に表示 | 開いた直後はこの区切り線の位置から表示する |
| 「最新のメッセージへ」ボタン | 最新メッセージから離れて過去のメッセージを見ている間に表示。その間に届いた新着がある場合は「新着メッセージ N件」と表示 | クリックすると最新メッセージまでスクロールする |
| メッセージ本文 | 通常のテキストメッセージ | URLは自動的にリンク化される |
| 画像添付 | 画像ファイルが添付されたメッセージ | サムネイル表示され、クリックで元画像を新しいタブで開く |
| ファイル添付（画像以外） | ファイルが添付されたメッセージ | ファイル名・サイズが表示され、クリックでダウンロード用リンクを新しいタブで開く |
| メッセージの削除アイコン（ゴミ箱） | 未削除のメッセージにカーソルを合わせた時、管理者は自分・他人を問わず全メッセージに対して表示される | 確認ダイアログの上で論理削除する。削除後は本文・添付が消え「このメッセージは削除されました」表示に置き換わる（元に戻せない） |
| メッセージ入力欄 | 自分がそのルームの参加者である場合のみ表示。改行・折り返しに合わせて高さが伸び、10行（スマートフォンは5行）を超えると入力欄の中でスクロールする | テキストを入力しEnter（Shift+Enterで改行。日本語入力の変換確定のEnterでは送信しない。タッチ端末ではEnterは改行）または送信ボタンで送信する。入力中の本文・送信前の添付はルームごとに保持し、別のルームを開いてから戻っても残る |
| 添付ファイルボタン（クリップアイコン） | メッセージ入力欄の左に常時表示 | ファイルを選択してアップロードし、送信待ちの添付として表示する（1ファイル10MBまで。複数選択可） |
| 送信待ち添付の削除（×） | 添付ファイルを選択した直後 | 送信前であればその添付を取り消せる |

## ルーム情報パネル

- 種別（1対1／グループ）、作成日、参加者一覧（名前・種別・所属顧客）を表示する。
- グループチャットの場合（Adminのみ）は、参加者の管理を行える。
  - 各参加者にゴミ箱アイコンで削除操作ができる（削除前に確認ダイアログが出る）。
  - グループの参加者は最低2名を下回る削除はできない（ボタンが無効化される）。
  - 「参加者を追加」を押すと追加欄が開き、ユーザー種別（Admin/生徒/コーチ）で絞り込み、生徒の場合は
    さらに所属顧客で絞り込んでから対象者を選び「追加」する。既にルームに参加しているユーザーは候補に出ない。
  - 追加・削除の後は、ヘッダー・パネルの参加者表示が最新の状態に更新される。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| ルームが存在しない | 404（Not Found） | 指定したroomIdのルームが存在しない場合 |
| 読み込み中 | チャットの骨組み（ヘッダーと吹き出しの形） | ルームを開いてから表示されるまでの間 |
| 過去メッセージ読み込み中 | タイムライン上部にスピナー | 上端までスクロールし追加取得している間 |
| 添付ファイル読み込み中 | 添付表示位置にスピナー | 添付ファイルの参照URLを取得している間 |
| 添付ファイル取得失敗 | 「添付ファイルの取得に失敗しました」 | URL取得に失敗した場合 |
| 参加者ではない（査閲モード） | 入力欄が「このルームの参加者ではないため、閲覧のみ可能です（発言はできません）」という案内に置き換わる | ログイン中の管理者がそのルームのメンバーではない場合 |
