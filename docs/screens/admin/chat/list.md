# チャット一覧（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/chat`
- 対象ロール: システム管理者
- 目的: コーチ・生徒間の1対1チャット／グループチャットのルーム一覧を表示し、新規ルームの
  作成、および自分が参加していないルームも含めた全ルームの内容確認（査閲）を行う。
  チャットルームの新規作成はAdminのみが行える。

## この画面に来る経路

- 管理画面のナビゲーションから直接遷移する（詳細な導線は本ドキュメントの対象外）。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文
2. **表示モード切り替え** — 「自分のチャット」／「全チャットルーム（査閲）」の切り替えタブ
3. **顧客フィルター** — 一覧に含まれる生徒の所属顧客で絞り込むプルダウン
4. **「新規チャット作成」ボタン**
5. **ルーム一覧** — 各ルームへのリンク（クリックでチャットルーム画面へ遷移）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「自分のチャット」タブ | 常時表示 | 自分が参加しているルームのみを一覧表示する（初期表示） |
| 「全チャットルーム（査閲）」タブ | 常時表示 | 自分が参加していないルームも含めた全ルームを一覧表示する |
| 顧客フィルター | 常時表示 | 一覧に含まれる生徒の所属顧客の一覧から選択し、その顧客の生徒が参加しているルームのみに絞り込む |
| ルーム行のアイコン | グループは緑の人型アイコン、1対1で自分が参加しているルームは相手のプロフィール画像（未設定時はアイコン）、1対1で自分が参加していないルームは両者名を「⇔」で連結した表示 | 表示のみ |
| ルーム行の種別ラベル | グループは「グループ」、1対1で自分が参加している相手には種別（コーチ/生徒等）、参加していないルームには「非参加」バッジ | 表示のみ |
| 未読件数バッジ | 未読メッセージがある場合、赤い丸に件数（99件超は「99+」） | 表示のみ |
| ルーム行のプレビュー | 最新メッセージの内容を1行で表示（画像は「📷 画像」、ファイルは「📎 ファイル」、削除済みは「（このメッセージは削除されました）」、メッセージが1件もない場合は「メッセージはまだありません」） | クリックでそのルームのチャットルーム画面へ遷移する |
| 「新規チャット作成」ボタン | 常時表示 | 新規チャット作成ダイアログを開く |

## 新規チャット作成ダイアログ

- ルーム種別を「1対1」「グループ」のタブで選択する。
- **1対1**: Admin・コーチ・生徒の中から異なる2名を選択する（種別の組み合わせは自由）。
  生徒を選ぶ場合は所属顧客で絞り込める。同一ユーザーを2箇所に選ぶとエラーメッセージが表示される。
- **グループ**: ルーム名（必須）と参加者2名以上（Admin・コーチ・生徒から種別を問わず複数選択）
  を指定する。参加者が2名未満の間はエラーメッセージが表示される。
- 「作成する」で確定すると、作成したルームのチャットルーム画面（`/chat/[roomId]`）へ遷移する。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| ルーム一覧が空 | 「チャットルームがありません」（顧客フィルター適用中は「該当する顧客のチャットルームがありません」） | 表示対象のルームが0件の場合 |
