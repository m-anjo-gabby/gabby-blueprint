# チャット一覧（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/chat`
- 対象ロール: システム管理者
- 目的: コーチ・生徒間の1対1チャット／グループチャットのルーム一覧を表示し、新規ルームの
  作成、および自分が参加していないルームも含めた全ルームの内容確認（査閲）を行う。
  チャットルームの新規作成はAdminのみが行える（生徒×コーチの1対1ルームは、マッチング成立時にも
  自動で開設される。下記「マッチング成立時の自動開設」参照）。
- チャットは2ペイン表示。`md` 以上では左にルーム一覧、右に選択中のルーム（[room.md](room.md)）を
  並べる。`md` 未満では一覧だけを表示し、ルームを選ぶとルーム画面に切り替わる。

## この画面に来る経路

- 管理画面のナビゲーションから直接遷移する（詳細な導線は本ドキュメントの対象外）。

## 画面の構成

1. **左ペイン（ルーム一覧）**
   1. 見出し「チャット」と「新規チャット作成」ボタン
   2. 検索欄 — 「名前・メッセージを検索」
   3. 絞り込み — 「すべて」「未読」の切り替え
   4. 表示モード切り替え — 「自分のチャット」／「全ルーム（査閲）」の切り替え
   5. 顧客フィルター — 一覧に含まれる生徒の所属顧客で絞り込むプルダウン
   6. ルーム一覧 — 各ルームへのリンク（クリックで右ペインにルームを表示）
2. **右ペイン（`md` 以上）** — ルーム未選択時は「チャットを選択してください」の案内。ルームを選ぶと
   チャットルーム（[room.md](room.md)）を表示する

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索欄 | 常時表示 | ルーム名・参加者名・最新メッセージの本文に部分一致で絞り込む（大文字小文字を区別しない）。×ボタンで入力をクリア |
| 「すべて」「未読」 | 常時表示。「未読」には未読のあるルーム数を赤いバッジで表示 | 「未読」を選ぶと未読メッセージのあるルームだけを表示する（開いているルームは既読になっても表示し続ける） |
| 「自分のチャット」タブ | 常時表示 | 自分が参加しているルームのみを一覧表示する（初期表示） |
| 「全ルーム（査閲）」タブ | 常時表示 | 自分が参加していないルームも含めた全ルームを一覧表示する |
| 顧客フィルター | 常時表示 | 一覧に含まれる生徒の所属顧客の一覧から選択し、その顧客の生徒が参加しているルームのみに絞り込む |
| ルーム行のアイコン・名前 | グループは人々アイコンとルーム名、1対1で自分が参加しているルームは相手のプロフィール画像（未設定時はアイコン）と名前、自分が参加していないルームは盾アイコン（黄）と両者名を「⇔」で連結した表示 | 表示のみ |
| ルーム行の種別ラベル | グループは「グループ」、1対1で自分が参加している相手には種別（コーチ/生徒等）、参加していないルームには「非参加」バッジ | 表示のみ |
| 未読件数バッジ | 未読メッセージがある場合、赤い丸に件数（99件超は「99+」） | 表示のみ |
| ルーム行のプレビュー | 最新メッセージの内容を1行で表示（画像は「📷 画像」、ファイルは「📎 ファイル」、削除済みは「（このメッセージは削除されました）」、メッセージが1件もない場合は「メッセージはまだありません」） | クリックでそのルームを開く（開いているルームの行は淡い青で強調する） |
| 一覧のリアルタイム更新 | 「自分のチャット」表示中に、参加中のルームへ新着メッセージが届いた場合 | そのルームを一覧の先頭へ移動し、プレビュー・時刻を更新する。開いていないルームは未読件数を1増やす（「全ルーム（査閲）」はタブを切り替えた時点の内容を表示し、自動更新しない） |
| キーボード操作 | 常時 | Alt + ↑／↓ で、表示中の一覧の前後のルームを開く |
| 「新規チャット作成」ボタン | 常時表示 | 新規チャット作成ダイアログを開く |

## 新規チャット作成ダイアログ

- ルーム種別を「1対1」「グループ」のタブで選択する。
- **1対1**: Admin・コーチ・生徒の中から異なる2名を選択する（種別の組み合わせは自由）。
  生徒を選ぶ場合は所属顧客で絞り込める。同一ユーザーを2箇所に選ぶとエラーメッセージが表示される。
- **グループ**: ルーム名（必須）と参加者2名以上（Admin・コーチ・生徒から種別を問わず複数選択）
  を指定する。参加者が2名未満の間はエラーメッセージが表示される。
- 「作成する」で確定すると、作成したルームのチャットルーム画面（`/chat/[roomId]`）へ遷移する。
- 1対1で、選んだ2名の有効なルーム（閉じられておらず、2名だけが在室中）が既にある場合は、新しく作らず
  そのルームへ遷移する。

## マッチング成立時の自動開設

- マッチングが成立するたびに（コーチの承認・管理者の直接マッチング。コーチ交代後の再マッチングを含む）、
  生徒×コーチの1対1ルームを用意し（既にあればそれを使う）、コーチから生徒へ挨拶メッセージを自動送信する。
  生徒にはチャット新着の通知が届く。
- 挨拶の文面は、同じ2名の過去の担当枠（終了済みを含む）の有無で出し分ける（`Hi, <生徒名>!` に続けて）。

  | 条件 | 文面 |
  |---|---|
  | 初めての担当 | Thank you for choosing me as your Gabby Coach! See you in the first live Coaching session. |
  | 同じ契約で別のコマも担当 | Thank you for choosing me for another weekly session! See you in the live Coaching session. |
  | 前の契約でも担当していた（更新） | Thank you for continuing your live Coaching sessions with me! See you in the next session. |

- 生徒名は登録名（`com_m_user.user_name`）をそのまま使う。コーチ交代後も旧コーチとのルームは閉じない。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| ルーム一覧が空 | 「チャットルームがありません」（顧客フィルター適用中は「該当する顧客のチャットルームがありません」） | 表示対象のルームが0件の場合 |
| 検索・未読の絞り込みで0件 | 「該当するチャットルームがありません」 | 検索語または「未読」の絞り込みに該当するルームが無い場合 |
| ルーム未選択（右ペイン） | 「チャットを選択してください」「左の一覧からルームを選ぶと、ここにメッセージが表示されます。」 | `md` 以上で `/chat` を開いている場合 |
