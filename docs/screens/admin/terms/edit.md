# 規約編集（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/terms/[id]/edit`
- 対象ロール: `admin`
- 目的: 既存の規約バージョン（利用規約／プライバシーポリシー）の本文を修正し、修正履歴
  （リビジョン）を確認する。

## この画面に来る経路

- 規約管理一覧（[`list.md`](list.md)、`/terms`）の各行の編集アイコンから遷移する。

## 修正の扱い（サイレント更新）

- 保存するたびに新しいリビジョンが追加され、以後その本文が生徒アプリに表示される。
  同意の単位（バージョン）は変わらないため、ユーザーへの再同意は求めない。
- 過去のリビジョンは変更・削除されず、すべて修正履歴として残る。
- 再同意が必要な変更（料金改定・免責事項・個人情報の取扱変更など）は、この画面ではなく一覧画面から
  新しいバージョンとして作成する。

## 画面の構成

1. **ヘッダー** — 一覧に戻るリンク、「規約編集: {バージョン名}」の見出し、説明文
2. **ツールバー** — 編集／プレビュー／修正履歴の切り替えと「修正を保存」ボタン
3. **案内・修正理由欄**（編集・プレビュー時のみ） — 保存時の扱いの案内文と修正理由の入力欄
4. **メインエリア** — Markdownのテキストエリア、プレビュー、または修正履歴

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「規約管理一覧に戻る」リンク | 常時表示 | `/terms`（一覧画面）に遷移する |
| 編集／プレビュー切り替え | 常時表示 | 「編集」でMarkdownのテキストエリア、「プレビュー」で整形済み本文の表示に切り替わる（切り替えのみでデータの保存は行わない） |
| 「修正履歴 (件数)」切り替え | 常時表示 | リビジョンの一覧（番号・登録日時・登録者・修正理由、最新に「現行」バッジ）と、選択したリビジョンの本文（閲覧のみ）を表示する |
| 案内文 | 編集・プレビュー時。公開済みなら「再同意なしで即時反映される／再同意が必要な変更は新バージョンで作成する」旨、公開前なら「公開開始日から表示される」旨 | — |
| 修正理由 | 編集・プレビュー時。公開済みのバージョンでは「必須」、公開前は「任意」（最大200文字） | 入力値はリビジョンの修正理由として記録される |
| 本文テキストエリア | 「編集」モード時に表示。初期値は最新リビジョンの本文 | 自由にMarkdownを編集できる |
| 「修正を保存」ボタン | 修正履歴表示中以外。本文が最新リビジョンから変更されていない間、および公開済みで修正理由が未入力の間は無効化される | 新しいリビジョンを追加し、「規約を修正しました（リビジョン n）」を表示して画面を最新状態に更新する |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 保存中 | 「修正を保存」ボタンがローディング表示になる | 保存処理の実行中 |
| 保存エラー | 「公開済みの規約を修正する場合は、修正理由を入力してください」／「現行の本文から変更されていません」等のトースト | サーバー側（RPC）の検証で拒否された場合 |
| データ取得失敗 | 「データの読み込みに失敗しました。時間をおいて再度お試しください。」 | 規約データの取得中に例外が発生した場合 |
| 規約が存在しない | Next.jsの標準not-foundページ | 指定したIDの規約が存在しない場合 |

## 実装参照（エンジニア向け）

- `apps/admin/app/(app)/terms/[id]/edit/page.tsx`
- `apps/admin/app/(app)/terms/[id]/edit/_components/TermEditor.tsx`
- `packages/lib/components/term/TermViewer.tsx`（プレビュー・履歴表示に使用）
- `apps/admin/actions/adminTermAction.ts`（`getTermDetail`, `addTermRevision`）
- RPC `add_term_revision`（`supabase/DDL/function/add_term_revision.sql`）。採番・修正理由必須判定・
  本文未変更の拒否はRPC側で行う
- `com_m_terms_revision` は追記専用（UPDATEはトリガーで拒否）。生徒の同意記録
  （`com_t_user_terms_agreement.revision_id`）には同意時点で表示していたリビジョンが記録される
- 備考: バージョン名・公開開始日・同意必須はこの画面からは変更できない
