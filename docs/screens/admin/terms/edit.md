# 規約編集（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/terms/[id]/edit`
- 対象ロール: `admin`
- 目的: 既存の規約バージョン（利用規約／プライバシーポリシー）の本文を編集・保存する。

## この画面に来る経路

- 規約管理一覧（[`list.md`](list.md)、`/terms`）の各行の編集アイコンから遷移する。

## 画面の構成

1. **ヘッダー** — 一覧に戻るリンク、「規約編集: {バージョン名}」の見出し、規約種別の説明文
2. **エディタ** — 編集／プレビュー切り替えタブと、Markdown本文のテキストエリア（または
   プレビュー表示）、「保存する」ボタン

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「規約管理一覧に戻る」リンク | 常時表示 | `/terms`（一覧画面）に遷移する |
| 編集／プレビュー切り替え | 常時表示 | 「編集」でMarkdownのテキストエリア、「プレビュー」で整形済み本文の表示に切り替わる（切り替えのみでデータの保存は行わない） |
| 本文テキストエリア | 「編集」モード時に表示 | 自由にMarkdownを編集できる |
| 「保存する」ボタン | 常時表示。本文を初期値から変更していない間は無効化される | クリックすると本文をStorageに新規ファイルとしてアップロードし、DBのバージョン名・保存先パスを更新する。保存後、古い本文ファイルはStorageから削除される |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 保存中 | 「保存する」ボタンがローディング表示になる | 保存処理の実行中 |
| データ取得失敗 | 「データの読み込みに失敗しました。時間をおいて再度お試しください。」 | 規約データまたは本文の取得中に例外が発生した場合 |
| 規約が存在しない | Next.jsの標準not-foundページ | 指定したIDの規約が存在しない場合 |

## 実装参照（エンジニア向け）

- `apps/admin/app/(app)/terms/[id]/edit/page.tsx`
- `apps/admin/app/(app)/terms/[id]/edit/_components/TermEditor.tsx`
- `packages/lib/components/term/TermViewer.tsx`（プレビュー表示に使用）
- `apps/admin/actions/adminTermAction.ts`（`getTermById`, `getTermContent`, `updateTerm`。
  RPCは使わず`com_m_terms`テーブルとStorage `terms`バケットを直接操作する）
- 備考: 保存の度に本文はキャッシュ対策のため新しいファイルパス
  （`{種別}/{種別}_{バージョン名}_{タイムスタンプ}.md`）としてアップロードされ、旧ファイルは
  削除される。バージョン名自体は編集画面からは変更できない（保存前と同じ値が使われる）。
