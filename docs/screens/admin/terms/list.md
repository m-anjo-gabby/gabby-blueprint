# 規約管理一覧（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/terms`
- 対象ロール: `admin`（サイドバーの「システム設定」グループ内「規約管理」メニューは`admin`ロールのみに表示される）
- 目的: 利用規約・プライバシーポリシーのバージョンを一覧・検索し、新規バージョンの作成や
  既存バージョンの編集・削除を行う。

## この画面に来る経路

- サイドバーメニューの「システム設定」グループ内「規約管理」から遷移する。

## 画面の構成

1. **ヘッダー** — 画面タイトルと「規約を新規作成」ボタン
2. **検索・ページングバー** — バージョン名でのキーワード検索、全件数表示、ページ送り
3. **一覧テーブル** — 規約種別・バージョン・ステータス・公開開始日・操作（編集／削除）
4. **新規作成ダイアログ**（ヘッダーの「規約を新規作成」から開く）
5. **削除確認ダイアログ**（一覧の削除アイコンから開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索ボックス | 常時表示 | バージョン名で絞り込み、Enterまたは「検索」ボタンでURLの`q`パラメータを更新して再検索する |
| ページ送り（前へ／次へ） | 常時表示（1ページ10件） | 前後のページへ遷移する |
| 規約種別バッジ | 常時表示 | `TERMS`は「利用規約」、`PRIVACY`は「プライバシーポリシー」と表示される |
| ステータスバッジ「公開前」 | 公開開始日が未来の場合 | — |
| ステータスバッジ「公開中」 | 公開開始日が過去、かつその種別の中で現在有効な最新版の場合 | — |
| ステータスバッジ「公開終了」 | 公開開始日が過去だが、現在有効な最新版ではない（＝過去の版）場合 | — |
| 編集アイコン | 各行に常時表示 | `/terms/[id]/edit`（規約編集画面）に遷移する |
| 削除アイコン | 公開開始日が未来（＝「公開前」）の行のみ表示 | 削除確認ダイアログを開く。確定すると規約レコードとStorage上の本文ファイルが削除される |
| 「規約を新規作成」ボタン | 常時表示 | 新規作成ダイアログを開く |

## 新規作成ダイアログ

- 入力項目: 規約種別（利用規約／プライバシーポリシー）、バージョン名、公開開始日（JST）、
  同意必須（必須／任意）、規約本文（Markdown、テキストエリアに直接入力）
- 公開開始日は本日以降の日付のみ指定可能（過去日を入力するとエラーメッセージが表示される）
- 「内容を確認する」を押すと入力内容の確認表示に切り替わり、「はい、確定します」で確定する
- 同じ規約種別・バージョン名の組み合わせが既に存在する場合、確定時にエラーメッセージが表示される
- 保存されたMarkdown本文はStorage（`terms`バケット）にアップロードされ、DBには保存先パスが記録される

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| データなし | 「規約データが見つかりませんでした。」（テーブル内） | 検索条件に一致する規約が0件の場合 |
| 削除処理中 | テーブル全体に半透明オーバーレイと「削除しています...」の表示 | 削除確認ダイアログで削除を確定した直後〜完了まで |
