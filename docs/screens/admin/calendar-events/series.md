# グループセッションのシリーズ（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/calendar-events/series`（一覧）、`/calendar-events/series/[seriesId]`（詳細）
- 対象ロール: 管理者（カレンダーイベント管理を利用できるロール）
- 目的: グループセッションを企画（シリーズ。例: 「10月の発音グループセッション」「10月のビジネス英語ミニセッション」）ごとに、
  シリーズ名・説明（企画の紹介・その月のテーマ等）と複数の回をまとめて管理する。翌月分は新しいシリーズとして作る。
- シリーズの回はこの画面の「回をまとめて追加」でだけ作る。カレンダーイベント管理（[list.md](./list.md)）の「新規登録」は単発のイベント専用で、
  シリーズの付け外しはできない（シリーズの回の編集画面ではシリーズ名を読み取り専用で表示し、「シリーズで管理」でこの画面へ移る）。

## この画面に来る経路

- カレンダーイベント管理のヘッダーの「シリーズ管理」（一覧）。
- カレンダーイベント管理の一覧で、シリーズの回のタイトルの下の「シリーズ: <シリーズ名>」、または回の編集ダイアログの「シリーズで管理」（詳細）。

## シリーズ一覧

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「カレンダーイベント管理へ戻る」 | 常時 | `/calendar-events` へ |
| 「新規シリーズ」 | 常時 | シリーズの作成ダイアログ（シリーズ名〔必須〕・説明）。作成するとそのシリーズの詳細へ移る |
| 一覧の行 | シリーズ名・回数（論理削除を除く）・次回の開始（これから始まる直近の回の開始日時。日本時間。無ければ「予定なし」）。新しく作った順 | 行全体（またはシリーズ名・「回の管理・詳細」ボタン）でシリーズの詳細へ |
| 空の一覧 | 「シリーズはまだありません。」 | — |

## シリーズ詳細

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 「シリーズの一覧へ戻る」 | 常時 | `/calendar-events/series` へ |
| 見出し | シリーズ名・回数。説明があれば下に表示 | — |
| 「編集」 | 常時 | シリーズ名・説明を編集する |
| 「このシリーズを元に作成」 | 常時 | タイトル（末尾に「（コピー）」）と説明を引き継いだ作成ダイアログを開き、作成すると新しいシリーズの詳細へ移る。回は引き継がない |
| 「削除」 | 常時 | 確認の上でシリーズを削除する。各回は削除されず、単発のイベントとして残る（`series_id` は外れる） |
| 「回をまとめて追加」 | 常時 | 下記のダイアログを開く |
| 回の一覧 | シリーズの回（開始日時の順）。表示・操作はカレンダーイベント管理の一覧と同じ（参加者・アナウンス、編集、削除）。シリーズ名の表示は省く | — |

### 回をまとめて追加

- **全回に共通する設定**: 配信対象（生徒全体／顧客指定。顧客指定は対象顧客が必須）、参加URL（全回に同じURL。回ごとに変える場合は登録後に各回を編集）、公開する。
  参加確認はグループセッションのため常に有効で登録する（その旨を表示）。
- **回ごとの設定**: 日付（日本時間）・開始時刻・終了時刻（任意。開始時刻以前なら翌日の時刻とみなす）・内容（タイトル、必須）・説明（任意）・担当コーチ（複数選択）。
- **初期値**: シリーズの最後の回を引き継ぐ（共通設定、1週間後の同じ時刻・同じ担当コーチ。内容・説明は空）。回が無い場合は今日の 21:00〜21:30。
  「回を追加（1週間後）」で直前の行の1週間後の行を足し、「この回を外す」で行を消す（1行は残す）。
- 「n件を登録する」で全回を1つのトランザクションで登録する（1件でも失敗したら登録しない）。登録後はダイアログを閉じ、「n件の回を登録しました」と表示する。
- バリデーション: 日付・開始時刻・内容が必須、参加URLはURL形式、顧客指定の場合は対象顧客が必須。
