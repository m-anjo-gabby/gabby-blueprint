# カレンダーイベント管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/calendar-events`
- 対象ロール: システム管理者
- 目的: 生徒・コーチのカレンダーに表示されるグループセッションやメンテナンス告知などの
  「共有カレンダーイベント」を登録・編集・削除する。個別の1:1セッション（予約枠）とは別の仕組み。

## この画面に来る経路

- 管理画面のナビゲーションから直接遷移する（詳細な導線は本ドキュメントの対象外）。

## 画面の構成

1. **ヘッダー** — 画面タイトル、説明文、「新規登録」ボタン
2. **一覧テーブル** — 登録済みカレンダーイベントの一覧（検索・ページング付き）
3. **新規登録／編集ダイアログ**（一覧から開く）
4. **削除確認ダイアログ**（一覧から開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 検索ボックス | 常時表示 | タイトルの部分一致で一覧を絞り込む |
| 種別バッジ | 「グループセッション」「メンテナンス」のいずれか | 表示のみ |
| 開始日時 | 日本時間で表示 | 表示のみ |
| 担当コーチ列 | グループセッションで担当コーチが割り当てられている場合に氏名を列挙。未設定は「-」 | 表示のみ |
| 公開状態バッジ | 「公開中」（緑）または「下書き」（グレー） | 表示のみ |
| 参加者・アナウンス管理アイコン（人型アイコン） | 参加確認が有効、または担当コーチが1人以上割り当てられている行にのみ表示 | 参加者・アナウンス管理画面（`/calendar-events/[id]/participants`）へ遷移する |
| 「編集」ボタン | 各行に表示 | 新規登録と同じダイアログが編集モードで開き、既存値が入った状態になる |
| 削除ボタン（ゴミ箱アイコン） | 各行に表示 | 確認ダイアログを経て論理削除する。削除後は生徒/コーチのカレンダーから表示されなくなる旨が確認文言に明記される |
| 「新規登録」ボタン | 常時表示 | 新規登録ダイアログを開く |

## 新規登録／編集ダイアログ

- 入力後、「登録内容を確認する」ボタンでいったん確認画面（入力値の読み取り専用表示）に切り替わり、
  「はい、確定します」で確定する2段階の登録フローになっている。
- 入力項目:
  - **イベント種別**: 「グループセッション」「メンテナンス」から選択
  - **タイトル**（必須）、**説明**（任意）
  - **開始日・開始時刻**（必須、日本時間で入力）
  - **終了日時を設定する**トグル。オンにした場合のみ終了日・終了時刻の入力欄が表示され、
    開始日時より後であることがバリデーションされる
  - **参加URL**（任意。主にグループセッションのZoom URL等を想定）
  - **参加確認を有効にする**トグル。オンの場合、生徒/コーチ側でこのイベントへの参加登録・
    キャンセルが可能になる
  - **配信対象**: 「生徒全体」「顧客指定」「コーチ全体」から選択。「顧客指定」を選ぶと
    対象顧客の選択欄が追加表示され、選択が必須になる
  - **担当コーチ**（イベント種別が「グループセッション」の場合のみ表示。複数選択可、
    人数の上限はない）。コーチ名で検索して選択でき、選択済みコーチはタグ形式で表示され
    個別に解除できる。登録すると自動的にコーチアプリのカレンダーにも表示される旨の説明がある
  - **公開する**トグル。オフの場合は下書きとして保存され、生徒/コーチには表示されない
- バリデーション: タイトル必須、開始日時必須、終了日時を設定する場合は開始日時より後であること、
  参加URLはURL形式であること、配信対象が「顧客指定」の場合は対象顧客の選択が必須であること。

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 一覧が空 | 「カレンダーイベントが見つかりませんでした。」 | 登録されたイベントが0件、または検索条件に一致する行がない場合 |
| 登録・更新エラー | 確認画面内にエラーメッセージを表示 | サーバー側で保存に失敗した場合（ダイアログは閉じない） |
