# お知らせ既読状況（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/notice/[id]/reads`
- 対象ロール: システム管理者
- 目的: 特定のお知らせについて、配信対象ユーザー（生徒・コーチ）ごとの既読／未読状況を確認する。

## この画面に来る経路

- お知らせ管理一覧（`/notice`）の対象行の既読状況アイコン（チェックマーク）から遷移する。

## 画面の構成

1. **ヘッダー** — 一覧へ戻るリンク、対象お知らせのタイトル
2. **集計サマリー** — 対象ユーザー数、既読数（既読率%付き）、未読数
3. **フィルターバー** — 所属顧客・ユーザー区分（生徒/コーチ）での絞り込み
4. **一覧テーブル** — 対象ユーザーごとの既読状況（ページング付き）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 対象ユーザー数・既読数・未読数のサマリーカード | 常時表示。既読数には既読率(%)を併記 | 表示のみ（現在のフィルタ条件を反映した集計値） |
| 所属顧客フィルター | 「すべての顧客」＋顧客一覧 | 選択した顧客に所属する対象ユーザーのみに絞り込む |
| ユーザー区分フィルター | 「すべての区分」「生徒」「コーチ」 | 選択した区分の対象ユーザーのみに絞り込む |
| ユーザー行 | 氏名、所属顧客、区分バッジ、既読状況バッジ（既読/未読）、既読日時（JST。未読は「-」） | 表示のみ |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 対象のお知らせが存在しない | 「お知らせが見つかりません。」 | 指定したnotice_idが存在しない場合 |
| 一覧が空 | 「対象ユーザーが見つかりません」 | 絞り込み条件に該当する対象ユーザーが0件の場合 |
