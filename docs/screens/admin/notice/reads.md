# お知らせ既読状況（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/notice/[id]/reads`
- 対象ロール: システム管理者
- 目的: 特定のお知らせについて、配信対象ユーザー（生徒・コーチ）ごとの既読／未読状況を確認する。

## この画面に来る経路

- お知らせ管理一覧（`/notice`）の対象行の既読状況アイコン（チェックマーク）から遷移する。

## 画面の構成

1. **ヘッダー** — 一覧へ戻るリンク、対象お知らせのタイトル
2. **集計サマリー** — 対象ユーザー数、既読数（既読率%付き）、未読数、（行動ボタンのあるお知らせのみ）ボタンを押した人数
3. **一覧テーブル** — 氏名の検索・所属顧客/ユーザー区分（生徒/コーチ）の絞り込み・条件のクリア・件数・ページ送りの操作欄と、対象ユーザーごとの既読状況（既読を既読日時の新しい順に先頭、続けて未読）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| 対象ユーザー数・既読数・未読数のサマリーカード | 常時表示。既読数には既読率(%)を併記 | 表示のみ（現在の検索・絞り込み条件を反映した集計値） |
| 「ボタンを押した」のサマリーカード | 行動ボタンのあるお知らせのみ。押した人数と、既読者のうち押した割合（「既読のn%」） | 表示のみ（同上） |
| 検索ボックス | 常時表示 | 氏名の部分一致で検索。Enterまたは「検索」ボタンで確定し、URLの`q`に反映する（1ページ目に戻る）。入力した文字はそのまま文字として検索する（`%`・`,`等も特別な意味を持たない） |
| 所属顧客フィルター | 検索式セレクト（未選択時は「すべての顧客」） | 選択した顧客に所属する対象ユーザーのみに絞り込む（URLの`clientId`。1ページ目に戻る） |
| ユーザー区分フィルター | 「すべての区分」「生徒」「コーチ」 | 選択した区分の対象ユーザーのみに絞り込む（URLの`userType`。1ページ目に戻る） |
| 「条件をクリア」ボタン | 常時表示（検索語・絞り込みが無いときは押せない） | 検索語・絞り込み・ページをすべて外し、初期状態の一覧に戻す |
| 件数・ページ送り（前へ・次へ） | 常時表示（「全 n 件」、1ページ10件。先頭・末尾では該当ボタンが無効） | 前後のページへ移る（URLの`page`） |
| ユーザー行 | 氏名、所属顧客、区分バッジ、既読状況バッジ（既読/未読）、既読日時（JST。未読は「-」）、（行動ボタンのあるお知らせのみ）ボタンを押した日時（JST。最初に押した日時。押していなければ「-」） | 表示のみ |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 対象のお知らせが存在しない | 「お知らせが見つかりません。」 | 指定したnotice_idが存在しない場合 |
| 一覧が空 | 「対象ユーザーが見つかりません」 | 検索・絞り込み条件に該当する対象ユーザーが0件の場合 |
