# お知らせ新規作成（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/notice/new`
- 対象ロール: システム管理者
- 目的: 生徒・コーチのアプリ内に表示する「お知らせ」を新規作成する。編集画面
  （`/notice/[id]/edit`）と同一の入力フォーム（`NoticeEditor`）を使用しており、
  画面の構成・項目・挙動は共通。本ドキュメントがその内容の正本であり、編集画面側は
  差分のみを記載する。

## この画面に来る経路

- お知らせ管理一覧（`/notice`）の「新規お知らせ作成」ボタンから遷移する。

## 画面の構成

1. **トップバー** — 一覧へ戻るボタン、画面タイトル、「登録する」ボタン
2. **左パネル（メタ情報）** — タイトル、種別、配信対象、公開期間、各種フラグ、添付ファイル
3. **右パネル（本文エディタ）** — Markdown本文の「編集」「プレビュー」切り替えタブ

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| タイトル入力 | 必須 | 一覧画面のタイトル列に表示される |
| お知らせ種別セレクト | 「お知らせ」「キャンペーン」「メンテナンス」「アップデート」から選択 | 一覧・利用者側での種別バッジ表示に反映される |
| 配信対象セレクト | 「生徒全体配信」「顧客指定」「コーチ一括配信」から選択 | 「顧客指定」を選ぶと対象顧客セレクトが追加表示され、選択が必須になる |
| 公開開始日（JST） | 必須。新規作成時は当日日付が初期値 | 未入力の状態では保存できない |
| 公開終了日（JST） | 任意 | 未入力（無期限）の場合、「クリア」ボタンで入力値を空に戻せる。設定した場合、この日時を過ぎると一覧上のステータスが「終了」になる |
| 公開ステータストグル | ON=公開、OFF=下書き | OFFのまま保存すると、生徒/コーチのアプリには表示されない下書き状態で保存される |
| 重要お知らせトグル | ON/OFF | ONにすると一覧および配信先アプリで「重要」バッジが赤色で強調表示される |
| ポップアップ表示トグル | ON/OFF | ONにすると、対象ユーザーのログイン時に全画面ダイアログとして自動表示される |
| 添付ファイル「追加」ボタン | 常時表示 | ファイルを選択してアップロード対象に追加する（保存時に実際のアップロードが行われる） |
| 添付ファイル削除（ゴミ箱） | 添付済みファイルの各行 | その場でリストから外す（保存時にStorageからも削除される） |
| 本文エディタ（編集/プレビュー切り替え） | 常時表示 | Markdown形式で本文を入力する。「プレビュー」タブで配信先アプリでの表示イメージを確認できる |
| 「登録する」ボタン | 常時表示 | タイトル・公開開始日・（顧客指定時は）対象顧客が未入力だとエラーメッセージを表示して保存しない。保存に成功すると一覧画面（`/notice`）へ遷移する |

## 状態

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 保存中 | 「登録する」ボタンがローディング表示になり操作不可 | 保存処理中（添付ファイルのアップロード含む） |
| バリデーションエラー | トースト通知でエラーメッセージ表示、画面は編集画面のまま | タイトル未入力、公開開始日未入力、配信対象が「顧客指定」なのに対象顧客未選択、のいずれか |
| 保存失敗 | トースト通知でエラーメッセージ表示 | サーバー側で保存に失敗した場合（添付ファイルのアップロード失敗を含む） |
