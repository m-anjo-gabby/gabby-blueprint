# お知らせ管理（adminアプリ）

## 概要

- アプリ: `admin`
- パス: `/notice`
- 対象ロール: システム管理者
- 目的: 生徒・コーチのアプリ内に表示する通知・キャンペーン・メンテナンス情報等の「お知らせ」を
  一覧・検索し、新規作成・編集・削除・既読状況確認への導線を提供する。

## この画面に来る経路

- 管理画面のナビゲーションから直接遷移する（詳細な導線は本ドキュメントの対象外）。

## 画面の構成

1. **検索・フィルターバー** — タイトル検索、種別フィルター、「新規お知らせ作成」ボタン
2. **一覧テーブル** — お知らせの一覧（URLのクエリパラメータ`q`/`type`/`page`で状態を保持する）
3. **削除確認ダイアログ**（一覧から開く）

## 表示要素・操作

| 要素 | 表示条件・内容 | 操作した時の挙動 |
|---|---|---|
| キーワード検索 | 常時表示 | タイトルの部分一致で一覧を絞り込む（1ページ目に戻る） |
| 種別フィルター | 「お知らせ」「キャンペーン」「メンテナンス」「アップデート」＋「すべての種別」 | 選択した種別で一覧を絞り込む |
| タイトル列 | タイトル。「重要」バッジ（重要フラグON時、赤色）、「ポップアップ」バッジ（ポップアップ表示ON時）、添付ファイル件数を併記 | クリックで編集画面（`/notice/[id]/edit`）へ遷移する |
| 種別バッジ | 「お知らせ」「キャンペーン」「メンテナンス」「アップデート」 | 表示のみ |
| 対象列 | 「生徒全体配信」「コーチ一括配信」、または顧客指定時は顧客名 | 表示のみ |
| ステータスバッジ | 「下書き」「予約公開」「公開中」「終了」のいずれか（後述の「状態」参照） | 表示のみ |
| 公開日時・終了日時列 | JST表示。終了日時未設定は「無期限」 | 表示のみ |
| 編集アイコン | 各行に表示 | 編集画面（`/notice/[id]/edit`）へ遷移する |
| 既読状況アイコン（チェックマーク） | 各行に表示 | 既読状況確認画面（`/notice/[id]/reads`）へ遷移する |
| 削除アイコン（ゴミ箱） | 各行に表示 | 確認ダイアログを経て削除する（取り消し不可、ユーザー画面からも削除される旨が案内される） |
| 「新規お知らせ作成」ボタン | 常時表示 | 新規作成画面（`/notice/new`）へ遷移する |

## 状態（公開ステータスバッジの判定）

| 状態 | 表示内容 | 発生条件 |
|---|---|---|
| 下書き | グレーの「下書き」バッジ | `is_published`がOFFの場合（他の条件より優先） |
| 予約公開 | 黄色の「予約公開」バッジ | 公開フラグはONだが、公開開始日時（`published_at`）がまだ到来していない場合 |
| 公開中 | 緑の「公開中」バッジ | 公開フラグON、公開開始日時を過ぎており、終了日時が未設定または未到来の場合 |
| 終了 | グレーの「終了」バッジ | 終了日時（`expired_at`）を過ぎている場合 |
| 一覧が空 | 「お知らせが見つかりません」 | 登録されたお知らせが0件、または検索・フィルタ条件に一致する行がない場合 |
