### CVJ-20260925-01 機能語の発音は辞書の見出し発音（強形）で統一する

- **状態**: 暫定（コンテンツチームの確認で変更可）
- **対象**: 冠詞・前置詞・代名詞・助動詞などの機能語（the, a, for, you, to, was など）
- **論点・事象**: 機能語は会話では弱形（the /ðə/、for /fər/）で発音されることが多いが、辞書には1つの発音しか登録できない。
- **判断**: 辞書の見出し発音（強形）で統一する（例: `the` → `/ðiː/` `green_tea`、`for` → `/fɔːr/` `orange_door`）。
- **根拠**: 既存の辞書データ（`for` = `/fɔːr/`）に合わせた。弱形に揃える場合は、機能語を一括で見直す。
- **反映先**: reference.md「8. phonetic_spelling」

### CVJ-20260925-02 Gem で作成した既存データに cv_id の誤りがあった（for = rose_boat）

- **状態**: 確定
- **対象**: dev環境の既存データ `for`（PREP）
- **論点・事象**: 発音記号は `/fɔːr/` なのに `cv_id` が `rose_boat` になっていた（正しくは `orange_door`）。
  旧Gemの出力を目視確認だけで取り込んでいたため気づけなかった。
- **判断**: 発音記号のアクセント母音から期待される `cv_id` を機械的に照合し、不一致を要確認に出す。
- **根拠**: 発音記号と Color Vowel は1対1で対応するため、機械的に検出できる。
- **反映先**: `validate.ts`（IPAとcv_idの照合）。dev の既存データは未修正（辞書画面で修正するか、上書き取込で直す）。

### CVJ-20260925-03 略語は1文字を1音節とし、最後の文字にアクセントを置く

- **状態**: 暫定（コンテンツチームの確認で変更可）
- **対象**: 1文字ずつ読む略語（CEO など）
- **論点・事象**: 略語は通常の単語のように音節に分けられない。
- **判断**: 大文字のまま登録し、`C-E-O` のように1文字を1音節とする。第一アクセントは最後の文字、
  `stress_vowel_spelling` はその文字、`cv_id` は文字の名前の読み（O /oʊ/ → `rose_boat`）で決める。
- **根拠**: 英語の略語は一般に最後の文字に第一アクセントが来る。
- **反映先**: reference.md「略語」節

### CVJ-20260925-04 綴りと品詞が同じで発音が異なる語は1行しか登録できない（read）

- **状態**: 確定
- **対象**: `read`（VERB）
- **論点・事象**: 現在形 `/riːd/` と過去形 `/rɛd/` で発音も Color Vowel も異なるが、辞書のキーは
  「英単語＋品詞」のため、同じ品詞で2行は登録できない。
- **判断**: 現在形（原形）の発音で登録し、要確認メモに過去形の発音を残す。
- **根拠**: 辞書の見出しは原形の発音が一般的。区別が必要になった場合はDB設計（キー）の見直しが必要。
- **反映先**: 台帳（read / VERB）
