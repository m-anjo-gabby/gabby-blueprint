# ビデオ教材の管理（アドミン）

## 概要

アドミンがビデオ教材（1シリーズ = 1教材）の区切り（見出し）とビデオを管理する。ビデオのファイルはブラウザから
保存先へ直接アップロードし、差し替え・削除のたびに使わなくなったファイルを消す。旧システムから移したビデオは
非公開で入り、並べ替え・移動・プレビューをしてから公開する。

## 関与ロール・画面

| ロール | 画面 | パス | 主なコンポーネント/アクション |
|---|---|---|---|
| アドミン（システム管理者・教材担当） | 教材管理（一覧・登録） | `admin` `/contents` | `ContentFormDialog.tsx`・`columns.tsx`、`upsertContent`。画面仕様: [docs/screens/admin/contents/list.md](../../../../docs/screens/admin/contents/list.md) |
| アドミン（システム管理者・教材担当） | 教材詳細エディタ（ビデオ教材） | `admin` `/contents/[id]` | `editors/VideoEditor/`、`adminVideoAction.ts`。画面仕様: [docs/screens/admin/contents/detail.md](../../../../docs/screens/admin/contents/detail.md) |

## 前提条件

- 固定の `qa-admin` でログインする（`support/adminApp.ts` の `openAdminContext`）。
- 教材はテストごとに使い捨てで作る（`support/videoFixtures.ts`。教材名 `【QAテスト】ビデオ教材E2E（${tag}）`）。
  画面の登録の操作を確かめないテストは `seedVideoContent` で区切り・ビデオまで作る（動画は2秒のテスト用のファイル）。
- テスト用のファイルは `testing/e2e/fixtures/video/`（2秒・3秒の MP4、PNG のサムネイル。合成のテストパターン）。
- 視聴の記録の検証には使い捨ての生徒（`createAuthFixture` / `createDisposableStudent`）を作り、`student_m_video_progress` に行を入れる。
- ファイルの置き場所は、R2 の準備ができるまで dev の Supabase Storage の一時のバケット `video`（dev だけで実行する。
  staging にはビデオの機能を出していない）。

## フロー（正常系）

1. アドミンが教材管理で新規登録を開き、種別「ビデオ」とビデオの種類（発音トレーニング / オンデマンド / ColorVowel）を選んで確定する。
   → 教材が非公開で作られ（`category_id` は種類の値）、見出しの無い区切りが1つでき、教材詳細エディタへ移る。
2. 区切りを追加する（見出しは任意）。見出しを変える・上下に並べ替える・空の区切りを削除する。
3. 区切りの「ビデオを追加」から、タイトル・動画ファイル・サムネイル（任意）・公開（既定は非公開）を入れて保存する。
   → 再生時間を選んだファイルから測り、ファイルを `{video_id}/{uuid}.<拡張子>` のキーで保存してからビデオの行を作る。区切りの末尾に入る。
4. サムネイル（または空の枠）を押すとプレビューが開き、非公開のビデオでも再生できる。
5. 編集で動画を選び直すと差し替えになる。新しいキーで保存し、再生時間を測り直し、古いファイルを消す。
   「サムネイルを外す」で保存すると、サムネイルの列を空にしてファイルを消す。
6. ビデオを上下に並べ替える・公開スイッチで公開状態を切り替える。
7. 「別の区切りへ移す」で、移動先の教材（別の教材も選べる）と区切りを選ぶ。→ 移動先の末尾に入る。今の区切りは選べない。
8. ビデオを削除する。→ 行を消した後に動画・サムネイルのファイルを消す。
9. 教材一覧のビデオ教材の行の「ビデオを編集」（と教材名のリンク）から教材詳細エディタへ移れる。

## 異常系・バリデーション一覧

| # | 条件 | 期待結果 | 発生層 |
|---|---|---|---|
| 1 | 種別「ビデオ」でビデオの種類を選ばずに確認へ進む | 「ビデオの種類を選択してください」で止まる | UI |
| 2 | 動画の欄に MP4 以外（PNG 等）を選ぶ | 「このファイルの形式には対応していません」を出し、選ばない | 両方（サーバーもアップロード先の発行で断る） |
| 3 | 動画 50MB・サムネイル 5MB を超えるファイルを選ぶ | 「ファイルが大きすぎます（…MBまで）」を出し、選ばない | 両方（バケットも 50MB で断る） |
| 4 | 新しいビデオで動画を選ばずに保存する | 「動画ファイルを選んでください」で止まる | UI |
| 5 | タイトルが空のまま保存する | 「タイトルを入力してください」で止まる | 両方 |
| 6 | ブラウザが送ったと言うキーが、そのビデオのフォルダーでない・置かれていない・種類が違う | 「アップロードしたファイルを確認できませんでした…」で保存しない | サーバーアクション（UI導線なし） |
| 7 | アップロードの途中で失敗する | 「ファイルのアップロードに失敗しました…」を出し、今回送ったファイルを消す | UI |
| 8 | ビデオの行の保存に失敗する | エラーを出し、今回送ったファイルのうち行が使っていないものを消す | サーバーアクション |
| 9 | ビデオが残っている区切りを削除する | 削除のボタンを押せない（サーバーも「ビデオが残っている区切りは削除できません…」で断る） | 両方 |
| 10 | 視聴の記録があるビデオを削除する | 「視聴の記録があるため削除できません。非公開にしてください」を出し、行・ファイルは残る | サーバーアクション（DB の外部キーの RESTRICT） |
| 11 | 区切りの先頭・末尾で上へ・下へを押す | ボタンを押せない | UI |
| 12 | 移動先にビデオ教材でない教材の区切りを指定する | 「移動先の区切りが見つかりません」で移さない | サーバーアクション（UI導線なし） |
