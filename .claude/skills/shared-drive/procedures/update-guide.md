# 「はじめにお読みください」を直す

B_運営共有/00_はじめにお読みください のドキュメント（ID は [../reference/drive-map.md](../reference/drive-map.md)）。運営スタッフが最初に開く案内なので、フォルダ構成・受付方法・連絡先の変更は必ずここに反映する。

## 今の構成

見出し1つ（Gabby Blueprint 運営共有フォルダの使い方）の下に、見出し2の節が次の順で並ぶ。

1. フォルダの案内（番号付きリスト。各行は「フォルダ名（リンク）：役割」）
2. ファイル名のルール（番号付きリスト）
3. 資料についてのご質問
4. 要望・不具合のご連絡（受付フォーム・受付台帳・補足資料フォルダのリンク、フォームの質問の箇条書き）
5. お問い合わせ（窓口は未決。決まったらここに書く）

節を足す・順を変える場合は、この一覧も直す。

## 手順

1. Drive の `read_file_content` で今の文面を読む（ユーザーや他の人が直していることがある。前回の内容を前提にしない）。
2. 直す位置が要る編集は Docs の `read_doc` で位置と `revisionId` を取り、`requiredRevisionId` を付けて送る。文言だけの置き換えは `replaceAllText`（`tabsCriteria: t.0`）で行う。
3. 書き方は既存に合わせる。
   - フォルダの案内に行を足すときは、既存のリストの最後の行の末尾に改行して足す（同じ番号付きリストに入る）。フォルダ名にリンクを付け、色は [../reference/known-limits.md](../reference/known-limits.md) のリンクの色にする。
   - 新しい節は見出し2で足し、本文は標準のスタイルにする。
4. `read_file_content` で読み直し、リンク・番号・見出しが崩れていないかを確かめる。
5. フォームの質問を変えた場合は、「要望・不具合のご連絡」の箇条書きもフォームに合わせる。
