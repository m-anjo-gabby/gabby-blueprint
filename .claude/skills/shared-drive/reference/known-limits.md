# 既知の制約と回避策

詰まったこと・遠回りした方法は「症状 → 原因 → 回避策」で1件ずつ足す。

## Googleフォーム

- **フォームを作る・編集する接続が無い** → Claude の接続は Drive・Docs・Sheets・Slides だけで、フォームの中身は読むことも書くこともできない（Drive の `read_file_content` もフォームは非対応）→ Apps Script を書いてユーザーに実行してもらう（[script.google.com](https://script.google.com) の同じプロジェクトに関数を足す）。2回実行しても壊れないよう、同じ質問があれば何もしない作りにする。実行したスクリプトは `scripts/` に残す。
- **共有ドライブに置いたフォームで「ファイルのアップロード」が選べない** → Google の仕様。Apps Script にもこの種類の質問を作る機能が無い → 添付は使わず、70_要望・不具合の受付/補足資料 に起票者が1件1フォルダで置き、フォームにはそのフォルダのリンクを書いてもらう。
- **フォームの質問を足すと、回答先のシートに列が増える** → 新しい列は、回答の列の最後（管理用の列の左）に入り、管理用の列は右へずれる → 変更後に台帳の見出し・プルダウン・色分けの位置を読み直して確かめる。
- **質問を消しても、回答先のシートの列は残る** → 回答が無い列であることを確かめてから、列を削除する。

## 受付台帳（フォームの回答先のスプレッドシート）

- **見出しの「受付日時」「メールアドレス」が英語（Timestamp / Email Address）に戻る** → フォームを編集すると、Google が見出しを書き直す → フォームを変えたあとに A1:B1 を日本語に直す。
- **回答の列（A〜J）の見出しを台帳側で変えてはいけない** → 質問との対応が崩れる → 質問の名前はフォームの編集画面で変える。
- **管理用の列の見出しの色が見えにくい** → 回答のシートは「表」（`Form_Responses`）で、文字色が白に決まっている → 管理用の列の見出しは濃い色（濃いオレンジ `#b45f06`）にする。薄い色にしない。
- **プルダウン・日付チェック・色分けは1000行目まで** → 行を区切らずに設定しても、Google 側で今の行数（1000）までとして保存される → 回答が1000件に近づいたら、行を足して同じ設定を広げる（request-ledger.md の手順）。

## Googleドキュメント

- **フォルダのリンクの色** → 既存のリンクは文字色 `rgb(0.067, 0.333, 0.8)`・下線付き。新しく付けるリンクも同じにする。
